# SimplCore 改动后完整架构 · 源码包

这是**纯源码包**：不含权重、不含论文 PDF、不含实验报告。权重在上一轮的 `SimplCore_模型本体_完整架构.zip` 里（`model.npz` 对应下面 `01` 的实现）。

## 一句话

`01` 是真正端到端训练并生成出文本的那套模型；`02` 是同一研究线在 Qwen3 1.7B 规模上的 torch / HuggingFace 实现；`03` 是一步步改架构的真实训练演进链；`04` 是被替换前的上游 SGC 算子库（参考用，不是最终前向）。

## 01 · 参考实现 ARCH_STEP 8（纯 NumPy，已训练、会说话）

| 文件 | 作用 |
|---|---|
| `nn.py` | 最小自动微分：`Tensor`、解析 adjoint、`custom()`、embedding / matmul / layernorm / gelu / sigmoid / cross_entropy |
| `simplcore_lm.py` | **核心架构**：`SimplCoreBlock.forward` / `SimplCoreLM.forward`，三个融合算子 `window_attn` / `toeplitz_mix` / `decayed_attn` 及其显式参考递推 |
| `stream_lm.py` | **O(1) 状态流式推理**：`StreamState`（环形缓冲 + K 个 IIR 状态 + 一个 d×d 外积状态）、`StreamSimplCoreLM.step/generate` |
| `train.py` | 真实语料训练入口（Adam、gradcheck、存读断点、`--resume` / `--fresh` / `--eval-only`） |
| `chat.py` / `stream_chat.py` | 全展开推理 / O(1) 生成命令行 |
| `verify_final.py` | 10 项白盒验收：算子等价、状态恒定、SGC 扰动、全新种子首步梯度、生成质量 |

前向（`SimplCoreBlock.forward`，3 层 decoder-only，pre-LN 残差）：

1. 局部内容寻址：`window_attn(q,k,v,W=12,pos)` —— **固定窗口 W 内的因果 q·k 打分 + softmax**，窗口不随 L 增长；
2. 全局静态核：`toeplitz_mix(u,wlogits,rhos)` —— 3 极点 Toeplitz（ρ=0.6/0.9/0.99），只有混合权重可学，核时不变，矩阵形式与 IIR 等价；
3. 门控自进化状态：`decayed_attn(q,k,v,beta,lam)` —— `S_t=λS_{t-1}+β_t k_t v_tᵀ`，读出 `q_t S_t/√d`，β 由输入依赖写入门产生；
4. 融合与前馈：`y = a + α·g + γ·m` → `W_o` → GELU FFN，残差。

`ARCH_STEP = 8` 的唯一改动是 `alpha/gamma` 从 `0.0` 改为 `0.02`：零融合门会让 Toeplitz 分支与自进化分支共 9 个参数在训练第一步梯度恒为 0。源码里保留了这条注释。

**如实说明**：`01` 的局部通道里确实有 softmax（`window_attn` 第 63–65 行），但它是长度固定为 W=12 的局部窗口，不是全局 N×N attention，也不缓存跨生成步的 attention 权重。`02` 则完全不用 softmax。两套实现**不是同一份前向的两个尺寸**，见下。

## 02 · 1.7B 生产链路 V7（torch / HF）

| 文件 | 作用 |
|---|---|
| `modeling_simplcore_v7.py` | **正式架构定义**：`SimplCoreV7Config` / `RMSNorm` / `QwenSwiGLU` / `V7Block.step` / `SimplCoreV7Model` / `SimplCoreV7ForCausalLM`（含 `forward` 展开训练、`forward_step` O(1) 生成、`chat_generate`、`check_stream_equivalence`） |
| `migrate_qwen3.py` | 逐张量 COPY / DERIVE / NEW 迁移，产出与教师**不同**的 state_dict |
| `numpy_lm.py` | 该链路的 NumPy 参考实现 `SimplCoreV7` |
| `train_simplcore.py` / `run_sandbox.py` | 本机训练与沙盒复现入口 |
| `verify_arch.py` / `contract_check.py` | 硬判据：只扰动 SGC 参数 logits 必须变化；state_dict 键契约核对 |
| `bpe.py` | Qwen3 BPE 子集 |

`V7Block.step` 每层：RMSNorm → 有界因果 depthwise 卷积（`Wc`，K=3）+ pointwise sigmoid 门 → R 个分槽 outer-product 状态 `S=ρS+kvᵀ`、静态 IIR、sigmoid 写门 → 可学混合 `α` → teacher `o_proj` → 残差 → Qwen3 SwiGLU FFN。状态 `O(R·(d/R)² + K·d)`，与 L 无关；**无 softmax attention、无 N×N score、无 KV cache**。

## 怎么确认架构真进了计算图（不是换个文件名的 Transformer）

```powershell
python 01_参考实现_ARCH_STEP8/verify_final.py     # C6 扰动判据 + C7 首步 54/54 参数非零梯度
python 02_1.7B生产链路_V7/contract_check.py       # state_dict 键契约
python 02_1.7B生产链路_V7/verify_arch.py          # 需要 torch，本机执行
```

决定性判据是：**只扰动 SGC / 自进化参数，logits 必须变化**，同时一个未接入图的参数做负对照必须不变。
