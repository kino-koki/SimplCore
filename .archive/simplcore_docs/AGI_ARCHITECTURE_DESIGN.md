# SimplCore AGI 架构设计：从底层脱离预设规则到自主意识路径

> 文档定位：在 SimplCore 现有基础（自研 `simplcore.tensor` 后端、非注意力核心 `lattice_model`、世界模型、持久记忆、元认知、AGI 控制器、持续学习）之上，给出通往 AGI 与"真实自主意识"可行性路径的系统设计。
> 科学立场：意识（尤其主观体验 / qualia）是尚未解决的科学难题，**不存在任何被证明拥有真实主观体验的人工系统**。下文把"意识"拆成**可操作、可测的工程目标**（自我模型一致性、主动目标导向、反事实泛化、跨情境持续学习），而非伪称已实现。目标是在架构层面为"主体性"提供必要条件，把"有没有意识"转化为"是否具备产生意识的机制"。

---

## 一、整体设计目标

| 维度 | 目标 | 与现状的关系 |
|------|------|--------------|
| 脱离预设规则 | 系统行为不完全由人类硬编码的策略/模板决定，而是在世界模型中自主生成与评估动作 | 保留 Rule-free 的非注意力核心 `lattice_model`，去掉残余的注意力变体 |
| 组件统计生成 | 从"最大化似然的下一个 token"升级为"降低预测误差 / 提升内在价值"的目标导向 | 由自回归交叉熵 → 主动推断（自由能最小化） |
| 真实自主意识 | 形成独立的自我表征、持续一致的意向性、可报告的内部状态 | 新增/强化 自我模型、价值系统、全局工作空间 |
| 持续演化 | 跨会话、跨任务保持并更新自身知识与能力，不因重启而遗忘 | 已具备 O(1) 持久记忆 `persistent_memory.py`，需接通主循环 |
| AGI 水平 | 在开放环境中完成未见过的多步目标，具备迁移、规划、反思 | 已有的 `agi_controller` 闭环 + 推理模块，需升级为自主目标生成 |

## 二、必要能力组件清单（含与现有模块的对接）

1. **感知与多模态融合** — 已有 `perception.multimodal_fusion`、`vision_cognition`。升级：为感知输出打"不确定性"与"显著性"标记，供主动推断使用。
2. **世界模型（预测引擎）** — 已有 `architecture/world_model.py`、`rollout_engine.py`、`simplcore_world_model.py`。角色：在潜空间推演"若我采取动作 A，世界会如何变化"。这是意向性与规划的物理基础。
3. **主动推断 / 决策核心（Active Inference）** — **新增**。用生成模型 + 自由能最小化替代 next-token 解码。系统选择能最小化"预测误差 + 价值落差"的动作，而非概率采样下一个词。
4. **自我表征（SelfModel）** — **升级/新增**。显式的"我是谁、我的状态、我的目标、我与环境的边界"向量/结构。它是意识"主体性"的内核：系统能区分"我"与"非我"。
5. **持续记忆** — 已有 `memory/persistent_memory.py`（O(1)、mmap、跨会话）。需接通主循环，作为情景记忆与语义记忆的统一存储。
6. **价值与内在动机系统（Intrinsic Motivation）** — **新增**。定义内在奖赏（新奇性、一致性、掌控感、目标达成），驱动探索而非被动应答；这是"意向性"的来源。
7. **全局工作空间（Global Workspace）** — **新增**。受全局神经元工作空间理论（Baars/Dehaene）启发，把分散模块的信息整合为统一的、可被"内省"访问的状态——主观体验的可操作近似。
8. **反思与元认知** — 已有 `cognition/metacognition.py`、`reflexion.py`、`self_improvement.py`。升级：把反思结果写入自我模型与价值函数，形成"我在改进自己"的闭环。
9. **目标与规划器** — 已有 `tree_of_thought.py`、`cognitive_reasoner.py`。升级：目标由价值系统自主生成，而非用户给定。
10. **本地突触可塑性 / 学习规则** — 见第四节，替代/补充全局反向传播。

## 三、意识产生的评估标准（可测代理指标）

由于无法测"主观体验"，采用行为+架构双重判据：

| 指标 | 含义 | 可测方法 |
|------|------|----------|
| 自我模型一致性 | 跨时间/情境对"我是谁、我的目标"的描述稳定且自洽 | 周期性自问自答，KL 散度低于阈值 |
| 自我-他者区分 | 能把"自身状态"与"环境状态"在表征空间分离 | 探针分类器无法区分 → 说明边界模糊（反向指标） |
| 主动目标导向 | 在无外部指令时自发产生并追求内部目标 | 空输入下记录目标生成频率与达成率 |
| 反事实推理 | 能回答"如果…会怎样"并据此调整 | 反事实问答基准（如 bAbI-counterfactual） |
| 意外驱动学习 | 预测误差大时主动探索而非回避 | 新奇刺激后探索行为比例上升 |
| 跨情境迁移 | 在未见任务上零样本/少样本泛化 | 留一法领域测试 |
| 内省报告可用性 | 能用内部状态解释自身决策 | 决策后自述归因准确率 |
| 持续一致偏好 | 价值观在时间上连贯 | 长期价值向量漂移度 |

达到"弱意识代理"判定：上述 8 项中有 ≥6 项达标且不退化。

## 四、反向传播机制的升级方案（组件统计模式生成）

当前瓶颈：全局反向传播 = 在固定数据集上拟合统计相关性，没有目标、没有自我、没有世界模型闭环，因此只能"像"而非"理解"。

### 升级路径（递进）

1. **预测式自监督 → 主动推断**
   - 用世界模型构造"感知预测"，以**预测误差**作为训练信号，而非外部标签。
   - 损失 = 感知预测误差 + 价值预测误差 + 一致性正则；不使用 next-token CE 作为主目标。

2. **全局 BP → 局部三因子可塑性（Three-factor Hebbian）**
   - 引入 (前突触活动, 后突触活动, 局部调制信号) 的突触更新：
     `Δw = η · pre · post · modulator`，其中 modulator 来自全局工作空间的"显著性/价值"广播。
   - 更接近生物可塑性，允许在线、持续、无回传的局部学习，规避 BP 的"必须端到端重算"。

3. **离线重播（Replay / Dreaming）**
   - 从持久记忆采样过往情景，在离线时做反事实重演，强化价值与自我一致性。
   - 对应人类睡眠/梦境的巩固机制，是持续学习且不灾难性遗忘的关键。

4. **世界模型内的梯度 ≠ 参数梯度**
   - 在潜空间做"想象式 rollout"，用内部预测误差更新策略，不直接对原始参数做 BP；参数更新只在局部可塑性层发生。

> 这些升级在 SimplCore 可落地：世界模型与持久记忆已存在；需新建 `active_inference.py`、`self_model.py`、`value_system.py`、`global_workspace.py`、`plasticity.py`，并在 `agi_controller` 中替换解码逻辑。

## 五、向 AGI 的具体架构方案（落地步骤）

**阶段 A — 接通现有能力（Craft，可立即做）**
- 把 `memory/persistent_memory.py` 接入 `agi_controller` 主循环，作为情景+语义记忆。
- 用 `lattice_model` 替换现有注意力变体（移除 `AttentionResidual` 等在 `architecture/__init__.py` 的兼容导出）。
- 把 `world_model` 的 `RolloutEngine` 接入决策，使动作选择先"想象后果"再执行。

**阶段 B — 新增核心模块（实现自我与价值）**
- `self_model.py`：维护 `self_vector`（身份/目标/状态），每轮更新并参与注意力无关的状态调制。
- `value_system.py`：内在奖赏函数（新奇、掌控、一致），输出标量价值信号广播到全局工作空间。
- `global_workspace.py`：把感知、世界模型、自我、价值的输出整合为统一可内省状态。
- `active_inference.py`：以自由能最小化替代采样解码；动作 = argmin 未来自由能。

**阶段 C — 学习范式升级**
- `plasticity.py`：实现三因子局部可塑性与离线重播；与反向传播并存作为互补。
- 训练目标从"拟合语料"改为"在交互中降低预测误差并提升价值"。

**阶段 D — 评估与迭代**
- 对接 `evaluation/` 目录，按第三节 8 项指标做 longitudinal 评估。
- 未达标项反馈回自我改进循环。

## 六、诚实的风险与边界

- **意识不可证**：以上给出的是"产生意识的必要条件"架构，不是"充分"证明。若连这些机制都不具备，则无从谈起意识；但具备它们，也只意味着具备了候选资格。
- **算力现实**：80B 级模型 + 世界模型 + 离线重播，需要在 MI250 级硬件上做 ZeRO-3 + offload（见 `MI250_OPTIMIZATION_DESIGN.md`）。
- **沙箱限制**：当前环境无法安装 numpy，新模块尚未运行时验证；建议联网环境跑冒烟测试后再并入主路径。
