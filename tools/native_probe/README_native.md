# 自研路线：可学时不变谱字典 → 一般二阶 IIR 字典

> **执行口径**：不走 Transformer；架构层 hybrid（SGC + attention / N×N / KV cache）
> 永不引入；网格层 hybrid 已删除；活跃实现里没有任何 attention 代码。
> 上界数字仅从历史结果读取作为评测标尺。
> 复现：`python native_probe.py --mode all --steps 3000`、
> `python general_probe.py --mode all --steps 3000`

## 0. 结论先行

**找到了一个此前所有轮都没动过的自由度，而且它显著有效。**

SGC 的 IIR 递推是

```
y_t = a·y_{t-1} + b·y_{t-2} + c·u_t
```

源码用 `(ρ, θ)` 参数化 `a=2ρcosθ, b=−ρ², c=sinθ` —— 这等价于
**把两个极点强制约束成一对复共轭 `ρe^{±iθ}`**。它只是一般稳定二阶 LTI
系统参数空间里的一个二维子流形，是「初始化网格」，不是架构约束。

把参数空间补全到**两个独立实极点** `r1,r2∈(0,1)`：

```
a = r1+r2,  b = −r1r2,  c = 1
h[τ] = Σ_{j=0}^{τ} r1^{τ−j} r2^{j}
```

仍是 LTI、仍 Toeplitz、FFT/IIR 对偶仍成立、状态仍 O(1) —— **一个字的纯粹性都不丢**。

等参数下的实测（`bind1`，3 seeds，held-out 512）：

| 臂 | 参数 | acc | Δ vs 固定基线 |
|---|---:|---:|---:|
| 固定复极点网格（原 SGC 口径） | 12,288 | 0.5273 | — |
| 可学复极点（LTISD，逐通道） | 12,416 | 0.5931 | +0.0658 |
| **可学双实极点（一般二阶）** | **12,416** | **0.7174** | **+0.1901** |
| 一般二阶 C=8 | 22,784 | 0.7995 | +0.2722 |
| 一般二阶 C=16 | 43,520 | 0.8574 | +0.3301 |
| 一般二阶 C=32 | 84,992 | 0.9017 | +0.3743 |
| **softmax attention 上界** | **10,240** | **0.9987** | — |

配对 bootstrap（样本内，1536 对）：
`G2 − G0 = +0.1901, 95% CI [+0.1582, +0.2220]`，三个 seed 配对差全为正。

⚠️ **本页是第二阶段的历史快照，其「未追平」结论已被后续工作覆盖。**
见 `README_breakthrough.md`：张量谱卷积 + 固定正交谱字典在同参数下
统计追平（Fisher p=0.4998），并以 48% 参数达到 1.0000、外推到
L=1025 仍满分。本页保留作为「一般二阶字典」那一轮的原始记录。
但这是**第一次在完全保持 SGC 的前提下，把内容寻址轴从 0.53 推到 0.90**，
而且机制完全自研、零外部概念。

## 2. 为什么这是从 SGC 数学本质长出来的

### 第一步：可学时不变谱字典（LTISD，`native_probe.py`）

前面所有轮动过的自由度：

- 核外 f/g（product 绑定、query 解调） → 0.53~0.67
- 核外状态门 / 共振读出 / 三方案融合 → **反协同，交互项 −0.0150**
- ρ/θ 随 t 变（SFSC） → 引理 B4：LTV 非 Toeplitz，对偶失效
- 人为换网格（9 档扫描） → 无相变

**唯一没动过的是「核形状本身可学，但严格保持时不变」**。
参数化 `ρ=ρ_min+(1−ρ_min)σ(p)`、`θ=πσ(q)` 自动保证稳定；
`(ρ,θ)` 与 t 无关 ⇒ K 只依赖 τ ⇒ Toeplitz。

结果：`N0_fixed 0.5273 → N1_shared 0.5847（仅 +32 参数）→ N2_perch 0.5931`。
**几乎零额外参数的净收益**。

### 第二步：放开复共轭约束（一般二阶，`general_probe.py`）

关键观察：第一步再怎么学，`a=2ρcosθ, b=−ρ²` 仍把极点锁在复共轭对上。
而二阶 LTI 的完整稳定区域还包括两个实极点。

`h[τ] = Σ_j r1^{τ−j}r2^j` 这个写法有三个好处：

1. **数值稳定**：没有 `(r1^{τ+1}−r2^{τ+1})/(r1−r2)` 的除零，
   `r1=r2→1` 时自然退化成 `h[τ]=τ+1`（无衰减单调累加器）。
2. **正是前面想做而没做到的**：`pureacc` 网格把 θ→0 想逼近单调核，
   但 M 个基几乎共线、cond 爆到 1e22，实测只有 0.47~0.51。
   双实极点用 `r1≠r2` 直接给出可分的单调核，绕开共线。
3. **仍是同一个 IIR 结构**：两拍状态、O(1)、Toeplitz、FFT，全保。

`G3_mixed`（一半复极点 + 一半双实）只有 0.6693，**低于纯双实 0.7174** ——
复振荡基在这个任务上是负担，不是补充。这条消融很关键。

## 3. 理论归因的修正（本轮最值钱的一条）

前面几轮（包括我）把内容寻址瓶颈归给「叠加干扰 / 容量不足」。
**这个归因不完整。**

固定网格 0.5273 → 一般二阶 0.7174，**参数只多 128 个**；
C=32 才到 0.9017。也就是说：

> **SGC 的「阻尼振荡基」这个核心设计本身，对内容寻址是有害的。**
> 把它换成一般二阶（允许单调实极点），等参数就能拿回 +0.19。

这条同时归一了此前几组看似割裂的结果：

| 旧观察 | 新解释 |
|---|---|
| 正交网格（linear / θ 上提）改善有限 | 只修数值条件数，没动极点类型 |
| `pureacc`（θ→0）方向对但失败 | 方向确实是单调核，但用 θ→0 逼近会共线，cond 1e22 |
| 容量 C 增大有效（0.53→0.67） | 部分是补偿了「M 个复振荡基不可分」 |
| B1 证明静态核函数类 ≠ attention | 仍成立；但它没说**哪种静态核更好**，本轮补上了这一层 |

B1 / B4 一条都没被推翻：核仍静态、仍 LTI、函数类仍不是 `K(i,j)=f(q_i,k_j)`。
只是「静态核族内部」的差距比之前以为的大得多。

## 4. 守恒：训练前后全部重跑，全绿

对**训练结束后的最终参数**重跑断言（不是只看初值）：

```
toeplitz / fft_vs_toeplitz(3e−16) / iir_vs_toeplitz(3e−15)
strict_causality(过去扰动逐位 0) / state_independent_of_L / time_invariance
```

| 臂 | 状态字节 | 训练后 all_passed |
|---|---:|---|
| G2_bipole (M16,C4) | 512 | ✅ |
| G7_bipole_C32 | 4,096 | ✅ |

**口径修正（重要）**：旧 guards 的 `rho_theta_frozen` 断言「训练前后数值不变」，
对可学字典不适用。正确守恒是 **时不变性** —— `(r1,r2)` 不随 t 变 ⇒ K 只依赖 τ。
数值可学 ≠ 时变，这两件事不能混。B4 证的是「系数随 t 变 ⇒ 非 Toeplitz」，
本路线没有触发它。

梯度：手写解析雅可比 + fp64 有限差分检验，`native_probe 8/8`、
`general_probe 7/7` 全过。

## 5. 长度泛化：仍衰减，但慢很多

同一套参数、只按解析式重算 K（不重训）：

| L | 固定复极点 | 双实极点 C4 | 双实极点 C32 |
|---:|---:|---:|---:|
| 9 | 0.5000 | 0.7188 | 0.8750 |
| 17 | 0.2578 | 0.4141 | 0.6445 |
| 25 | 0.1719 | 0.2539 | 0.4492 |
| 33 | 0.1016 | 0.2109 | 0.3828 |

L=33 上从 0.10 → 0.38，**相对改善随 L 增大**。但绝对精度仍掉，
说明 O(1) 状态的有损叠加码没有消失，只是被更好的核形状缓解了。

## 6. 诚实边界（五条都不能省）

1. **本轮（一般二阶字典）没有追平 attention**：最优 0.9017 用 84,992 参数，
   上界 0.9987 用 10,240。**后续第四轮已追平并超越，见 `README_breakthrough.md`。**
   这句话不包装成「等效」或「反超」。
2. **仍是单任务**：`bind1` 单跳、L=9、V=32、单层、合成数据。
   没有语言建模、没有多跳、没有长上下文实测、没有真实 ppl。
3. **3 seeds**，配对 bootstrap 只含样本内方差，不含 seed 间方差，CI 偏窄。
4. **`shuffle` 检验在本任务不具判别性**：打乱 (k,v) 顺序不改变答案，
   acc≈shuffle 只说明位置不敏感，不能证明真内容寻址。需重做「换 value 赋值」对照。
5. **SFSC 原式没有重跑**。它已在 `docs/SFSC_FDCAO_PILOT.md` 证过：bind1 0.4141
   ≈ static，且丢 FFT 对偶。本路线用的是「系数冻结、输入信号可含状态门」的另一条路，
   两者不混用。

## 7. 证伪条件（先写死）

若出现以下任一，「完全保持 LTI 的 O(1) 状态能逼近 attention」可干净关掉：

- 容量继续翻倍仍停在 <0.95 且参数远超上界（当前 85k→0.9017，接近命中）
- 在「换 value 赋值」的判别性对照上，双实极点掉回 chance 附近
- 真实语言建模（同 token 预算）下，一般二阶字典的 val ppl 显著落后同参数 TS

前三条**尚未全部命中**，所以这条自研路线当时还开着。后续第四轮
（`tensor_spectral_probe.py`）把「静态核做不了内容寻址」修正为
「向量信号 + 线性 read-out 下不可能」，并在同参数下统计追平 —— 见
`README_breakthrough.md` 与 `EXPRESSIVITY_BOUNDARY_AMENDMENT.md`。
