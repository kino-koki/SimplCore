# 三方案融合判别性前哨：SFSC + FD-CAO + 核外叠加码

> 任务：`bind1` 单跳内容寻址（chance 1/32，平凡基线 last_value 1/4）。
> 规模：L=9、M=16、C=4、D=32、纯 NumPy fp64 手写 BPTT、3 seeds、
> 3000 步、held-out 512、配对对照。
> 所有臂共用**同一个固定 SGC 核**，ρ/θ 全程冻结。
> 复现：`python fusion_probe.py --mode all --steps 3000`

## 0. 结论先行

**三种方案同时融入不是协同，是反协同。**

同网格（logfreq）2×2 因子分解：

| 配置（state × resonance） | acc (3 seeds) |
|---|---:|
| 00 无状态反馈、无共振（= 纯叠加码基线） | 0.5273 ± 0.0136 |
| 10 有状态反馈、无共振 | **0.5560 ± 0.0235** |
| 01 无状态反馈、有共振 | 0.5202 ± 0.0176 |
| 11 有状态反馈、有共振（全融合） | 0.5339 ± 0.0258 |

- 状态反馈主效应 **+0.0286**（唯一正贡献）
- 共振读出主效应 **−0.0072**（净负担）
- **交互项 −0.0150 → 反协同**
- 全融合比最优单臂**低 0.0221**

对照上界：带局部窗口的单层 softmax attention **0.9987**（10,240 参数）。
**全融合参数 18,944，精度差 0.465。**

## 1. 最大的伤害其实来自网格，不是融合

初版全融合用 hybrid 网格（前半近零 θ 做单调累积、后半正交 θ 做振荡），
得 0.3418，看起来像「融合彻底失败」。换成同配置 logfreq 后得 0.5339：

```
F2_full (hybrid, 11配置)  = 0.3418
F7_cell11 (logfreq, 11配置) = 0.5339
Δ = −0.1921   <-- 单一因素里最大的损失
```

原因可查：hybrid 的 Gram 条件数 **9.335e16**，前半基 θ∈[π/8192, 0.02]
几乎共线，M/2 个槽互相混叠 → 容量塌缩。这反而**印证**了主稿 §3.2
「近零 θ + 高 ρ = 数值病态 ⟺ 表征容量塌缩」——只是方向相反：
本想用单调基做寻址，结果单调基彼此不可分。

> 若不先固定网格就下结论，会把「网格选错」误判成「融合逻辑有害」。
> 这是本轮唯一靠因子分解救回来的归因。

## 2. 三个组件各自的判决

| 组件 | 净效应 | 判定 |
|---|---:|---|
| 核外叠加码（product 绑定编码 + query 解调） | 基线 0.5273 | **唯一在干活的**。去掉绑定编码（A3_noBind）直接掉到 0.1693 |
| SFSC 核外状态反馈（EMA 门控写入） | **+0.0286** | 有小幅正贡献，但代价见 §3 |
| FD-CAO 相位共振读出 | **−0.0072** | 净负担。与此前 `S8_softgate`（softmax 竞争 0.2220）同向：**读出端任何锐化/竞争机制都伤梯度** |

即：三者里只有一个在提供能力，一个几乎白送还带成本，一个主动拖后腿。
「全部堆上」自然不会赢。

## 3. 守恒断言：核保住了，训练路径没保住

对全部 SGC 臂，`sgc_fixed.guards()` 六条**全 PASS**：

```
toeplitz / fft_vs_toeplitz / iir_vs_toeplitz /
strict_causality / state_independent_of_L / rho_theta_frozen
state_bytes = 512（M=16,C=4，与 L 无关）
```

因为 ρ/θ 冻结，系数 `a=2ρcosθ, b=−ρ², c=sinθ` 与 t 无关，
**核矩阵仍 Toeplitz、FFT/IIR 对偶仍成立、状态仍 O(1)**。

⚠️ **但融合有真实代价，不能包装成零成本**：状态反馈使
`s_t = λs_{t-1} + (1−λ)y_{t-1}`，而 `u_t` 依赖 `s_t`，`y_t` 又依赖 `u_t`
——闭环使 `u_t` **内生**。因此端到端**不能一次 FFT 算完整段**，
训练必须逐步 scan，退化到 O(L·M)。

| 臂类型 | 端到端训练路径 |
|---|---|
| 无状态反馈（F1/F4/F6/B0） | 单次 FFT |
| 有状态反馈（F2/F3/F5/F7/A2/A3） | **O(L·M) scan** |

> 用 +0.0286 的精度换掉 O(L log L) 训练路径，这笔交易**不划算**。
> 注意这与引理 B4 不是同一回事：B4 证的是「ρ/θ 时变 ⇒ 核非 Toeplitz」；
> 这里核仍 Toeplitz，只是输入信号不再外生。两条口径都写清，不混用。

## 4. 与历史臂的横向量级

| 臂 | 参数 | acc |
|---|---:|---:|
| `S2_bind`（logfreq 叠加码） | 12,288 | 0.5501 |
| `S12_C8`（C=8） | 22,528 | 0.6243 |
| `S13_C16`（C=16） | 43,008 | **0.6693** |
| `F5_cell10`（本轮最优融合） | 18,432 | 0.5560 |
| `F3_full_C8`（全融合 + C=8） | 43,520 | 0.3932 |
| **`A_softmax_win`（上界）** | **10,240** | **0.9987** |

**容量能换精度（0.53→0.67），但参数翻 4 倍仍差上界 0.33；
融合三方案反而让同容量下更差（43,520 参数只有 0.3932）。**
瓶颈是叠加码的干扰，不是容量，也不是调制。

## 5. 诚实边界（三条都不能省）

1. **`shuffle` 检验在本任务下不具判别性**。打乱 (k,v) 对的顺序并不改变
   「query 指向哪个 value」的答案，所以 acc≈shuffle_acc 只说明模型对位置
   不敏感，**不能证明真正的内容寻址**。之前几轮把它当 sanity 可以，
   当证据不行。需要重做成「换 value 赋值 / 换 query 指向」的对照组。
2. **全部是 L=9、V=32、单层、合成 bind1**。没有语言建模、没有长上下文、
   没有多跳、没有 ≥5 seed 的 seed 间 CI（3 seed，误差棒偏窄）。
3. **原样 SFSC（让 ρ/θ 随状态变）没有在本轮重跑**。它已在
   `docs/SFSC_FDCAO_PILOT.md` 证过：bind1 0.4141 ≈ static 0.4160，
   且丢掉 FFT 对偶。本轮把它移到核外，正是为了绕开那条证伪。

## 6. 证伪条件（先写死，不事后圆）

若出现以下任一，则「完全保持 LTI 的 O(1) 状态能逼近 attention」这条路线
可以干净关掉：

- 同网格下全融合交互项持续为负（本轮 **−0.0150**，已命中）；
- 容量再翻一倍仍 < 0.8（本轮 43k 参数只有 0.6693，已命中）；
- 任何保持核静态的读出/写入改造，在等参数下都追不上 10k 参数的
  softmax attention 上界（本轮差 0.465，已命中）。

**三条全中。** 因此本轮的结论不是「再调一调能好」，而是：
在守住「LTI 核 + 无 N×N + 无 KV cache + O(1) 状态」四条的前提下，
内容寻址轴的上界由**叠加干扰**决定，堆机制、堆容量、堆调制都绕不过去。
