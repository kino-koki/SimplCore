# 表达力边界命题的收紧（B1′ / B4 复核）

> 本文是对 `EXPRESSIVITY_BOUNDARIES.md` 中 B1 的**适用范围修正**，由
> `tensor_spectral_probe.py` 的实测结果触发。不是新定理，是把隐含前提写清楚。
> 主稿 `SimplCore_Paper.md` 的对应段落需同步替换（列为投稿待办）。

## 1. 原 B1 的陈述与证明骨架

设单个 mixer、静态 LTI 核 `K(τ)`、**向量信号** `u_t ∈ ℝ^N`：

```
y_L = Σ_{τ} K(τ) · u_{L−τ} = A + K(0)·E(q)
```

历史摘要 `A = Σ_{τ>0} K(τ)u_{L−τ}` 与当前 query `E(q)` **可加分离**。
取两个指向不同位置的 query 相减：

```
K(0)·W·(E(q₁) − E(q₂)) = E(v_{j₁}) − E(v_{j₂})
```

左边与 value 赋值无关，右边随 value 任意变化 ⇒ 矛盾。

**适用范围（原文已声明）**：单个 mixer + 线性 read-out。
深层 + 逐位置非线性 FFN 的推广当时明确写「未在此证明」。

## 2. 本轮实测暴露的两个隐含前提

`tensor_spectral_probe.py` 在**同参数、同任务、同守恒断言**下得到 1.0000。
检查证明链，发现 B1 还额外默认了：

| 隐含前提 | B1 中的角色 | TSC 中的实际情况 |
|---|---|---|
| 信号是**向量** `u_t ∈ ℝ^N` | `y_L` 写成向量的线性叠加 | `u_t[r,n] = a_t[r]·b_t[n]` 是**外积张量** |
| read-out 是**线性**映射 | 「相减消去 A」依赖线性 | `Σ_r q_r·s_{p,r,n}` 是**缩并（双线性）** |

两条同时不成立时，「相减消去历史摘要」这一步不再有效：
`Σ_r q_r·s_{p,r,n}` 里 query 与历史信号**相乘**，不是相加。

因此 **B1 没有被推翻，是不适用**。

## 3. 收紧后的陈述

> **B1′（适用范围收紧版）**
> 若 `u_t ∈ ℝ^N` 为向量信号、`K(τ)` 为静态 LTI 核、
> `y_L = Σ_τ K(τ)u_{L−τ}`、read-out 为线性映射，
> 则单个 mixer 无法实现内容寻址（key→value 精确取回）。
>
> 证明如 §1，与原文一致。
>
> **不适用情形**（任一成立即脱离本命题）：
> (a) 信号为张量/外积形式；
> (b) read-out 含双线性缩并或乘积交互；
> (c) 多层堆叠含层间逐位置非线性；
> (d) 核随 t 变化（此时改由 B4 约束）。
>
> 本命题**不**声称「任何 O(1) 状态的 LTI 系统都做不了内容寻址」。

推论 B1.1（原「必须出现 (q,k_p) 匹配项」）**仍然成立且被实测支持**：
`T7_noK` 去掉前驱 key 编码后 acc 0.2331（chance 附近），而保留外积结构
的 `W1` 为 1.0000。匹配项确实必要 —— 只是它可以出现在**核外的缩并读出**，
不必出现在递推内部。

## 4. B4 复核：完全不受影响

B4 证明的是「ρ/θ 随 t 变 ⇒ LTV ⇒ 非 Toeplitz ⇒ FFT 对偶失效」。

TSC 的 `ρ_{p,n}` **与 t 无关**，对每个 `(r,n)` 通道都是同一个一阶递推：

```
s_{p,r,n,t} = ρ_{p,n}·s_{p,r,n,t−1} + u_t[r,n]
```

⇒ 冲激响应只依赖 τ ⇒ 核矩阵 Toeplitz ⇒ 单次 FFT / IIR 流式对偶成立。
实测（训练后最终参数）：FFT 误差 1.7e−16~3.0e−16，IIR 误差
1.7e−16~3.6e−16，过去扰动逐位 0，状态字节与 L 无关。

**因此「内容寻址」与「FFT/IIR 对偶」并不互斥。**
此前第 14 节「两者互斥」的推断是**基于 B1 过宽适用范围得出的，需撤回**。

## 5. 与已知工作的关系（不主张首次）

Zoology / Repeat After Me / Illusion of State 等早已给出「常数状态模型在
联想回忆上弱于 attention」的结论；本轮只是在**同一族内部**找到一个
此前未被枚举的函数类（张量信号 + 缩并读出）。

 novelty 收窄为三条，与 `RELATED_WORK.md` 一致：

1. **形式化收紧**：把「静态核做不到」归约到可检查的代数前提
   （向量信号 + 线性 read-out），而非笼统的「架构能力」
2. **两条边界解绑**：内容寻址 ↔ FFT 对偶 在张量信号下可同时成立
3. **落地证据链**：固定正交谱字典 + 全套守恒断言 + 判别性对照 + 长度外推

**禁用表述**：「首次证明静态卷积能做内容寻址」「推翻 B1」「超越 attention
的通用表达力」。这些都不成立。

## 6. 与线性注意力的同构张力（如实记录）

当 `ρ→1, P→1` 时：

```
S = Σ_τ u_τ = Σ_τ k_τ ⊗ v_τ
```

与线性注意力状态 `S_t = Σ_s φ(k_s)v_sᵀ` 同构。

本路线的**自研边界**：
- 没有 token 对之间的打分矩阵（无 N×N）
- 没有 softmax 归一化
- 没有随 L 增长的 KV cache
- 递推是 SGC 的 LTI 谱滤波，`ρ<1` 的衰减谱是 attention 没有的零件

但概念层的同构不隐藏。若审稿人判定「这已属于线性注意力族」，
则本工作的定位应改为「**从 SGC 第一性原理独立重新导出该结构，并给出
LTI/对偶性的严格守恒证明**」——这个贡献依然成立，只是叙事要换。
由作者自行裁定，本报告不替你下结论。
