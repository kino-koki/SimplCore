# 论文主稿改写说明（0.1-α → 0.2-β，2026-11-05）

> 本次提交**替换**根目录 `SimplCore_Paper.md`。原稿逐字节归档到
> `docs/SimplCore_Paper_v0.1alpha.md`，供口径追溯。
> 一致性自检结果见 `docs/PAPER_CONSISTENCY_CHECK.json`（26/26 PASS）。

## 为什么要改

原稿定位是「以阻尼振荡基谱卷积**替代注意力** + 能力对照」。但仓库内外的
多轮独立实验反复给出同一结论：该架构在内容寻址与生成质量轴上的劣势是
**结构性的**，不是调参可绕过的。继续维持「替代/超越」叙事会构成 overclaim，
且把最有信息量的负面结果挤到附注里。

新稿把定位改为 **「常数状态非注意力序列模型的表达力边界刻画」**：
把失败组织成边界，把边界组织成贡献。这既更准确，也更符合 ICML 对
informative negative result 与严谨性的要求。
