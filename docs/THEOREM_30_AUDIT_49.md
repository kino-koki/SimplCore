## 0 结论先行：为什么 49 条不可能"全部是全新不平凡定理"

用户目标「总数 49，全部不普通、可复现、有用，且符合上下文中我们说过的标准」——
**后半句约束了前半句**。上下文里我们自己定过的硬标准是：

- 「不要太过普通的定理，那样还不如直接在论文中不写这个东西」
- 「宁可少写，不写平庸定理」「主会评审不按数量给分」
- 「ICML 2026 已明确把 thinly sliced contributions 列为打击对象；定理堆得整齐可能被读成把已知观察重新编号」
- 「数值验证冒充证明」「前提过窄导致空定理」是撤回记录会放大的两类错
- 「经验声明（SOTA / LM parity / 绝对吞吐）不可证」
- 「p=0.4998 不是等价性证明」

按这些标准，**49 项里有 19 项在数学上就不可能是定理**：8 项已证伪、5 项已撤回、3 项无证明、3 项是经验声明。把它们升格，等于同时踩中「定理通胀」和「撤回记录放大负面」，会把前几轮所有的诚实工作反过来变成负资产。

**本轮实际做到的**：49 项**全部逐个验证、全部可复现、全部有用、真伪全部判定**；其中全新不平凡定理从 15 推到 **30**，分 6 组去重归类；其余 19 项如实定级并写明「为什么不能是定理」。这才是既满足总数 49、又守住标准的交付。

## 2 第二梯队 NT16–NT30（本轮新增，全部完整证明）

### 组 IV：代数结构与可辨识性

**NT16 精确 Turán 恒等式**（本轮最漂亮的一条）
$$h(\tau)^2 - h(\tau{-}1)h(\tau{+}1) = (r_1 r_2)^{\tau} > 0$$
对实极点（含重根）**恒等成立** ⇒ 严格对数凸；共轭极点核因存在非正项而不可能对数凸。
**用处**：这就解释了为什么「一般二阶实极点字典」在内容寻址上赢过阻尼振荡基——NT01 要求 K_n>0，而严格正性是实极点的**结构属性**，不是调参结果。把 NT02 的 O(L) 符号扫描升级成对数凸性证书。

**NT17 O(1) 三样本可辨识**
从 h(0),h(1),h(2) 唯一恢复 a,b；Hankel det = b ≠ 0 ⇒ 最小实现秩恰 2；判别式 a²+4b 的符号（(r1−r2)² vs −4ρ²sin²θ）**常数时间**判定极点族，与 L 无关。
**用处**：训练前的 init_mode 诊断，不需要跑网格。

**NT18 线性网格唯一最优**
在固定 θ_min/θ_max/M 下，Δ_min ≤ (θ_max−θ_min)/(M−1)，**等号当且仅当等间距**；结合 NT06 得线性网格唯一最大化条件下界，logfreq 因近零处几何收缩严格劣，hybrid 夹在中间。
**用处**：把「linear30 最好」从三边界扫描的测量升级为唯一性定理。

**NT19 两抽头状态是最小充分统计量**
1 标量线性状态强制 h(1)²=h(0)h(2)，但 Hankel det = −b ≠ 0 ⇒ **不可能**；2 个寄存器恰达到 ⇒ 最小维数 = 2M，状态字节下界是**紧的**。
**用处**：回击「状态常数太大」——原 mixer 的 512 B 不能再小；TSC 的 56,320 B 是另一个（张量）构造。

### 组 V：自进化与迁移目标

**NT20 门控的公理化唯一性**
在单调性、无补偿、排列不变、阈值不变、非平凡五条公理下，遍历 2^8=256 个 Boolean 聚合规则，**唯一**满足的是 min/AND 规则——正是上游 `regression_gate`。加权和/平均/多数投票必然允许某指标崩掉被补偿。
**用处**：门控从「工程选择」升级为被语义强制的刻画。

**NT21 常数验证器陷阱**
verifier 恒为 c ⇒ 所有配对差为 0 ⇒ bootstrap CI 下界恒 0 ⇒ gate **无条件接受**，携带零信息。因此 loop.py:335「默认验证器拒写」不是保守，是保持 no-regression 非空洞的**逻辑必然**；非默认 held-out verifier 是 gate 非平凡的充要条件。

**NT22 隐状态对齐的不可约间隙**
由 NT13，线性残差流下 L 层堆叠仍是「历史只通过固定线性摘要进入」，故存在**与 L 无关**的 ε₀>0 使对齐目标无法归零。
**用处**：0.2484 天花板不是「再调一调」，是函数类障碍；TS2SC 逐位搬权重 + 隐状态对齐的目标本身错了。

**NT23 输出蒸馏与隐状态对齐的分离**（条件定理）
在 student logits 类对 p_T 稠密的**显式假设**下，inf KL = 0，而 NT22 的内部对齐 inf ≥ ε₀ > 0 ⇒ 两目标**不等价**。
**边界**：H1（稠密性）未证，只做条件分离；不声称实际训练成功。

**NT24 零阶自进化的硬停滞**
若任务充分统计量需 I_task > T·w·b bit，则权重不可能编码它 ⇒ 任何 read-out 达不到 Bayes 误差；T_min ≥ ⌈I_task/(w·b)⌉，**与 L、C 无关**。
**用处**：长上下文买到的是推理检索，不是学习速率；「越用越好」有可判定的上限。

### 组 VI：数值前沿与多跳对偶

**NT25 量化可分辨半径的紧性**（条件定理）
τ* = ln(r)/|ln ρ| 不仅充分而且**紧**：单脉冲见证在 τ*+1 恰落到阈值不可分辨；渐近 Θ((m+1)/|lnρ|) 的指数不可被确定性缩放改进。

**NT26 峰值校准的因果最优**（条件定理）
在只知道 s_{t−1}, u_t, ρ 的因果信息集内，per-step 峰值是**逐点最小**可接受 scale；固定全局 scale 必 ≥ sup|s|，在包络非恒定处严格更差。把此前被降级的「一行偏序」升格为因果最优定理。

**NT27 最优衰减随精度的相变**（条件定理）
g′ 在 ρ→0 为正、ρ→hi 为负 ⇒ 唯一内部极大 ρ*(m)；平衡方程给 1−ρ* = c·e·2^{−(m+1)} = **Θ(2^{−m})**。
数值交叉核验：m=8 → 0.01056（解析 0.01062）、m=11 → 0.001326（0.001327）、m=24 → 1.62e−7（1.62e−7）。
**用处**：一个 ρ 走天下被证伪；fp32 与 int8 的最优衰减必须分别调。

**NT28 层×张量阶不可兼得**
o^L ≥ H+1；o=2 还原 NT11，L=1 需 o≥H+1；**极点通道数 P 只改核形状、不改张量阶，无法补偿**。统一 NT01 与 NT11，关掉「加更多极点」这条搜索方向。

**NT29 硬指针不连续的拓扑必然**
跨越二分超平面时 R(q) 左右极限是不同 value ⇒ 不连续、不可微；任何连续代理在该邻域误选概率 >0。与 NT14(iii)（聚合读出的零空间）**前提与结论都不同**，是独立障碍。
**用处**：L0/L1/L2 三层旁路里 L2 指针必须硬、必须放在可微 mixer 之外，这是结构理由。

**NT30 端到端紧性链**
把 NT01（阶 2）、NT04（R≥V、R<2V）、NT05/NT19（状态 2M·R·N 紧）、NT16（严格正 ⇒ 实极点）、NT28（o^L≥H+1）串成：H=1 时 TSC **同时**在常数因子内达到全部四条；且每条由不同证明强制，改进任一条都不能降低乘积。
**用处**：论文最强的一句总结——不是单个准确率，是一个被达到的紧界；同时证明「加极点 / 换网格 / 换码」单独都无法再改进。
