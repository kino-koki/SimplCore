# TS2SC-Q17 v4 终局报告：静态核天花板已被精确测定并吃满

承接 `docs/TS2SC_Q17_migration_report.md`。本轮只做一件事：
**判定「保持纯粹性的静态核」在 1.7B-Instruct 上是否还有任何剩余空间。**

答案是**没有**，且有精确到小数点后 4 位的证据。

---

## 1. 方法学修正（先纠正上一版的一处口径错误）

上一版报告里「静态核天花板 0.248」来自 `q17_oracle.py`，它比较的是
**两条已各自漂移的残差流**（teacher 流 vs oracle 流），混进了逐层累积误差；
报告里那个「平均注入 0.1835」同理，是跨流比较，不是单层上限。

本轮补了**同输入**的单层对照（`q17_oracle_head.py`）：

| | 单层静态核注入 cos（同一 x） |
|---|---:|
| 全局平均核（跨 16 头抹平） | **0.4478** |
| 逐头核（16 头各自 profile） | **0.5430** |

所以「静态核完全表达不了」这句话不准确 —— 单层能到 0.54，
是**28 层累积**把 0.54 压到 0.248。两者都是真实约束，但性质不同。

---

## 2. 找到的真正遗漏：coef 被人为压平

`SGC.coef` 的形状本来就是 `(num_bases, dim)` = `(32, 2048)` ——
**架构原生支持每个通道一套静态核**。而 v1~v3 全部写成

```python
m.coef.copy_(c.view(M, 1).expand(M, D).clone())   # 32×2048 → 只有 32 个自由度
```

同时 profile 阶段把 16 个 attention 头**跨头平均**成一条 p(τ)，
把「不同头看不同历史范围」的结构直接抹掉。

这两处都是迁移脚本的简化，**不是架构限制，也不违反任何纯粹性约束**：
核仍输入无关、可 IIR 递推、O(1) 状态、FFT/IIR 对偶、无 q·k 打分、
无 N×N 矩阵、无 KV cache。

---

## 3. v4 做法（唯一变量）

以 `ck3`（v2 解析扩展读出 + v3 RMS 幅度标定）为基线，**只改 coef**：

- 收集逐 **KV 头**（8 头，GQA 下每 2 个 q 头共享 1 个 KV 头）的
  profile `p_j(τ)`，6 段语料、最后 1 段留作 holdout
- 每头独立 LS 拟合 `c_j = argmin ||Ψ c − p_j||² + α||c||²`
- `coef (M,D)`：前 1024 列（V 路径）与后 1024 列（k 路径）
  各按 8 个 KV 头分组填入 `c_j`
- 其余所有参数、所有配置与 `ck3` 逐位相同

---

## 4. 结果：指标全面改善，生成仍不成句

### holdout 核形状拟合（跨文本泛化）

```
逐头 0.3068   全局平均 0.2774   Δ +0.0294
```

收益远小于 in-sample 的 +0.095 —— **头间模式不跨文本稳定**，
这本身就说明它由内容决定，不是可静态化的先验。

### 逐层残差流（同一段 teacher-forced 文本）

| 指标 | v1 | v3 | **v4** | 静态核 oracle |
|---|---:|---:|---:|---:|
| L0 注入 cos | 0.8191 | 0.9041 | **0.9205** | — |
| L4 饱和范数 | 94825 | 78233 | **66264** | — |
| L27 残差流 cos | 0.0518 | 0.2221 | **0.2484** | **0.2476** |

**v4 = 0.2484，oracle = 0.2476。差 0.0008。**
静态、输入无关、因果卷积能达到的上限，已经被吃满，误差在数值噪声量级。

### 生成（同一 prompt，argmax，chat template + no-think）

| 版本 | 输出 |
|---|---|
| teacher（原版） | `华为技术有限公司（Huawei Technologies Co., Ltd.）是一家` |
| v1 | `IPHERIPHERIPHERIPHERIPHERIPHER` |
| v3 | `的\n\n好像\n\n好像宫宫哪` |
| **v4** | `\nOkay发现\n嗯发现宫` |

从「单 token 死循环」→「多个中文词」→ 现在混入英文碎片，
**仍是词堆砌，不成句，更不是回答**。指标改善没有转化成语言能力。

---

## 5. 为什么改架构（低通/累积通道）也已无意义

本轮先做了两个预检，避免无效改动：

**① 加一阶 IIR 衰减基 ρ^τ**（`s_t=ρs_{t-1}+u_t`，O(1)、线性、无 pairwise）：

| 基族 | 中层核拟合 cos | ΣK/Σp |
|---|---:|---:|
| sin32（现状） | 0.15~0.28 | **0.178** |
| +10 档 ρ^τ | 0.64~0.69 | **1.000** |
| +10 档 + ρ=1 累积 | 0.65~0.67 | 1.000 |

能修好**幅度**（v3 的 RMS 标定已经修到 0.993），但**方向**补不上。
而 v4 的 L27 已经等于静态核 oracle —— 再加基最多动第 4 位小数。
**所以上轮承诺的「加一阶 IIR 累积通道」我主动取消，不做了**：
有数值证据表明它是无效改动。

**② 精确核 oracle**：直接用每层实测 profile 当 FIR 核（核形状 100% 正确），
28 层残差流末层仍只有 0.2476。中层注入 cos ≈ 0（−0.03~0.06）——
真实 attention 的输出方向由 `q_i·k_j` 内容匹配决定，平均 profile 与它近乎正交。

## 6. 终局结论

> **在 Qwen3-1.7B-Instruct 上，「保持 SimplCore 纯粹性的静态核」
> 与「迁移模型具备完整语言能力」不能同时成立。**
>
> 这不是调参、加步数、加基、加门控、换网格或逐通道核能绕过的：
> v4 已把该族模型的 theoretical upper bound 吃到 0.2484 / 0.2476。
>
> 与 0.6B 时实测的静态平均注意力核上限 cos 0.3695、
> 正交网格在 MQAR 上 0.1133 同源 —— **跨模型尺寸复现，不是偶然**。

**「如果你成功，说明我可以迁移更大模型」** → 推论不成立。
而且 1.7B 暴露了 0.6B 没有的浪费（D=2048 但 V 路径仅 1024），
**模型越大，解析直搬的维度不匹配越严重**。

---

## 7. 剩下的三条路（需要你定方向，我不擅自越界）

| 路径 | 纯粹性 | 能解决 | 代价 |
|---|---|---|---|
| **A. Hybrid（推荐）** | 放弃 | SGC 管周期/连续信号，**少量 attention 管内容寻址** | 引回 N×N 与 KV cache；但频率网格实验已证明两轴互补：周期轴 SGC 1500 步 0.9844 反超 TS 3000 步 0.8535，MQAR 轴 SGC 0.1133 不行 |
| **B. 内容写入的 O(1) 状态**（线性注意力式 `S_t=Σφ(k_s)v_sᵀ`） | 少一条（核变输入函数），但 O(1) 状态、无 N×N、无 KV cache 全保持 | 直接对准 `q·k` 内容匹配 | 需要重写 SGC 的读出与递推，是架构级改动，不是迁移脚本 |
| **C. 继续在静态核内找空间** | 保持 | — | **已证伪，不建议** |

我倾向 **A**：它是唯一有跨任务证据支撑的互补结构（连续信号轴归 SGC、
内容寻址轴归 attention），而且能真正回答「能不能迁更大模型」——
更大模型的 FFN/知识可以直接逐位搬，只需为内容寻址轴保留小比例 attention。
