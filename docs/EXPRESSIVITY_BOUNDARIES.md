## 0. 符号与设定

设输入嵌入序列 $u_1,\dots,u_L\in\mathbb{R}^d$。SGC 的**静态核** mixer 输出

$$
y_t \;=\; \sum_{\tau=0}^{t-1} K(\tau)\,u_{t-\tau},
\qquad K(\tau)=\rho^\tau\sin((\tau+1)\theta)\ \text{（或 } M \text{ 个基的线性组合）}
$$

其中 $K$ **只依赖相对延迟 $\tau$，与输入序列内容无关**（线性时不变 / LTI）。
整段形式等价于 Toeplitz（循环近似）卷积，可用单次 FFT 计算。

对照：softmax attention 的输出为

$$
y_i=\sum_{j\le i}\frac{\exp(q_i^\top k_j/\sqrt{d})}{\sum_{j'\le i}\exp(q_i^\top k_{j'}/\sqrt{d})}\,v_j,
$$

其系数 $K(i,j)$ 依赖**每一对** $(i,j)$ 的内容。

## 1. 命题 B1（严格证明）：可加分离使内容寻址不可达

### 1.1 任务定义

**内容寻址任务 $\mathcal{T}$**：序列形如
$[\,k_1,v_1,k_2,v_2,\dots,k_n,v_n,\ q\,]$，其中 $k_p$ 是 key 嵌入、
$v_p$ 是 value 嵌入、$q$ 是 query。令 $j(q)\in\{1,\dots,n\}$ 为 $q$ 所指向的
key 下标，要求输出 $y_L = v_{j(q)}$。假设映射 $q\mapsto j(q)$ **至少取两个不同值**
（否则任务退化为常数输出，不构成检索）。

假设：
- (A1) key 嵌入 $\{k_p\}$ 线性无关（正交 one-hot 是最干净的实现）；
- (A2) value 嵌入 $\{e_v\}$ 线性无关，且 $v_p$ 可独立取值（词表大小 $\ge2$）；
- (A3) read-out 为线性 $W$（SGC mixer 的输出经线性 `coef` 读出即是此情形）。

### 1.2 命题

> **命题 B1** 在 (A1)–(A3) 下，不存在与输入无关的核 $K(\cdot)$ 与线性 $W$，
> 使得静态核模型在 $\mathcal{T}$ 上对**所有** $(q,\{v_p\})$ 都输出 $v_{j(q)}$。

### 1.3 证明

把 $y_L$ 拆成「历史摘要」与「当前 query 项」：

$$
y_L \;=\; \underbrace{\sum_{\tau=1}^{L-1}K(\tau)\,u_{L-\tau}}_{\displaystyle A}\;+\;\underbrace{K(0)\,E(q)}_{\displaystyle B(q)} .
$$

**关键观察**：$A$ 是所有历史 token 的**固定线性组合**，系数
$(K(1),\dots,K(L-1))$ 与 $q$ 完全无关；$q$ 只能经由 $B(q)=K(0)E(q)$
这一项进入。因此静态核输出对 $q$ 的依赖是**可加分离**的：

$$
W y_L \;=\; \underbrace{W A}_{\text{与 } q \text{ 无关}} \;+\; \underbrace{K(0)\,W E(q)}_{\text{只依赖 } q}.
$$

取两个 query $q_1,q_2$ 使 $j(q_1)=j_1\ne j_2=j(q_2)$。
**固定**所有 key 与位置，只让 value 赋值可变。若模型正确，则

$$
WA + K(0)WE(q_1) = E(v_{j_1}),\qquad
WA + K(0)WE(q_2) = E(v_{j_2}).
$$

两式相减，$WA$ 消去：

$$
K(0)\,W\big(E(q_1)-E(q_2)\big) \;=\; E(v_{j_1}) - E(v_{j_2}). \tag{★}
$$

左边只依赖 $q_1,q_2$ 与固定参数，**与 value 赋值无关**；
右边由 (A2) 可随 $v_{j_1},v_{j_2}$ 的取值任意变化。
取两组不同 value 赋值使右边取两个不同值，即与 (★) 矛盾。$\square$

### 1.4 推论：所有修复路线为何必然汇合

> **推论 B1.1** 要在 $\mathcal{T}$ 上成功，输出必须含有形如
> $\sum_p \langle\phi(q),\psi(k_p)\rangle\,v_p$ 的**成对匹配项**，
> 即 $q$ 与每个历史 key 的乘积交互，再对对应 value 加权。

理由：可加分离的输出中，历史摘要 $A$ 与 $q$ 无关；要让它随 $q$ 选择不同的
$v_p$，唯一途径是让每个历史位置的贡献系数依赖 $(q,k_p)$——这需要
$q$ 与 $k_p$ 的双线性（或更高阶）交互，并且 value 必须与 key 分离读出。

这一条把此前所有路线统一进同一个理论框架：

| 路线 | 形式 | 是否含 $(q,k_p)$ 匹配 |
|---|---|---|
| 静态 SGC（加长记忆 / 调 ρ / 正交网格 / 逐通道 coef） | $A$ 固定 | ❌ |
| 输入相关门控（selective / SFSC） | 门控只依赖当前 token 或状态摘要 | ❌（见 §1.5） |
| 线性注意力 / CAS $S_t=\sum_s\varphi(k_s)v_s^\top$ | $\phi(q)^\top S_t$ | ✅ |
| FD-CAO 相位共振 | $\sum_s\cos(\theta-\phi_s)v_s$ | ✅（频域槽版本） |
| softmax attention / hybrid | $\mathrm{softmax}(q^\top k)v$ | ✅ |

**这解释了为什么**「加长记忆」「加门控」「换网格」在实测中都无法补齐内容寻址，
也解释了为什么 R1 定容绑定、CAS、FD-CAO、hybrid 都必然走向「某种内容寻址状态」——
不是巧合，是 B1 的函数类后果。

> ⚠️ **推论 B1.1 不是定理**。它给出了必要条件的一个自然形式，
> 但「任意高阶交互都必须归约为成对匹配」这一步未在此证明。
> 本文只把它作为解释性框架使用。

### 1.5 命题的适用范围（必须写明）

- **严格成立的范围**：单个静态核 mixer + 线性 read-out（SGC 层的数学本体）。
- **未严格推广到**：含逐位置非线性 FFN 的深层堆叠。逐位置非线性作用在
  $A$ 上可产生历史 token **之间**的交叉项；本证明未排除这类交互间接实现
  内容寻址的可能性。
- 因此本文**不声称**「任何深度的 SGC 网络都做不了内容寻址」。
  实证上（v4 吃满 oracle、生成仍不成句、MQAR 0.1133）与已知理论工作
  （§5）都支持这个推广方向，但形式化证明仍列为待补（主稿 §7.1(6)）。
- 同理，输入相关门控（selective SSM / SFSC）**不受 B1 直接约束**，
  它们受的是 §2 的 B4（对偶失效）约束。两条边界管的是不同东西，不要混用。

## 2. 引理 B4（严格证明）：时变参数破坏 FFT 对偶

### 2.1 设定

SFSC 把 $\rho,\theta$ 改为状态反馈 $\rho_t,\theta_t$，递推仍为二阶 IIR：

$$
y_t = a_t\,y_{t-1} + b_t\,y_{t-2} + c_t\,u_t,
\qquad a_t=2\rho_t\cos\theta_t,\quad b_t=-\rho_t^2,\quad c_t=\sin\theta_t .
$$

这是**线性时变（LTV）**系统：线性于 $u$，但系数随 $t$ 变。

### 2.2 引理

> **引理 B4** 若存在 $s$ 使 $a_{s+1}c_s \ne a_{s+2}c_{s+1}$，则冲激响应
> $K(t,s)$ **不是** $t-s$ 的函数，即核矩阵非 Toeplitz；从而不存在单一
> 频域滤波器 $\hat K$ 可表达该算子，FFT/IIR 双形式对偶不成立。

### 2.3 证明

直接计算单位脉冲响应。在 $s$ 时刻注入 $u_s=1$、其余为 0：

$$
K(s,s)=c_s,\qquad K(s{+}1,s)=a_{s+1}c_s,\qquad
K(s{+}2,s)=(a_{s+2}a_{s+1}+b_{s+2})\,c_s .
$$

若 $K(t,s)$ 只依赖 $t-s$（Toeplitz），则同一延迟 $\tau=1$ 的两个不同
绝对时刻必须相等：

$$
K(s{+}1,s)=K(s{+}2,s{+}1)
\;\Longleftrightarrow\;
a_{s+1}c_s = a_{s+2}c_{s+1}.
$$

SFSC 的 $\rho_t,\theta_t$ 由状态 EMA 调制，随输入序列与 $t$ 变化，
一般不满足该等式，故非 Toeplitz。

整段 FFT 路径计算的是 $\mathrm{IFFT}(\hat K\cdot\hat u)$，它要求
$K$ 平移不变（Toeplitz / 循环卷积）。非 Toeplitz ⇒ 不存在这样的单一
$\hat K$；用「平均核」代替只能得到近似。$\square$

### 2.4 数值确认 `[R]`

`tools/sfsc_fdcao_probe/results/toeplitz.json`：

```
toeplitz_mean_abs_deviation = 17.67     is_toeplitz = false
fft_avg_kernel_rel_error    = 0.9720
K[5,0:6] = [-10.4376, 8.4158, 13.6868, -11.9257, 0.081, 15.9999]
```

### 2.5 推论：互斥性

> **推论 B4.1** 在 SGC 家族内，「保持 FFT/IIR 双形式对偶与 $O(L\log L)$
> 训练路径」与「核随上下文变化」互斥。要保对偶，$\rho,\theta$ 必须与 $t$
> 无关（回到静态核，受 B1 约束）；要核随上下文变，必须放弃对偶，退到
> $O(LM)$ 递推 scan（与 `srf` 同档）。

**这不是新发现**：S5（arXiv:2208.04933）已指出「卷积操作要求系统时不变」，
Mamba（arXiv:2312.00752）明确「选择性破坏纯卷积视图，必须用并行前缀扫描」。
本文的新增是把这一已知事实**在 SGC 具体二阶递推上写成可检查的引理 +
数值确认**，并把它与 B1 并列为同一条架构约束的两个后果（主稿 §6.3）。

## 3. B2 / B3 的准确定位（**不是定理**）

主稿 §4.2–4.3 的 B2（逐层累积）与 B3（静态核天花板）是**实证观察 +
有限样本估计量**，不是形式化上界定理。必须写明三点：

1. $0.2476$ 是「用每层实测 profile 当 FIR 核」的 oracle 在
   **28 层、特定语料、特定模型**上的残差流余弦，是一个估计量；
2. v4 的 $0.2484$ 略**高于**它，正说明它不是硬上界；
3. 因此「天花板被吃满」的准确表述是：
   **在该 oracle 定义下，可优化的余量在数值噪声量级**，
   不是「已证明该族模型的表达力上界为 0.2476」。

B2 的 $0.4478 / 0.5430$ 单层对照同理，是同输入单层测量，
不构成跨层的形式化分解定理。

> 形式化工作仍待补：把「静态核函数类无法表示内容寻址」从单层推广到
> 深层非线性网络，以及给出残差流余弦上界的严格陈述。见主稿 §7.1(6)。

## 4. 数值注脚（可复现）

`tools/boundary_probe/b1_additive_separation.py`（纯 NumPy，秒级，无 torch）

刻意取**最有利**设置使下界更强：key = 正交 one-hot、value = 共享随机单位向量、
query 恰为第 $j$ 个 key、目标输出 $v_j$。四类对照在同一套共享嵌入上
train / held-out 分离评估：

| 对照 | 形式 | held-out L2（V=8..64, d=16..64，12 组） |
|---|---|---|
| `static` | **任意固定线性映射**作用于拼接的整段 $u$（比 $K(\tau)$ 更宽松 = 乐观上界） | $0.907 \sim 5.693$，恒 $>0.5$ |
| `naive_bilin` | $\mathrm{mean}_s(q\odot u_s)$，有乘积但抹平位置 | $0.934 \sim 1.001$，恒 $>0.5$ |
| `matched` | $\sum_p (q\cdot k_p)v_p$（key/value 分离 + 成对匹配） | $\approx 0$（10/12 组为 0，最坏 $2.5\times10^{-3}$） |
| 解析玩具 | $c_0(E(q_1)-E(q_2))$ 固定 vs $E(v_{j_1})-E(v_{j_2})$ 任意 | 矛盾成立，最大差 $1.81$ |

`static` 在 $V=64,d=64$ 的 $5.69$ 是 ridge 在 $256$ 样本 / $576$ 维下
数值不适定造成的放大，不影响结论方向（仍 $>0.5$）。

**结论**：静态线性读出（连比静态核更宽松的版本）在最有利设置下都解不出
内容寻址；仅加乘积交互但抹平位置也失败；只有 $(q,k_p)$ 成对匹配加权塌到 0。
这与 B1 的推论一致。

## 5. 与已知理论工作的关系（**不主张首次发现**）

> 这一节是投稿时的护身符。若把 B1 / B4 写成「我们首次证明」，
> reviewer 会立即用下列工作驳回。

| 已知结果 | 与本文边界的关系 |
|---|---|
| Zoology / MQAR（arXiv:2312.04927）：门控卷积与 attention 的 **82% ppl 差距可由联想回忆解释**；hybrid 弥合 97.4% | B1 的**实证先驱**。本文的 MQAR 劣势、R1 追平、§6.4 分工依据都与之同向 |
| Repeat After Me（arXiv:2402.01032）：GSSM 无法复制超过其隐状态比特数的串，理论 + 实验 | 「固定大小状态在检索/复制上弱于 attention」的**理论先驱** |
| The Illusion of State in State-Space Models（arXiv:2404.08819, ICML 2024）：S4/Mamba 的表达力限于 $\mathsf{TC}^0$ | 常数状态模型表达力受限的**复杂度类先驱** |
| S5（arXiv:2208.04933）：卷积视图要求时不变系统 | B4 的**已知事实来源** |
| Mamba（arXiv:2312.00752）：选择性破坏纯卷积视图，需并行前缀扫描 | B4 的**已知工程结论来源** |
| Mamba-2 / SSD（arXiv:2405.21060）：SSM 与一类线性注意力形式等价 | 支撑 B1.1 推论（内容寻址状态与 attention 同源） |

**因此本文的理论贡献是「重述 + 绑定 + 落地」，不是「首次发现」**：

1. **形式化收紧**：把「静态模型回忆能力弱」归约到 SGC 输出的一个
   可检查代数性质（可加分离），给出几行可验证的证明（§1）；
   把「选择性破坏卷积」写成 SGC 二阶递推上的引理（§2）。
2. **绑定**：把两条边界绑到**同一条架构约束**上，得到互斥性结论
   （保对偶 ⟺ 核静态 ⟹ 受 B1 约束），见主稿 §6.3。
   这是单看任何一个已知结果都得不到的。
3. **落地证据链**：在一个具体架构上把理论、精确核 oracle、
   $0.2484$ 天花板、47 万参数三臂、SFSC/FD-CAO 六臂连成可复现的一条链。
4. **附带**：频率网格塌缩的「数值病态 ⟺ 表征容量塌缩」双重解释（主稿 §3.2）。

**novelty 的可辩护表述**：
> 「我们把已知的『静态/常数状态模型在内容寻址上受限』与『选择性破坏卷积视图』
> 两条结论，在一个具体算子上形式化并绑定到同一条架构约束，给出
> 对偶性与上下文相关核的互斥性，并用可复现实验把边界钉到数值上。」

**不可辩护的表述**（一律不用）：
「首次证明静态卷积做不了内容寻址」「发现时变核没有 FFT 对偶」
「证明该族模型表达力上界为 0.2476」。
