# 端侧极限训练报告：1.085 亿参数 @ 2 GB（2026-10-31）

> **归档注记（0.1-α）**：外部独立实验的原始记录。**Adafactor 已落地**
> （`training/train/optim.py` 的 `Adafactor` + CLI `--optimizer adafactor`，
> 守护测试 `test_adafactor.py`：状态 512× 压缩、收敛方向、update clipping、
> CLI 契约）；状态字节对账注记见文末（48B = E_t 口径差，Paper §3 勘误）。

## 一、怎么把 1 亿参数塞进 2 GB

AdamW 要 16 B/参数 → 1.085 亿参数 1.74 GB，直接爆。改用 **Adafactor**
（factored 二阶矩，只存行/列因子）：

```
108.5M × (4 权重 + 4 梯度) ≈ 0.87 GB   ← 可行
```

再加梯度检查点 + micro-batch=1 + 梯度累积 + 语料缓存。

**2 GB 机器的实际上限 = 1.085 亿参数**（dim=768 / 12 层 / M=64）；
tuan-350m 会被内核 OOM 杀掉。

## 三、四项验证

| 验证 | 结果 |
|------|------|
| A 学习 | ✅ train −63.8%，val −43.8% |
| B O(1) 状态 | ✅ **4,829,184 B（4.61 MiB），300 步全程唯一值** |
| C 双形式对偶 | ✅ max\|Δ\| = 2.384e-05 @ L=96（低于 4e-5 守护阈值） |
| D 长程稳定 | ✅ L=1024 logits 全部有限 |

**B 是本次最有价值的**：在**真实训练循环**里（不是玩具调用）、跨 300 步、
跨 batch 变化，状态字节严格恒定——**定理 3 的工程级证据**。
C 证明训练不会破坏对偶性。

**0.1-α 对账注记**：4,829,184 B 对应**不含 E_t 标量**的口径
（$4(2MD+(K{-}1)D)\times12$）；`streaming_state_bytes()` 实测同值——
Paper §3 曾写"实现按含 +1 计"与实现不符，已勘误（差 48 B = 12 层 × 4 B，
即每层 1 个 fp32 标量 $E_t$ 的口径归属，现为**实现不含**）。

## 四、必须诚实说：生成仍是噪声

```
'def '    -> '= `st 12.netorateteng, sorer, chentit stenten = aror...'
'这是一个' -> '谱全局卷积、SGComper statelor 164, st 10 16)"] = st sercelo...'
```

loss 降 63.8% 但生成是噪声——**不矛盾，原因已定位**：
60,800 tokens / 1.085 亿参数 = **0.00056 tok/param**。Chinchilla 最优是 20，
即需要 21.7 亿 tokens——我们跑了它的 **1/35700**。

差四个数量级。但注意第二个样本生成出了"**谱全局卷积**"——仓库原文的
真实术语。模型确实学到了语料的统计结构，只是远未到能连贯成句。

**对照微型世界实验**（45.7 万参数 / 组合泛化成立）：那个能成是因为任务
封闭 + 数据密度够。三个实验结论一致：**架构的学习能力没问题（loss 都
真实下降），生成质量完全由 token/参数比决定**。

## 五、给项目的意义

1. **150M 在 2 GB 上可训**——端侧/边缘部署叙事的正面证据；
2. **O(1) 状态在真实训练循环被证实**——比玩具调用强得多；
3. **Adafactor 可行**——低成本上规模的路径，内存受限时不必硬上 AdamW
   （0.1-α 注记：已落地 `--optimizer adafactor`）。

## 诚实边界

训练被沙箱 OOM 中断多次，靠 checkpoint 续跑完成（每轮重启重放 warmup，
对最终 loss 有轻微影响）；**350M 本机无法训练**。
