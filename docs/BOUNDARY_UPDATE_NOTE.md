## 新增的理论结果

### 命题 B1（严格证明）
静态核输出 $y_L = A + K(0)E(q)$，其中历史摘要 $A=\sum_{\tau>0}K(\tau)u_{L-\tau}$
与 query **可加分离**。取两个指向不同位置的 query，正确输出要求

$$K(0)W(E(q_1)-E(q_2)) = E(v_{j_1})-E(v_{j_2}),$$

左边与 value 赋值无关、右边随 value 任意变化 → 矛盾。
前提：key 线性无关、value 可独立取值、线性 read-out。
**适用范围严格限定在单个 mixer + 线性 read-out**，
向深层 + 逐位置非线性 FFN 的推广明确标为「未在此证明」。

**推论 B1.1（解释性框架，非定理）**：要打破分离必须引入
$\sum_p\langle\phi(q),\psi(k_p)\rangle v_p$。这统一解释了为何
加长记忆 / 调 ρ / 正交网格 / 逐通道 coef / 输入门控全都不解决问题，
而 CAS、FD-CAO、线性注意力、attention、hybrid 必然汇合到内容寻址状态。

### 引理 B4（严格证明）
LTV 二阶递推 $K(s{+}1,s)=a_{s+1}c_s$、$K(s{+}2,s{+}1)=a_{s+2}c_{s+1}$，
Toeplitz 要求二者相等，状态反馈一般不成立 → 非 Toeplitz → 无单一 $\hat K$
→ FFT 对偶失效。数值确认 `fft_avg_kernel_rel_error=0.972`。
