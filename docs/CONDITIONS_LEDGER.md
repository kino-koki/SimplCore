# 智能条件账本（120B 主干 + 2B token 上下文）（120B 主干 + 2B token 上下文）

> 模块：`simplcore/core/conditions_ledger.py` · CLI：
> `python -m simplcore.core.conditions_ledger`（`--json` 机器可读）
> preset：`tuan-120b`（dim 8192 / L 118 / M 256 / mixer=srf / v1.2 增强全开，
> 解析参数 119.55B）

## 1. 立场

智能不从 mixer 里"长"出来——mixer 决定成本曲线；智能条件来自
**系统能力组合**。本设计把五项条件做成架构的**原生属性**（每项绑定
仓库内已存在的机制模块），并给出条件"开始可能成立"的规模阈值账本。

## 2. 五项原生条件（机制就绪 5/5，能力达标 0/5——诚实口径）

| ID | 条件 | 机制/模块 | 最大缺口 |
|----|------|-----------|----------|
| C1 | 经验即上下文 | O(1) IIR 流式状态；`stream_bytes` 与视野无关（断言验证） | 状态是有损压缩，精确召回信息论边界仍在 |
| C2 | 可塑性-稳定性分离 | 冻结主干 + 可学分支，`envlearn.WeightBudget` 硬拒超额 | 蒸馏质量未大规模验证 |
| C3 | 验证器门控写权 | 独立 verifier + no-regression gate + 逐位回滚 | 硬验证器目前以代码域为主 |
| C4 | 三级记忆巩固 | 工作/情景/语义 + `sleep`；`smm.SimplModelMemory` | 情景→语义规则未过 1e8 token 长周期 |
| C5 | 自主目标与工具 | `IterativeRefiner` 循环 + tool 钩子 + 自生成课程 | **最大缺口：自主行为能力为零** |

## 3. 为什么阈值定在 120B + 2B token 视野

工程假设（可证伪）：能力涌现随规模跨阈值出现；2B token 的**持续经验流**
使在线学习量首次与预训练预算（20×N）同量级，C2/C3/C4 闭环才有统计意义。
120B 是把假设买进"涌现观察常见区间"的保守定价。

**C1 断言（2³¹ token 视野实测）**：流式状态 **1.855 GiB**（tuan-120b，batch=1，fp32，118 层）与视野无关（恒真）；
推理 FLOPs/token 为常数；同视野 Transformer KV cache ≈ **8 PB**（结构性
不可行）。这是"2B 上下文"只有在这个架构上才谈得起的结构性原因。

## 4. 120B 档账本（纯解析）

- 每 token 训练 FLOPs ≈ 718G；Chinchilla 预算 2.39T tokens；
  总计 **1.72e24 FLOPs**（≈ 40× GPT-3 量级）。
- 显存下限：**14× MI250**（ZeRO-3 均分 1.91 TiB 训练态）。
- 时限需求（MFU=0.25）：30 天 → **≥11252 卡**；60 天 → 5626；
  90 天 → 3751。**单卡 MI250 不可训练此档位**——这是账本结论，不是悲观情绪。

## 5. 可证伪验收协议（A1–A3）

- A1 持续改进：闭环启用后固定保留集逐月非劣 + 至少一项显著提升
- A2 不失忆：每轮写权 no-regression gate 通过率 ≥ 预训练基线
- A3 自主性：自生成课程完成率 ≥ 随机课程对照
- 若 120B+2B 闭环在 A1–A3 无显著差异，"120B+2B 开始即可能"假设**被证伪**。

## 6. 诚实边界

本模块输出"条件就绪度"，不是"智能已诞生"。诞生与否只能由 A1–A3
行为验收判定；C5 的自主目标生成当前是控制流骨架——机制正确 ≠ 质量达标。
