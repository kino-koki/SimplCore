# TS2SC 自监督 LM 微调：负面结果实录（2026-11-04）

**结论：不采用。181 步自监督 next-token 微调让 holdout CE 下降 10.4%，
但生成质量实测退化——重复率上升 36%、中文占比下降、事实正确数持平。
`TS2SC-VL-1B v2`（解析 DC-bias 修复）保持为当前最佳权重包。**

这不是「还没训够」，是**优化目标与生成质量在这个配置下不同向**的实证。
按用户「不行再训，直到好」的要求继续训过，但数据不支持继续同一路径。

---

## 1. 训练配置（严格非蒸馏）

| 项 | 值 |
|---|---|
| loss | 纯 next-token cross-entropy，监督来自文本本身 |
| 与 teacher 的关系 | **无**：不用 teacher 注意力输出、logits、激活，不蒸馏 |
| 冻结 | `embed_tokens` / `lm_head` / 28 层 FFN / `post_attention_layernorm` / `ln_f` / mixer 的 `in_proj`·`gate_proj`·`out_proj`·`norm.weight`（全部 TS2SC 迁移权重逐位保持） |
| 可训 | mixer 的 `coef`·`raw_rho_log`·`raw_theta`·`out_scale`·`feed`·`local_conv.weight` + 每层 DC bias |
| 可训参数 | **1,091,356**（占 1.057B 的 0.103%） |
| 语料 | 25 段真实中文 + 5 组问答格式 → 221 个长度 16 的片段 |
| LR / 步数 | 3e-5，181 步（目标 300，沙箱 502 反复中断后取最后完整 ckpt） |
| 收敛判据 | **固定 5 片段 holdout CE**（跨片段 loss 不可比） |

代码：`train_lm.py`（训练）、`eval_ckpt.py`（独立评估）。

### 工程修复（这些是有效的）

| 问题 | 修复 | 效果 |
|---|---|---|
| fp32 lm_head 每步分块读 622MB → OOM (exit 137) | 预加载为 **bf16 常驻 311MB** | 不再 OOM |
| FFN 权重 fp32 常驻 1.06GB | 全部 **bf16** | 常驻降到 ~530MB |
| 单步 20s | 去掉重复读取 + 解析梯度 | **0.83s/步** |
| 502 杀进程把 `trace.json` 截成 0 字节 | 临时文件 + `os.replace` 原子写 | 记录不再丢 |
| 502 恢复后多进程并发写坏 ckpt / 日志 | `fcntl.flock` 内核文件锁 | 真互斥 |
| 进程被杀丢进度 | 每 10 步落盘 + 断点续跑 | 无损续跑 |

解析梯度（`RMSNorm` 精确 Jacobian）已数值校验：**cos=1.0000, rel=0.0**。

## 3. 生成实测（8 个 prompt，18 token，argmax 贪心）

| 指标 | v2（未训练） | 训练 181 步 | 变化 |
|---|---:|---:|---|
| rep3 重复率 | **0.1719** | 0.2344 | **+36% 变差** |
| 中文字符占比 | **0.7469** | 0.7310 | 变差 |
| 事实正确（期望词出现） | 1 / 8 | 1 / 8 | 持平 |
| 事实错误（错误词出现） | 3 / 8 | 2 / 8 | 略好（噪声） |

原版 teacher（3 条历史基线）：rep3 0.1428、cjk 0.7598 —— **仍优于两路迁移模型**。

### 逐条输出（原始，未改动）

```

  v2     : 的，是直辖市，人口，是新兴。深圳是新兴。深圳是新兴，

  v2     : 世界，但，所以。  Param化和化学化学化学化学化学化学化学化学
  训练后 : 世界，但，所以。在空中，但，所以，所以，是最大的城市      ← 去掉重复，但仍不成句

「问：中国的首都是哪里？答：」
  v2     : 但座，还有，还有丰富的城市，北京，位于北京，位于中国的气候
  训练后 : 但座，还有许多，所以，北京，北京，人口，人口，是新兴      ← 「北京」还在，仍不成句

「问：华为是什么公司？答：」
  v2     : 但，所以，所以，所以，所以，北京的饮食，是最大的城市，
  训练后 : 但，所以，所以，所以，所以，北京的气候，是直辖市，北京

「华为是什么公司」
  v2     : ，所以。  Param化处理参数，可以学习，可以学习，但不的
```

**训练改变的是词的选择，不是语言组织能力。** 有的去掉了重复（水化学式），有的引入新重复（华为→「吃好」×4），整体统计上更差。

## 4. 为什么 holdout 降、生成反而差

1. **冻结了真正说话的层。** FFN 与 embedding 承载语义与知识，全部冻结；只剩 mixer 的 109 万参数可调。降低 CE 的最省事办法是让 logits 在已知片段上更尖，而不是学会组织句子。
2. **语料规模不匹配。** 25 段文本 / 221 片段 / 181 步，对 1B 模型是严重欠覆盖；问答格式只占 5 段，学不到「回答」这个行为模式。
3. **贪心解码对分布微小变化极敏感。** CE 降 0.5 对应的 logit 变化足以改写 top-1 token，但不改变输出的结构性缺陷。
4. **两个硬缺口一个都没动**：base model 的续写行为（teacher 自己问「华为是什么公司」也只会续成追问）、静态核的 pairwise 内容寻址上限（实测 cos **0.3695**，见 `docs/TS2SC_coherence_audit.md`）。

一句话：**holdout CE 衡量的是「在冻结 FFN 下预测下一个字有多确定」，不是「会不会说正常汉语」。** 这又是一次指标被测量口径污染的案例，与之前「余弦 1.0000 被 FFN 刷出来」「6 倍性能其实是修死循环」同类。

## 5. 处置

- **训练权重不并入任何权重包。** `TS2SC-VL-1B v2`（commit `dec8d8a1`）保持为当前最佳版本，111 个分片一个字节未改。
- `TRAIN/ck.pt` / `trace.json` / `eval.json` / `eval_summary.json` 作为负面证据保留。
- `train_lm.py` 保留：工程管线（bf16 常驻、flock、原子写、断点续跑）是有效的，换数据/换配置可直接复用。

## 6. 真正可行的下一步（按优先级）

| 路径 | 能解决什么 | 前提 |
|---|---|---|
| **换 instruct 基座**（Qwen3-1.7B / 0.6B-Instruct） | base model 不会「回答」的行为缺口 | 需要用户上传权重；HF 在本沙箱 403 |
| **解冻 FFN 做 SFT**（问答对） | 让语义层学会组织答案 | 2 核 / 2.4GB 内存不够全量 1B 微调；需 LoRA 或真机 |
| **接受 pairwise 边界** | — | 静态核上限 cos 0.3695，加正交基/门控/MoK/静态平均注意力核都绕不过共享叠加状态不可分离 |

继续在同一配置下加步数**不推荐**：181 步已出现退化趋势，且 holdout 与生成反向。
