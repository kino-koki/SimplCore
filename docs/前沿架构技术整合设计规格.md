## 第 0 章 文档说明与证据分级

### 0.1 本文档的定位

本文档是架构新增模块的**开发依据**。它不做文献综述，而是将近三个月内公开的、具备工程可吸收性的前沿技术，重组为一套可实现的模块规格。每一项被采纳的技术都给出：机制、数学形式、量化结论、可复用组件、失效模式、证据等级。

### 0.2 证据分级（全文强制遵守）

| 等级 | 定义 | 使用方式 |
|---|---|---|
| **A-已验证** | 有可复现实验、明确任务、量化结果，且在被引用论文的设置内成立 | 可直接纳入设计 |
| **B-工程验证** | 实验结果成立，但规模、任务或硬件覆盖有限 | 纳入设计，但需在目标骨干上复测 |
| **C-有条件验证** | 需模型具备特定性质（如固定点收敛、预算严格匹配）才可复现 | 设为可开关模块，附带启用前提 |
| **D-提案/假说** | 理论分析、小规模实证、未经充分独立验证，或仅有 FLOPs 而无实测延迟 | 列为探索项，不得作为交付承诺 |

**红线：不同等级的技术不得在文档中被混为一谈，也不得把某一等级的结果外推到其未覆盖的范围。**

### 0.3 三条贯穿全文的判断原则

1. **不同量纲的结果不可横比。** 扩散损失效率、ARC 成本帕累托、MLE 奖牌率、Terminal-Bench 分数、NIAH 召回率分属不同目标，任何把它们汇总成单一排行榜的做法都是无效的。
2. **理论 FLOPs 与理论 KV 存储不能替代端到端测量。** 所有效率结论都必须在目标硬件上补测 TTFT、TPOT、吞吐、并发数与能耗。
3. **可解码不等于因果。** 潜空间中间态"可读""状态缓慢变化""删除后性能下降"都只是推理存在的证据，不是模型通过该链路得出结论的证据。

## 第 1 章 总体判断：近三个月前沿的六条主线

### 1.1 主线一：混合主干已经胜出

Transformer 没有失去"精确检索与全局交互"的位置，但正在失去"处理每一层、每一个 token"的默认地位。本季度最一致、最可工程化的架构信号，是让低成本序列算子承担长程状态维护和大部分计算，只在必要深度插入全局注意力。

代表证据：

- **Kimi K3**（Moonshot AI，2026-07-27，arXiv:2607.24653）：3:1 混合，每四个块中三个为线性状态块（KDA），后接一个全局注意力块（Gated MLA）。93 层由 69 个 KDA 层与 24 个 Gated MLA 层构成。总参数 2.8T，每 token 激活 104B，896 个路由专家中每 token 激活 16 个，原生视觉，上下文 1,048,576 token。量化为 MXFP4 权重 + MXFP8 激活。
- **Qwen3-Next-80B-A3B**：75% 线性状态 + 25% 门控注意力，512 专家中每 token 激活 10 路由 + 1 共享。官方称训练 GPU 小时不足 Qwen3-32B 的 10%，>32K 上下文推理吞吐提升超 10 倍。
- **Chimera**（Adobe Research 等，2026-07-25，arXiv:2607.28611）：把同一套混合机制扩展到文本/图像/视频统一光栅流，并给出可跨尺度迁移的超参数规则。

**结论：不要在每一层使用全注意力。**

### 1.2 主线二：循环深度推理进入工程化阶段

近三个月的进展不是"多跑几遍"，而是分别解决了五类问题：轨迹漂移、计算预算分配、MoE 路径坍缩、KV 成本、读取器失效。

- **DeepLoop**（2026-07）：残差分支必须按**参数访问次数**而非名义层数缩放，给出 α=(2N)^{1/2}、β=(8N)^{-1/2}。
- **InfiLoop**（2026-10-08）：把循环失效命名为 latent overthinking，用 loop-native residual 解决。7M 模型在 Sudoku-Extreme 达 97.9%，超 20,000 步仍提升。
- **SMELT**（2026-08-10）：严格匹配每 token FLOPs、参数和 KV 后，双循环节省 6.8—18.0% 训练 FLOPs。这是目前最可信的"循环深度具备架构增益"证据。
- **HLA / ResidualQuant / 终端 KV 共享**：三条可叠加的循环 KV 压缩路线。

### 1.3 主线三：自进化最先发生在控制面，而非基座权重

当前最强的递归自改进证据，都是"冻结模型、改变可审计控制面"的受限递归——改进对象是程序进化算子、记忆模块、探索策略或 harness 代码，而非不受约束地反复修改全部权重。

- **Recuris**（2026-08，arXiv:2608.24876）：从结构化轨迹定位故障组件的准确率 **64.8%**，而从任务最终结果直接归因只有 **13.0%**。这个对比是本季度最有诊断价值的数字之一。
- **AIDE²**（2026-08）：8 天自主运行产生 100 节点轨迹树，7 个改进被接受，私有评分由 0.703 升至 0.778。
- **Frontis-MA1 / OpenMLE**（2026-07-30）：NatureBench Lite 对照显示，框架固定换模型使 Match-SOTA 从 50% 升至 70%；模型固定换框架使 Match-SOTA 从 20% 升至 50%。**训练与搜索是互补而非二选一。**

### 1.4 主线四：世界模型从"会生成未来"转向"能在想象中稳定决策"

- **Koopman Dreamer**（2026-07-22，arXiv:2607.19719）：用有界谱半径约束动力学，DeepMind Control Suite 9 项中 8 项优于 DreamerV3；无人机导航目标成功率由 53.8% 升至 73.8%。
- **RoboJEPA**（2026-10-07，arXiv:2610.10515）：首次给出真实多本体机器人想象误差随计算的**二阶幂律** E(C) ≈ aC^{-b} + E_∞。
- **Dyna-2**（Dyna Robotics，2026-08）：1000 小时至 100 万小时人类第一视角视频的跨本体扩展律，归一化性能 20% → 53%；蒸馏后视频采样 10,203ms → 110ms。
- **The Planning Limits of Latent World Models**（2026-09-30）：纯想象仅在 23% 片段可靠成功，MPC 提至 30%，想象到完整目标 47%，**使用附近专家子目标达 76%**。

### 1.5 主线五：记忆从向量池转向有生命周期、可撤销、有类型的结构

- **TEPA**（2026-08，arXiv:2608.07429）：完整反转实验 50 种子下，append-only 与 last-write-wins 均为 0.210，无记忆 0.309，**TEPA 0.950**。
- **STRATA**（2026-10-14，arXiv:2610.19386）：三层经验图 + 类型化边，注入记忆比最占上下文基线少 44%，ScienceWorld 负迁移场景 78.7 → 96.7。
- **SIx Harness**（2026-08）：78,933 次 hook 调用记录 85 次失败，最终 20 天无失败。**记忆系统的瓶颈已从检索算法转向可靠性工程。**

### 1.6 主线六：长上下文从"扩大窗口"转向"分层召回 + 分级压缩"

- **LongCat Sparse Attention**（2026-08-03，arXiv:2608.01662）：1M 上下文可训练，1M prefill 最高加速 3.60×。但其**索引器在 1M 上下文可占每层时延约 90%**。
- **HySparse2**（2026-09-22，arXiv:2609.26368）：80B-A3B 上 1M-token FP8 KV 降至 2.69GB，prefill FLOPs 降至 Hybrid SWA 的 19.9%。但质量评测最长仅到 256K。
- **PuzzleKV**（2026-08-24，arXiv:2608.23843）：约 60% KV 存储保持 96%+ 性能，叠量化至 18.7% 仍保持 93%+。

### 1.7 一个必须纠正的认知

**"约 1GB HBM"必须按四本账核算。** HySparse2 的 2.69GB 是 **KV**，不是系统总显存。同一 80B 模型还有总权重、路由表、激活、All-to-All 缓冲、索引与运行时内存。若采用 W4A8 或 W4A16，80B 权重量级本身至少约 40GB。

> 较现实的 1GB 目标是**单序列工作集**（KV + 状态 + 索引），且不应把模型权重、稀疏索引和激活计入目标后再宣称达成。任何 1GB 结论都必须注明：精度、层数、KV 头数、页大小、压缩等级、batch、序列长度、模型总参、是否含权重。

### 2.2 双周期运行

**清醒期（在线）**
```
输入 → L0 混合主干编码 → L2 索引召回 → L1 循环深度推理
     → L3 记忆精准注入 → L7 校验 → 输出
     → 落库：会话轨迹 / 校验三元组 / 记忆操作日志
```

**睡眠期（离线）**
```
触发检查 → L6 四阶段巩固 → 候选产物（记忆条目 / 适配器 / 主干增量）
        → L7 门禁 → 晋升或丢弃 → L3 老化淘汰
```

### 2.3 骨干能力契约（既有系统提供）

本架构要求骨干满足以下接口指标。**本文档不规定其实现方式。**

| 编号 | 契约项 | 指标要求 |
|---|---|---|
| **C-1** | 原生上下文长度 | ≥ 1,048,576 tokens，支持按 2 的幂次继续扩展 |
| **C-2** | 单序列工作集 HBM | ≤ 1 GB（1M 上下文满载，含 KV + 状态 + 索引，不含模型权重） |
| **C-3** | 长程保持率 | 1M 上下文中首部信息检索正确率衰减 ≤ 5% |
| **C-4** | 参数规模 | ≥ 1T 量级，训练后冻结 |
| **C-5** | 模态支持 | 文本、图像、音频、视频、结构化数据统一表征 |

> 关于 C-3 的重要限定：**极低长程遗忘无法由单个位置编码或固定状态保证。** 线性状态混合体更受益于长上下文继续预训练，滑动窗口混合体更擅长免训练外推；即使 query-dependent 的分块状态仍会衰减，幂律核只能让尾部慢于指数而非消除遗忘。因此架构必须保留可回退的原始 token/页、精确锚点、动态索引与多页候选，并把召回损失、压缩损失与生成错误**分别监控**。

### 2.4 校验子系统契约（既有系统提供）

| 编号 | 契约项 | 要求 |
|---|---|---|
| **V-1** | 校验粒度 | 推理链内逐阶段校验，非仅输出后置校验 |
| **V-2** | 权威比对 | 可检索外部权威源并与内部判断比对，输出分歧度标量 |
| **V-3** | 日志输出 | 必须输出校验三元组（见 §6.2），落库供 CE 使用 |
| **V-4** | 可关闭性 | 允许在评测模式下关闭，用于对照实验 |

## 第 3 章 L0：混合计算主干

### 3.1 四层分工原则

推荐首版采用"状态—局部—全局—容量"四层分工：

1. **模态感知局部算子**（局部卷积/扫描）维护时空连续性
2. **线性状态层**（KDA / Gated DeltaNet 族）维护长程轨迹
3. **少量全局注意力**（每 3—8 层插入一次，压缩 KV）负责跨时空检索、反事实查询与多模态对齐
4. **稀疏 MoE** 扩展动态、任务和环境容量

### 3.2 线性状态层：delta-rule 状态更新

KDA 不是另一种 softmax 注意力，而是带通道遗忘门的 delta-rule 状态更新：

```
S_t = (I − β_t k_t k_t^T) · Diag(α_t) · S_{t−1} + β_t k_t v_t^T
õ_t = S_t^T q_t
```

- `S`：关联记忆状态
- `α`：控制状态保留（逐通道向量门控，非标量）
- `β`：控制当前 token 的写入强度

**本质**：用一次状态外积更新替代所有历史键值的全 pairwise 注意力。

**可吸收形式**（因果 delta 更新）：

```
S_t = S_{t−1} − β_t · S_{t−1} k_t k_t^T + β_t k_t v_t^T + forget/normalization
```

**为什么它适合无限轨迹而又优于纯固定状态**：比"保留所有 KV"更适合长程，比纯固定状态更容易遗忘噪声。逐通道门控让不同记忆维度按内容决定保留。

**关键限定**：每个 head 的状态秩和维数仍有限。对密集随机 needle、多针冲突、强干扰任务，状态会被连续写入覆盖。**不能按 1M 上下文窗口声称永久记忆。**

### 3.3 分块仿射状态（HLA 式增强）

HLA（2026-10-05，arXiv:2610.05842）将完整 chunk 表示为**精确仿射状态转移**，并用 query-dependent gate 组合历史转移与恒等映射：

- chunk representative 的 self-attentive pooling 产生路由门
- effective-support 正则鼓励稀疏路由

量化结果（Qwen3.5 0.8B—9B）：LongBench-V2 最高 +5.57 点，RULER 最高 +3.97 点。1.3B 从零训练于 4K 上下文时，32K RULER 增益由 4K 的 0.83 点增至 4.22 点。

**证据等级：B-工程验证。** 4K 训练到 32K 仍是短窗口外推，不等于 1M 可可靠外推。

**可复用组件**：chunked affine state、代表 token 池化、内容相关门控、分块并行 scan、gate 正则。
**风险**：代表 token 变成信息瓶颈；query 对旧 chunk 的门控缺乏长距监督时，可能系统性忽略低频证据。

### 3.4 幂律长记忆核（FRAC）

FRAC 以多时标 log-spaced 指数模态逼近**幂律**长记忆：

- 训练与 prefill 可做分块并行
- 解码保持有界状态
- 1.3B FineWeb-Edu 预训练、4K→64K NIAH 测试显示遗忘曲线比 GDN/Mamba 更平缓

**定位：它是"慢遗忘核"，不是无限记忆。** 对需要"精确键值关联且不能衰减"的 needle 并非天然更优；有限模态只是选定时间范围内的近似，超参 α、模态数与时标网格均需重调。

**推荐用法**：FRAC 负责连续历史摘要，索引保留原始关键 token/页——**组合使用，而非单独替换主干**。

### 3.5 跨深度旁路：Attention Residuals

AttnRes 允许每个模块从 **embedding、当前块和前序块**选择性取回表示，而非只依赖逐层残差链。

**工程价值**：对长视频、跨模态轨迹和世界状态，这相当于增加一条跨深度的旁路——深层决策可以重新读取早期观测特征，而不必等待它们经数十层非线性压缩。它使信息访问成为**可学习的选择**，而非固定拓扑。

这一机制可直接用于外部记忆注入：把记忆表示作为一层"可取回的前序块"，由门控决定是否读取。

### 3.6 统一多模态光栅流与 NoPE

Chimera 把文本、图像、视频 token 放入**统一光栅顺序流**，且**不使用传统位置嵌入**。三种机制互补：

- KDA：O(N) 维护长上下文状态
- MLA：直接全局交互
- 模态感知短卷积：局部时空上下文
- 稀疏 MoE：额外容量，只增加激活计算

KDA 在该工作中的单层形式：

```
KDA(x)_t = W_o [ σ(W_gate(x_t)) ⊙ RMSNorm(S_t^T q_t) ]
```

全局 MLA 把直接键与压缩潜在键拼接，使局部扫描与少量高保真关联通道并存。

**量化结果**：11B 总参数 / 2B 激活的 Chimera，稠密主干是匹配全注意力 Wan-2.1-2B 基线的 1.7 倍计算效率，完整系统达 7.3 倍；训练 5 秒片段后可在不做长度微调的情况下外推到 30 秒视频，末五秒 FID 仅下降 6.5%。

**解读限制**：损失效率与端到端效率的主要比较对象是全注意力扩散主干；FID 末段退化 6.5% 说明长外推并非无损。**不应把架构效率直接解释为生成质量绝对领先。**

### 3.7 异构架构的跨尺度超参数迁移：HeteroP

大多数混合主干把每个模块单独手调，导致小模型调好的结构无法可靠放大。Chimera 的 HeteroP 根据张量的**功能 fan-in** 与**网络深度**分别计算宽度和深度缩放系数：

```
m_W = fan-in(W) / fan-in(W^(0))
m_L = n_blk / n_blk^(0)
P_W = T_{ρ(W)}( h̄ ; m_W, m_L )
```

其中 h̄ 包含方差、学习率、初始化和归一化相关参数，T 按张量类型选择变换。由此得到**有原则的、而非网格搜索得到的超参数家族**。

**这是本季度对多模态架构直接价值最高的可迁移资产。** 自研系统应优先复现 HeteroP 与模块混合方式，而不是照搬具体层比——后者需根据具体视觉、音频、动作模态重做 ablation。

### 3.8 谱约束动力学（跨层通用原则）

Koopman Dreamer 提供了可迁移到任何状态传播模块的**三条设计原则**：

1. **约束谱半径**：把状态在每一步究竟被保留、衰减、旋转还是放大，变成可优化对象
2. **区分全局动作与状态依赖动作**
3. **让随机状态承担局部修正，而非主导长期传播**

确定性状态更新：

```
z^d_{t+1} = K z^d_t + B a_t + (z^d_t ⊗ a_t)^T L + σ(z_t, a_t)
```

- `K`：由二维旋转—缩放块组成，每个模态的谱半径有界
- `B`：全局线性动作效应
- `L`：低秩双线性状态—动作耦合

**关键发现**：谱半径敏感性实验显示，**最大收缩并非最优**——过度收缩会消除未来控制所需的信息。因此潜状态不能为了稳定性无差别压缩，稳定与信息保留必须共同优化。

### 3.9 稀疏 MoE 的稳定化

极端稀疏（如 896 专家激活 16）下会出现 expert collapse、数值尖峰与负载不均。K3 使用的手段：归一化、SiTU-GLU、Quantile Balancing。

**可直接复用的组件清单**：
1. per-token top-k 路由
2. 共享专家承担通用残差
3. 容量因子与队列
4. 量化感知训练与高效 EP
5. 基于统计分位数的负载归一化

**证据边界**：这些手段在 K3 内部报告中被描述，外部独立复现仍需补充不同路由噪声、故障专家移除与长期灾难性遗忘的评估。

### 3.10 MoE 效率：从专家 FLOPs 转向路由与容量

| 技术 | 机制 | 核心指标 | 失效模式 |
|---|---|---|---|
| **MoRE**（2026-09-28，arXiv:2609.36301） | 路由分解为秩 r 表示，成本 O((h+M)r)，fused Triton kernel | 匹配激活 FLOPs 下允许约 Θ(h/r) 倍更多专家 | 低秩 router 牺牲选择细粒度；负载证明基于 Gaussian memorization 模型 |
| **CIPHER-MoE**（2026-10-05，arXiv:2610.05744） | affinity-aware expert-to-token filtering + 显式容量控制，不改变 token Top-K | Top-1 专家负载最高降 64.9pt，训练加速 1.10—1.94× | 解决训练热点，不解决 decode KV |
| **MoE-Prism**（2026-08-10） | 按共激活神经元拆子专家，重构 top-k 路由接口 | 路由档位 +4×，离线吞吐最高 +33.9% | 子专家数量上升导致调度碎片与冷启动 |

**必须同时调度的五个容量项**：HBM 权重大小、活跃专家 GEMM、KV 页、All-to-All 发送缓冲、kernel workspace。

> **对 1GB 目标的关键提醒**：若活跃专家权重本身超过预算，仅压缩 KV 无用。此时必须转向端侧极小 MoE、分层存储或 prefill/decode 分离，**不能用"稀疏激活"掩盖总参驻留需求**。

### 3.11 量化

**DRQ**（2026-10-08，arXiv:2610.11226）的关键发现：仅最小化权重量化重建损失**未必改善下游任务**，同一校准集上甚至可能变差。它只在既有量化格点内优化**最坏激活分布下**的整型码，不改量化参数和推理算子，兼容 AWQ、GPTQ、ParoQuant 及 MoE。

**部署要求**：分布鲁棒校准、按层/通道验证、KV 与权重分开调，并监控长上下文检索退化，**不能只看困惑度**。

## 第 4 章 L1：循环深度推理核

### 4.1 三类循环范式

| 范式 | 结构 | 价值 | 代价 |
|---|---|---|---|
| **固定轮数深度堆叠** | 存 K 个物理块，执行 R 轮，展开深度 N=KR | 参数复用 | 循环顺序执行，不能直接享有并行深度 |
| **状态反馈循环** | 每 token 合并编码器输出与前一 token 最终解码状态 | 状态路径随序列增长，每 token 成本固定 | 反馈频率与并行度的权衡 |
| **自适应循环** | 逐 token 停止、逐轮步长、门控聚合、深度异步读取 | 计算按需分配 | 门控失准、批内深度不一致导致调度困难 |

**建议：固定轮数作为生产基线，自适应轮数作为优化项，而非前提条件。** 固定预算便于性能预算、吞吐预测与容错；纯自适应虽能节省简单 token，但可能因门控失准、KV 依赖或批内不同深度造成调度困难。

### 4.2 骨架结构

```
输入表征 / 问题状态
   ↓
Prelude：一次性编码
   ↓
Core block：注意力 + FFN / MoE  ←─┐
   ↓                              │
Core block：同一权重第 r 轮  ←─────┤ 最多 R 轮
   ↓                              │
   └──→ 稳定性与停止控制器 ────────┘
            ↓ 收敛/预算耗尽
     内容感知聚合
            ↓
     Coda：答案头 / 工具调用 / 解码
```

**稳定控制、退出读取、缓存管理、最终读出必须作为显式接口**，不应依赖单次退出概率。

### 4.3 残差缩放：DeepLoop 规则（必做）

标准 DeepNorm 的 L^{-1/2} 依赖"不同层写入近似不相关"这一假设。**循环时同一物理块的更新在同一状态路径上反复累积，形成正相关的 tied-depth 效应**，该假设失效。

DeepLoop 实施方案：

```
x_{i+1} = Norm( α x_i + f_j(x_i; φ_j) )

α = (2N)^{1/2}
β = (8N)^{-1/2}
```

其中 N 为**展开深度**（N = K·R），不是名义层数。

**量化结果**（GPT-2 small/medium，FineWeb-Edu 50BT）：R=1 时与基线持平；R=5 时 GPT-2 small 验证损失最多下降 0.023 nats；R=7 时零样本平均准确率 +0.43 点、单样本 +0.58 点。

**这不是免费午餐**——它证明的是残差尺度应按**参数访问次数**而非名义层数缩放。

**证据等级：B-工程验证。** 作者承认只在一个尺度和循环深度完整扫描，更坏情况访问对齐未必每次达到。

### 4.4 通用循环更新式与状态稳定

推荐实现形式：

```
h_{r+1} = γ_r · h_r + LoopBlock_r( x_in , h_r , s_r )
```

- `γ_r`：受约束的 carry / 遗忘因子
- `x_in`：**每轮重新注入**，防止信号漂移
- `s_r`：循环索引、归一化深度、路由特征、收敛指标

**监控项**（训练期必须采集）：
- 每轮隐状态 RMS
- 跨轮状态余弦相似度
- 残差增量范数
- 注意力输出 / Value 范数
- 路由器熵与 top-k 负载
- 退出概率熵
- 梯度 RMS 及跨轮梯度对齐

**训练 warmup 要求**：应同时 warmup **循环数、学习率和 carry**，而不是先固定最深循环再调整学习率。

### 4.5 谱裕度：稳定性预算的正确定义

LayerNorm as Implicit Gain Control（arXiv:2607.10681）给出关键洞察：pre-LN 通过激活尺度逆耦合局部 Lipschitz，使循环 Jacobian **非正态**。此时即使算子范数大于 1，谱半径仍可能小于 1。

**稳定预算应取谱裕度 1 − ρ_spec，而非算子范数界。**

小规模实验（d=8—32，2—4 头，序列长度 1—32）显示：carry 接近 1 时谱裕度被消耗，少数初始化完全不收敛；**carry 主要是稳定器而非深度记忆**。

**实现建议**：
- 初始化和训练中对随机输入做矩阵无关幂迭代，估计跨循环 Jacobian 主谱半径
- 以滑动窗口平均 ρ_spec < 1 − ε 作为 warmup / 回滚条件
- 对大更新做 trust region

**证据等级：D-提案/小规模。** "LayerNorm 占主导"不能直接当作 1B+ 骨干的规范。更稳妥的工程实践是**同时保留** LayerNorm/RMSNorm、carry、残差缩放、梯度裁剪、KL/状态漂移约束，并逐项消融。

### 4.6 潜状态保护：loop-native residual（InfiLoop）

**失效模式命名：latent overthinking**——带噪声的新更新覆盖正确的中间推导，甚至撤销已完成的解；早期循环的错误通过长程传播破坏状态后，后续轮次很难恢复。

InfiLoop 的方案是保持**聚合路径与当前推理路径分离**：

```
s_{r+1} = a_r ⊙ s_r + b_r ⊙ m_r
m_{r+1} = f_θ( x , h_{r+1} , c_{r+1} )
a_r     = decay_controller( content , loop_position )
b_r     = update_gate( content , uncertainty , progress )
```

- `s`：长期聚合状态
- `m`：新循环更新
- `a`：历史保留
- `b`：新信息接受度

这比"每轮残差直接相加"更接近**带内容的 leaky integration**。

**实现要点**：
- 保持聚合路径与当前推理路径分离
- 使用 FP32 累加关键状态
- **衰减不可强制为 1**
- 内容相似度需同时考虑 query、循环索引和候选答案差异
- 批处理中为每个样本维护独立状态长度
- 采用精确流式递归，使持久聚合内存**不随循环数增长**

**量化结果**：7M 模型 Sudoku-Extreme 97.9% 精确率，ARC-AGI-2 13.6% pass@2，超过 20,000 次有效步骤后仍持续提高。

**证据等级：B-工程验证（小模型）。** 强度在结构化搜索/约束满足，不应解读为通用开放域能力。生产系统仍需设置最大轮数、无进展保护、状态检查点、预算熔断。

### 4.7 潜空间监督：三个训练工具

**① LoopMTP —— 多 token 预测软对齐**

循环 T 次，把第 t 轮隐状态与"未来 t 个 token"的输出词嵌入软对齐（第 1 轮无对齐目标）；再用内容条件门控聚合全部循环输出，并加入使各轮不被饿死的 ponder 正则。

- 260M 模型 / 6.8B token：相对非循环基线平均准确率最高 +8.1%，训练稳定到 15 轮
- 数学版 GSM8K：19.03%（非循环基线 7.05%）

**价值**：给无监督循环提供方向性监督。代价只是余弦距离，不需为每轮增加完整词表头，可随轮数扩展。
**限制**：可能诱导模型把未来 token 语义压缩进隐状态，而不一定完成逐步验证。**应作为辅助目标，主损失仍是最终答案、状态一致性、停止质量与任务约束。**

**② WIDER —— 子空间坍缩正则**

把潜空间失效定义为**子空间坍缩**而非单纯范数增长。估计每条潜轨迹的主导方向，惩罚状态对该方向的投影：

```
L_div = λ Σ_r ‖ Π_{u_r}(h_r) ‖²
```

其中 u_r 是批次/轨迹估计的主方向，Π 是向该方向的投影。

**调参要求**：与归一化、残差缩放并列，权重应通过验证损失、最终任务、跨轮距离三目标调参，**避免为了高秩而破坏语义方向**。

**③ LLoCoT —— 并行潜槽精炼**

把潜推理从串行潜 token 生成改成**少量并行潜槽的迭代精炼**：共享块执行若干轮，所有槽共同根据提示和工作区状态更新；随后从精炼状态预测分布，并行采样潜 token，再由自回归解码器生成答案。

- HumanEval / MBPP：相对显式 Reasoning SFT 相近准确率
- 首 token 时间减少约 **36×**
- 推理阶段延迟减少约 **42×**
- 端到端吞吐 +9.2%

**定位**：证明潜空间适合作为"并行草稿工作台"。但若任务依赖严格串行证明步骤，仍需串行循环轴。

### 4.8 潜链因果性：必须做的评测，不能做的假设

《Does Latent Chain-of-Thought Actually Reason?》（2026-10，arXiv:2610.21182v1）在 21 个模型—任务配置下结合 chain deletion、内容替换、探针和轨迹分析，结论是：

> **高准确率、可读的中间态并不证明模型通过潜链得到答案。** 某些潜推理方法在逻辑任务上经常在开始循环前就已携带答案，删除潜链几乎不改变预测。逐步监督能产生有序布局并增加因果依赖，但有时内容替换仍不改变答案。

**工程要求**：
1. 维护两类读出——最终任务读出 g_T(h_{1:T})，以及**可审计状态探针**（低秩地把少量工作槽映射为可读 CoT，仅用于评测与失败诊断，不得默认作为外部监控）
2. 潜链必须分类报告：占位符 / 叠加坍缩 / 步骤相关，分别给出"是否依赖"与"编码了什么"
3. 若部署要求可解释，应在最终答案后**再产生一次性显式校验轨迹**
4. 若要求极致延迟，应接受潜状态本身不完全可读，并通过外部校验器约束可靠性

### 4.9 自适应计算：轨迹—读出必须联合设计

现代 ACT 形式：每 token/状态维护继续概率 p_r，第 r 轮累积生存概率 S_r = Π_{j<r}(1 − p_j)；损失使用 S_r · ℓ_r 加上 ponder cost τ · Σ_r p_r。

**关键诊断**（Adaptive Depth in Looped Transformers，2026-07，arXiv:2607.20519）：

> 若同一分布既作训练期深度损失权重又作推理停止规则，**退出选择和轨迹形成会纠缠在一起**。

对比结果：
- **固定先验深度监督**不依赖输入相关停止策略，却能塑造难度感知轨迹，其中间状态暴露出有用的停止信号
- 简单**事后置信度读取**常匹配或优于学习门
- 把门拟合到冻结轨迹后，主要失败源是**联合门训练诱导的轨迹**，而非门本身表达不足
- Ouro 的预训练 ponder 门有竞争力但**不均匀 Pareto 最优**；退出深度下降确实转化为实测延迟节省

**必须做的消融：冻结轨迹消融。**

1. 训练三个并行的停止相关头：答案熵、最终状态一致性、下一轮预期边际收益
2. 开发集上先冻结主干比较这些头
3. 再冻结生成轨迹，比较线性、MLP、阈值和贝叶斯规则
4. **只有当差异持续存在，才联合训练门控**

退出标签构造：定义 q_r 为第 r 轮相对参考答案的质量，令

```
p_r ∝ softplus( q_r − q_{r+1} − δ )
```

训练时引入固定先验，确保浅、中、深路径都被监督。

### 4.10 步长控制：TAPS

TAPS（2026-09-29，arXiv:2609.36653）把终端损失对更新尺度的敏感性分解为**持久进展**与**中心化波动**，在线追踪二者平衡后调整循环步长。

- 无需重训练即在多种循环架构和推理策略上提升终端准确率
- 若把进展—波动原则纳入训练，最多获得 **1.56× 墙钟加速**

**核心洞察：步长比轮数更接近循环计算的控制主轴。**

```
h_{r+1} = h_r + η_r · F(h_r, x)
```

把 η_r 设为可学习但受约束的标量/向量，能避免"始终执行满预算"和"早退后无法恢复"两个极端。

**双层控制设计**：
- 粗层：决定目标轮数
- 细层：为每轮设置 0—1 之间的更新增益
- 退出条件：连续多轮进展低于波动 **且** 答案熵足够低

**证据等级：B-工程验证。** 摘要未给出任务明细和统一停止预算，1.56× 不能视为所有骨干可移植值。

### 4.11 深度外推：三条证据与各自的边界

| 工作 | 结果 | 不可外推的部分 |
|---|---|---|
| **RLT**（arXiv:2610.07591） | 40 bit 训练 → 256 bit 奇偶外推 100%（普通 8 层 Transformer 接近随机）；8× 训练长度 S5 排列追踪 97%（Transformer <1%）；模运算超训练长度最高 93%（Transformer 33%） | 仅算法状态追踪任务，不证明开放语言外推 |
| **SMELT**（arXiv:2609.01343） | 严格匹配 FLOPs/参数/KV，只循环中间一半层两次，节省 6.8—18.0% 训练 FLOPs；DCLM Completion 96 个匹配对全胜，MMLU 胜 29/30 | 主要证据为中间层两循环；算术 FLOPs 匹配 ≠ wall-clock 匹配 |
| **Loop Scaling Laws**（arXiv:2609.40316） | 稀疏度约 3× 活跃参数效率，循环约 2× 总参数效率；按 law 选循环的 MoE 可匹配约 2× 大的非循环 MoE | 模型级预测，非系统级实测 |

**RLT 的关键反例（必须记录）**：
- 去掉反馈后，奇偶和 S5 在全部划分上退化到随机
- 每 4-token 块更新一次反馈，仍可保持 64 bit 奇偶 99%，但同样分块使 64 长度 S5 从 100% 降至 20%

> **状态更新频率应由任务状态转移频率决定，而不是为并行便利任意降低。**

**SMELT 机制洞察**：第二次访问降低 attention sink，把 attention 质量重新导向内容相关 token。

**外推实验的三维度**：
1. 训练内长度 → 2×/4×/8× 长度
2. 固定最大循环数 → 跨任务难度
3. 满深度训练 → 推理时少循环/多循环

指标不应只有 accuracy，还应包括：每额外轮边际收益、固定点残差、退出深度分布、批内 tail latency。

### 4.12 循环 × MoE：两类失效与配方

**两类失效**：
1. **残差累积**导致隐状态方差增长 → 稳定性问题
2. **同一路由在循环中反复选择相同专家** → 专家选择坍缩 → 计算多样性问题

**LOOM 配方**（arXiv:2610.01153，2026-10-01）：

| 手段 | 作用 |
|---|---|
| 缩放残差 | 限制方差增长 |
| 每轮重新注入输入嵌入 | 防止漂移 |
| **逐轮路由器** | 让不同循环调用不同专家 |
| looping residual | 携带早期输出 |

**量化结果**：
- 近似等 FLOPs 下，700M 在 5 轮最优，困惑度 18.36 → 16.54，平均零样本准确率 38.84% → 39.53%
- 不限制 FLOPs、60B token 训练的 1.7B 在 9 轮达峰值，困惑度 9.62 → 7.77，平均零样本准确率 42.4% → 47.7%
- 稳定扩展至 9—12 轮（100M—1.7B）

**Foil 的表象冲突**（arXiv:2609.35751）：把 (E, D, L) 展平为 (2E, D/2, 2L)，保持存储专家数、有效深度和 top-2 专家调用不变，却扩大每步可选专家池；注意力在不同轮解绑，专家和路由器**共享**。100B token 实验显示 loss 随展平单调下降，最大展平形态比基础循环 MoE 低 0.012 nat。

> **LOOM 强调逐轮路由器避免坍缩，Foil 用共享路由器但展平专家池。差异可能来自模型尺度、专家池大小和路由监督。路由架构不能照搬单一论文。**

**MoRE**（COLM 2026，arXiv:2609.18176）：相邻层共享专家池，每层保留独立路由器，加入轻量可学习深度嵌入。114M—1.15B 上匹配预算时优于标准 MoE 及既有权重共享架构。与 LOOM 互补：**MoRE 适合相邻物理层，LOOM 适合同一共享块的不同执行轮。**

**推荐实现**：软解绑 + 跨层共享池 + 逐轮路由 + 独立缓存。路由健康度不能由单一指标代表，应同时监控：Jaccard 相似度、路由置信度、专家负载、活跃专家数、跨轮独立性。相邻轮路由向量、top-k 集合和输出分布都应纳入 loss。

### 4.13 循环 KV 缓存：四级组合

循环架构中 KV 内存近似按 B·T·L·S·d_kv 增长——**T 轮使普通 KV 线性放大**。

| 技术 | 压缩对象 | 主要结果 | 必要条件 | 失效模式 |
|---|---|---|---|---|
| **终端 KV 共享** | 只保留最后一轮 KV | 1.6B 上 3× KV 可达全缓存下游水平 | **状态接近固定点** | 未收敛模型明显退化 |
| **HLA** | 历史位置精确 K/V → latent | 每 token 10.7×；并发 4.0—8.8×；decode 吞吐 2.5×（1K）/7.4×（16K）；准确率保留 97%+ | 冻结原模型、训练复现投影 | 长尾/分布外检索损失 |
| **ResidualQuant** | 跨轮 KV 残差 | 理论存储降 80.7%；固定批次 decode 吞吐最高 2.73×；峰值吞吐最高 4.15× | 最后一轮参考可靠 | 极端低精度误差传播 |
| **Recursion-wise cache** | 每轮独立缓存 | 支持不同深度 token 快速 decode | 退出/调度系统可用 | 缓存总量仍随轮数增长 |

**终端共享的关键前提**：固定点 z* = F_θ(z*, x) 只涉及终点而不依赖轨迹。原文回顾发现 **Huginn 靠近固定点、四循环时几乎无损，而 Ouro 不收敛，简单复用最后一轮 KV 会显著失败**。

> **部署前必须测量每轮 KV 差异、残差 norm 和验证集质量**；只在收敛置信度高、长度超过阈值且回退路径存在时使用共享。对生成任务，至少保留最后一轮和最近窗口的真实 KV。

**HLA 与 ResidualQuant 正交**：前者改变跨历史位置的表示，后者压缩每一轮的 K/V，两者可叠加。

**按生成阶段选择缓存策略**（而非全局单一规则）：
- prefill：固定点蒸馏或较长循环
- 已提交前缀：终端 KV 共享 + exact recent window
- 历史长尾：HLA latent
- 每轮内部仍超预算：ResidualQuant
- 批内未退出 token 继续循环，已退出 token 冻结并复用最成熟状态

**恢复路径必须保留**：质量突降、路由熵骤变或 latent cache miss 时，回退到真实全深度 KV。

## 第 5 章 L2：长上下文与分级召回

### 5.1 可扩展上下文的本质

可扩展上下文的本质不是让全注意力变快，而是**把全二次注意力的召回职责限制在少量全局层，把常规历史处理下放给局部窗口、有界状态和压缩存储**。

```
全注意力：    A(Q,K,V) = softmax(QK^T/√d)·V      prefill O(L²d)
线性注意力：  S = Σ_{i≤t} α_i k_i v_i^T         推理 O(d²) 状态
滑动窗口：    w 内计算                          prefill O(Lwd)
全局稀疏：    只计算 gL 边                      代价取决于全局预算 g
```

> **真正的复杂度谱不是"线性对二次"，而是"窗口保底、全局召回、状态压缩、远端归档"的分工。**

### 5.2 全局稀疏索引：LongCat Sparse Attention

**三件套预算**：固定局部预算 + 动态稀疏预算 + 少量全注意力。

- 流式 sink：`K_sink = 16`（保存序列起始等固定锚点）
- 滑动窗口：`K_swa = 1024`（保持局部语法和工具输出连续性）
- 动态部分：负责长程证据
- 固定与动态预算比约 **1:1**

**量化结果**：1M 上下文可训练；32K prefill 加速 1.42×，1M 最高 3.60×；decode 1.25—1.40×。Flash-Lite 为 69B-A3B，Flash 为 560B-A27B，均原生训练到 1M。

**⚠ 关键警示：索引器在 1024K 时最高占单层时延 90%。** 这比注意力输出不连续更值得警惕。

**两项摊销技术**：

**① 流式感知索引（SI）**——跨层相邻层分组，首层作为 owner 执行索引，其余层复用被选集合；跨层蒸馏让 owner 索引照顾整组显著性。N=2 时索引计算减半且无可观质量损失。

**② 层级索引（HI）**——先按页选出 Top-M 页，再仅在页内做 token 评分，把每 query 选择复杂度由 O(L) 降为 **O(L/P + M·P)**，P 为页大小。

**可复用实现要点**：
- 页目录使用连续块驻留 HBM
- owner 层写统一的 selected-bitmap / rank
- 后续层以 warp-cooperative top-k 与 gather 读取
- 页内细筛可延迟到 decode，避免每 query 扫描全历史

**失效模式**：分块割裂跨页实体、页内噪声使平均页表示失真、Top-M 过早淘汰稀有 needle。

**对策**：页边界 token 强制候选、多尺度页、压缩后被选中页转 dense、oracle 重合率监测（**而非只监控平均精度**）。

### 5.3 两级 KV 共享：HySparse2

**结构**：外层采用 YOCO 式 self-decoder / cross-decoder，只桥接全注意力层。

- cross-decoder 的全注意 K/V 由 self-decoder 全注意层隐藏态经**目标层独立投影**生成
- Q 仍来自当前层
- 内层保留 KV Reuse，block 级选择改为 **token 级选择**
- 用强制近期窗口代替稀疏层内的独立 SWA 分支
- 所有 cross-decoder KV 都可由 self-decoder 状态构造 → **prefill 可提前退出**

49 层 80B-A3B 模型：self-decoder 25 层，cross-decoder 24 层。prefill/decode 分离时 prefill 节点只需部署 25 层，**显存约减半**。

**量化结果**：
- 1M 时 prefill FLOPs 相对 HySparse 降 2.92×、相对 Hybrid SWA 降 5.02×
- FP8 KV：**2.69GB**（HySparse 6.72GB，Hybrid SWA 12.09GB）
- 轻量后训练后，MRCR-v2 +11.30 点、RULER-v2 +19.81 点

**⚠ 必须分开的两件事**：1M 是**计算与缓存分析**，质量上限是 **256K 实验**。不能把 256K 准确率外推到 2M/4M。

**失效模式**：桥接投影无法完全还原原 KV 表达、token 选择漏掉跨距离证据、强制窗口与全局预算冲突、early-exit prefill 只省计算不省跨解码器状态生成所需的总容量。

### 5.4 页级 KV 压缩：PuzzleKV

**机制**：把每层每头的 KV 分成固定逻辑页，保留小 sink 与近期窗口为 dense，其余页**逐页低秩分解**；kernel 直接对 dense 与 factorized 页计算，无需重建历史 KV；新完成页在解码中增量转换。

**量化结果**（Qwen3-8B、Llama-3.1-8B-Instruct，16K/32K）：
- 约 **60%** 原始 KV 存储保持 Full KV **96%+** 性能
- 叠加量化至 **18.7%** 存储仍保持 **93%+**

**可复用要点**：
1. 以 PagedAttention 页为压缩单元
2. **页内独立 SVD/URV**（固定投影、校准投影或全局共享基无法充分表达页内细节）
3. 每步只转换刚完成页
4. dense / factorized 混合 attention
5. 为高层/重要头保留更高秩或更高精度

**证据边界**：仅 8B 规模、16K/32K、两个模型。长代码跨页依赖、多语言、1M 长度和并发服务尚缺公开结果。

**工程对策**：用 oracle 保留集或重要性分数**豁免** needle 页、代码定义页、工具结果首尾页；rank/bit-width 按层和头离线搜索。

### 5.5 共享变换域索引：Self-Indexing Attention

无训练框架，使用共享变换域 **sign-magnitude** 表示：sign 既作为分组预填充选择的 1-bit 索引，也作为 decode 检索索引，兼容外部 KV 压缩，不新增独立索引元数据。

- 5% 注意力密度下接近 dense 的 LongBench 与 RULER
- prefill / decode 注意力算子最多加速 **6.1× / 10.3×**
- 与 TurboQuant、低比特 KV 兼容

**⚠ 局限**：这是**算子峰值**而非端到端吞吐。位运算快不代表页表和 gather 不触发 HBM 往返；5% 密度在强干扰、多针、长程推理上可能召回不足。

**定位：作为索引表示的候选模块，而不是直接替换分层调度器。**

### 5.6 推荐的四层可扩展架构

**第一层：混合注意力工程基线 = SWA + 周期全注意 + 动态稀疏索引**

- 每 4 层设 1 层全局/稀疏召回层，其余为 SWA
- 每若干全局层选一层作为 owner，使用跨层蒸馏供后续同构层复用
- 1M 以上任务把"周期全注意"改为分层：大部分层只看窗口/状态，少数层做少量全局全注意，另外用索引层选页
- 全注意力比例为常数，prefill 复杂度近似 O(L)

**第二层：远端历史 = dense 近期 + 精确锚点 + 页级低秩/低比特 + 回退 dense**

| 区间 | 策略 |
|---|---|
| 0—4K 近期 | dense / FP8 |
| 4K—64K | 页级低秩 + 2—4 bit 量化 |
| 64K 以外 | token/页选择，必要时卸载至 host |

压缩等级由重要度和召回置信度动态决定，预留 **5%—10% HBM 裕度**。

**总预算约束**：

```
B_dense + B_factor + B_index + B_recent + B_activation < 1 GB
```

**⚠ 每加一级压缩都有独立误差**。每级都应报告相对于原始 dense/FP16 或 FP8 基线的质量，**防止把 FP8 再压缩率误称为相对 BF16 的压缩率**。

**第三层：MoE = 低秩 router + 显式容量 + 细粒度调度**

- Router 使用 MoRE 低秩分解并在 fused kernel 中维护 running top-k
- 训练热点采用 CIPHER 式 affinity filtering（不改变 token Top-K）
- 服务侧按请求路由预算和长度分桶
- 序列极长时，把"每 token 计算"与"每请求 KV/带宽"分开调度

**第四层：量化与投机解码放在正确性闸门之后**

- 权重用 DRQ 式分布鲁棒格点优化
- KV 按层和头差异化量化
- 投机解码（NSD）上线前先做长上下文、低概率、安全任务验证

**NSD（Nucleus Speculative Decoding，2026-10-06，arXiv:2610.07822）**：接受"标准测试通过"或"token 属于 target nucleus"的草稿，保持残差校正和 bonus sampling；单步总变差误差**精确等于**草稿在目标 nucleus 内的超额概率。最多取得 5.16× 相对自回归、3.15× 相对标准 SD，验证时间近乎减半。

**⚠ 风险**：这是"以分布忠实性换接受长度"。安全、采样、低概率关键答案、长链推理需定义可接受误差，**不能直接当作无损**。

### 5.7 长程遗忘：分层失败指标

长上下文能力应**分层失败**，而不是"模型忘记一切"：

| 层 | 指标 | 失败时的调参对象 |
|---|---|---|
| **L0** | 原始全注意力上限 | 模型容量本身 |
| **L1** | 索引召回率 | 索引、Top-M、页大小、候选窗口 |
| **L2** | 压缩后质量 | 提高关键页秩/精度，或豁免重要页 |
| **L3** | 端到端任务成功率 | 生成、工具策略或状态追踪（**非缓存问题**） |

> 这个分层能避免把"KV 压缩导致遗忘"误判为模型参数能力不足。

### 5.8 长上下文评测集（必须覆盖，不能只用 NIAH）

单针结果会高估鲁棒性——SWLA 只在 NIAH-SK1 报告 64K 100%，而同表 SK2/SK3 较低。

**必须构造的六类测试**：
1. 1K—2M 的 passkey 及多 UUID
2. 跨页代码定义/引用
3. 100+ 轮工具状态
4. 多针相互干扰
5. 自然文本与重复填充对比
6. 格式、角色、规则与事实四类约束

**动态内存预算应让"遗忘"变成可解释策略**。每个 token/页维护：最后访问时间、写入重要性、跨页引用、索引分数、语义类型、压缩误差界。删除需保留审计日志和回源指针。

### 5.9 位置编码与阶段化扩展

**RoPE 类位置外推需要长期连续预训练与评估，不能仅靠基频公式承诺翻倍。**

训练应按 1M、2M、4M 分阶段扩大窗口，保持数据质量与位置混合比例，每阶段都测 in-domain PPL、NIAH、多针、检索、代码跨文件和 agent 状态追踪。

**混合位置策略判据**：
- 若计划做**长上下文继续预训练** → 选线性注意力混合体
- 若需要**免训练长度外推** → 选滑动窗口混合体，或采用 SWLA

**SWLA**（2610.10114）：把 gated LA 在 4096 token、步长 1024 的重叠分块中计算，再加全局 NoPE 分支的对数尺度注意力，实现 4K → 64K **16× 免训练外推**，NIAH-SK1 达 100%。

**⚠ 这是单任务检索指标，不能外推为语言模型普遍 16× 无损外推。**

**推荐层序**：输入附近保留 SWA；每 3—5 层插入一次全局全注意力或稀疏索引；其余层使用线性状态；全局层可作为索引 owner。位置编码优先用系统已验证方案，配合文档/页级位置标签。

## 第 6 章 L3：外挂记忆子系统（EMS）

### 6.1 四层数据面

自研架构不应把"检索增强"视为一个检索器，而应定义为具有状态迁移、预算控制、证据链和回滚能力的**记忆控制面**。

| 层 | 内容 | 特性 |
|---|---|---|
| **不可变事件日志** | raw event log | **只追加，不允许就地修改** |
| **可验证条目池** | canonical fact/lesson ledger | 主体、键、值、来源、时间、置信度、作用域、证据 ID、生命周期状态 |
| **热活动上下文** | active context | 当前任务需要的紧凑摘要 |
| **模型内部快速状态** | fast weights / 临时 LoRA | 只在会话或任务内临时更新 |

**VerMem 的三状态与七原子操作**（arXiv:2608.03137，2026-08）：

- 三状态：长期记忆、当前活动上下文、情景历史
- 七操作：**增加、修订、软删除、检索、过滤、情景恢复、摘要**
- 局部验证器检查可执行操作；全局验证器检查任务结束时的证据一致性和最终记忆一致性

**可复用价值不在于特定网络结构，而在于暴露了一组可审计的状态机**：在线推理不直接写"事实"，只提交候选条目；离线引擎负责把候选合并为稳定知识、将旧条目降级为历史并保留证据。

### 6.2 可撤销冲突管理：TEPA（核心组件）

**条目表示**：

```
p = (k, v, s, f, σ, τ)
```

- `k`：键
- `v`：值
- `s`：统计
- `f`：来源
- `σ`：置信度
- `τ`：时间

**生命周期状态**：Hypothesis（候选）→ Active（可检索）→ Revoked（被新证据撤销并归档）

**冲突函数**：

```
conflict(x_i, x_j) = 1[ κ(x_i) = κ(x_j) ∧ ν(x_i) ≠ ν(x_j) ]
```

即**只有同一键且值不同**的记录才视为替换对象。

**撤销条件**（满足任一）：
- 总共 5 次观察后，后验均值低于 θ_rev
- 同键记录至少 3 次后，近期成功率低于 θ_rec = 0.34

**量化结果**（受控漂移，50 种子）：

| 方法 | 完整反转 | 真实文件执行 |
|---|---|---|
| append-only | 0.210 | 0.203 |
| last-write-wins | 0.210 | — |
| **无记忆** | **0.309** | 0.298 |
| **TEPA** | **0.950** | **0.950** |

> **关键解读**：当环境事实反转时，永远追加、最后写入胜出都会把过期记忆再次送入上下文，**性能跌到比没有记忆还差**。TEPA 通过把旧值移入可审计归档而非物理删除，保留了时间线。

**架构要求：活动视图与审计历史必须分离。**
- 查询返回 active 快照
- 内部查询可返回 time-travel 视图
- 撤销操作**只改变状态位并写入补偿事务**

**⚠ TEPA 的边界**：该方法依赖可从证据中提取的**显式冲突键**，适用于偏好槽位、实体属性和工具状态；对冲突关系隐含的开放式记忆并不自然。在 MemoryAgentBench MH-6k 和长上下文变体上，TEPA 分别降至 0.040 和 0.000——**多跳链接构建、跨键组合和超长上下文选择才是下一步瓶颈**。

> **不能把字符串相似度当成键等价。** 开放式经验应交给结构化图和显式"待消解冲突"边。

### 6.3 精准注入门

**核心原则：检索命中不应自动转化为上下文展开。**

Remember When It Matters（2026-07，arXiv:2607.08716）用独立记忆智能体伴随主行动模型，把近期轨迹转为结构化记忆库，并**选择是否注入"记忆驱动的提醒"或保持沉默**。

- Terminal-Bench 2.0：pass@1 **+8.3**
- τ2-Bench：**+6.8**
- 优于被动展开、始终注入、仅顾问式引导与一般检索

**门控设计**：仅当当前目标、操作类型、最近错误和缺失状态命中某条记忆的触发条件时才注入。每条注入绑定：

```
{ 证据 ID, 有效期, 适用范围, 停用条件 }
```

### 6.4 结构化经验图：STRATA

**三层图 + 类型化边**：

| 层 | 内容 |
|---|---|
| 原子层 | 技能、代码片段 |
| 工作流层 | 任务工作流 |
| 元框架层 | 通用元框架 |

**维护机制**（共用一个相似度几何）：
- 按**操作**和**目标**的多元相似度检索
- 类型化反思器从成功中结晶流程、从失败中结晶陷阱
- 社区检测诱导元框架
- 压力触发的垃圾回收保留**关节点**（articulation points）
- 对比边标记容易混淆、方向相反的经验

**量化结果**：AppWorld、WebArena、ALFWorld、ScienceWorld 上，两种冻结主干、七个基线中取得最佳平均分数，同时**最低延迟、最少环境步骤**，注入记忆比最占上下文的基线**少 44%**；ScienceWorld 负迁移场景 78.7 → 96.7。

**证据等级：B-工程验证。** 这是交互式基准平均结果，不是通用检索准确率。

**节点 schema（建议最小集）**：

```
node_id, type, abstraction_level, scope,
task_embedding, op_embedding, target_embedding,
preconditions, postconditions, outcome,
confidence, provenance, valid_from, valid_to,
aliases, inverse_edges
```

**边类型**：

```
IS-A, PART-OF, GENERALIZES, CONTRASTS, SUPERSEDES,
EVIDENCED-BY, APPLICABLE-IN
```

> **CONTRASTS 边尤其关键**：它保存"在表面相似但方向相反的情境下不可用"的反事实，可在检索重排时显式降低误迁移风险。

**多维相似度的正确实现**：至少分别编码"操作（op）"和"目标/对象（target）"，**不是只算句向量**。在线检索先用键/类型/前置条件硬过滤，再做向量相似度与规则评分。

### 6.5 不可约冲突：TANGLE

TEPA 处理"过期覆盖"，但还有第三类冲突：**缺少决定哪个记忆适用的上下文、时间或来源可靠性**。

TANGLE（2026-08，arXiv:2608.13921）：541 个实例、40 个角色、三类不可约冲突：

| 类型 | 含义 |
|---|---|
| **CPC** | Context-Partitioned Conflict |
| **BOC** | Behavior-Oscillation Conflict |
| **SCC** | Source-Contradiction Conflict |

**动作空间**：

```
{ commit, conditionalize, clarify, verify, defer, reversible_trial }
```

**关键诊断**：即便拥有完整、精选的记忆，**模型识别冲突的能力仍高于校准建议或寻求定向澄清的能力**；端到端流水线中，**上游记忆抽取会丢失下游推理必需的冲突关系**。

**记忆 API 返回结构（强制）**：

```json
{
  "chosen_view": "...",
  "active_alternatives": [],
  "conflicts": [],
  "missing_context": [],
  "recommended_action": "commit|conditionalize|clarify|verify|defer|reversible_trial"
}
```

> 若冲突不可判定，返回 conditionalize 或 clarify，**不把某个记忆概率映射成事实置信度**。对高风险动作，离线引擎还应把记忆降为约束或风险标记，而不是让模型自主"综合"。

### 6.6 双时态 schema（最小集）

| 字段 | 用途 | 示例 | 一致性动作 |
|---|---|---|---|
| `subject_key` | 识别同一实体/接口/策略 | `tool.stripe.v2` | 同键新值触发迁移 |
| `attribute` | 限定被更新的是哪个属性 | `default_currency` | 不允许不同属性互相覆盖 |
| `valid_time` | 事实生效时间 | `[2026-08-01, ∞)` | 时间点查询返回正确版本 |
| `transaction_time` | 系统记录时间 | `2026-08-12T10:00Z` | 支持时间旅行与回滚 |
| `source_id` | 权威来源或观察 ID | `run#1042` | 支持来源排序与撤销 |
| `evidence_state` | 生命周期状态 | `active/revoked` | 控制是否参与常规检索 |
| `verification` | 可执行验证结果 | `pytest / API schema` | 提高状态迁移置信度 |
| `conflict_set` | 冲突或互补关系 | `contrasts/refines` | 多答案时提示澄清/条件化 |

> **该 schema 的价值在于把"检索相关性"和"逻辑可应用性"分开**：向量相似度只用于初筛，键、时间、前置条件、权限、版本、反例和验证结果才决定条目是否能成为 active candidate。

### 6.7 老化与淘汰：压力触发 GC

**原则：规模化治理要采用"压力触发 GC + 关节点保护 + 容量预算"，而不是定时删除旧条目。**

**评分函数**：

```
S(n) = α·success_quality(n)
     + β·recency(n)
     + γ·retrieval_utility(n)
     + δ·generality(n)
     − ζ·staleness_risk(n)
     − η·storage_cost(n)
```

- `success_quality`：可验证结果或校准后的反馈
- `recency`：**时间衰减**，而非简单删除
- `retrieval_utility`：实际改善决策的命中
- `generality`：跨任务复用量
- `staleness_risk`：来自版本、冲突键、过期时间
- `storage_cost`：token、向量维度、索引代价

**淘汰分级（不直接删除）**：
1. `S(n) < θ_low` → 降级至冷存储（保留 ID，移出活跃索引）
2. 冷存储中 90 天未再激活 → 归档
3. 被 `supersedes` 指向的旧条目 → 保留元数据，移出活跃索引

> **任何承担结构桥接、被多版本引用的关节节点即便低频也应保护。**

**GC 必须生成压缩事务**：输入证据哈希、规则版本、删除/合并节点、回滚引用、验证结果。

**生命周期状态机**：

```
Candidate → Validated → Active → Deprecated → Archived
              ↘ Conflict Pending / Under Verification
```

**状态迁移只能由事件触发**：版本更新、环境反馈、可执行验证、来源撤回、同键新证据、显式 TTL、相似反例、容量压力。

> **删除只是把 Latest 指针移走，底层事件和旧版本永久保留。**

### 6.8 多模态记忆：四类组织方式

| 系统 | 结构 | 关键结果 |
|---|---|---|
| **MFM**（arXiv:2610.22686，2026-10-15） | episodic / spatial / semantic-procedural / working 四分区；可搜索文本记录作索引，保留原始多模态 episode 指针 | Mine Diamond 完成更多里程碑；Ender Dragon 16/24（最佳基线 12.7）；CUABench-KiCad 平均奖励 0.440（最佳基线 0.400，无记忆 0.267） |
| **MemPilot**（arXiv:2610.06830，2026-10-05） | 查询时按需整理 vs 查询无关检索，多步策略联合控制证据量、整理指令、模型选择、视觉访问 | 五个多模态 agent memory benchmark 上 Pareto 前沿优于既有 trade-off-aware 基线 |
| **EMMA**（arXiv:2610.23892，2026-09-28） | raw video / clip-level / event-level 三级；事件边界由视觉语义漂移与语音转换共同触发 | 适合小时级长视频，减少固定窗口造成的片段拼接与事件碎片化 |
| **World-T3**（arXiv:2610.17434，2026-10-12） | 按相机位姿索引的**快速权重**，递归最小二乘在线吸收新视觉特征 | 重访 PSNR 13.52 → **18.31 dB**；绝对旋转误差 3.344 → **1.075**；单张 B200、1280×704 下 20.6 FPS |

**MFM 的核心洞察**：全量历史会压垮上下文，过早摘要又会不可逆地丢失视觉和空间细节。**索引负责检索，原始证据负责核验，高层知识负责复用。** 智能体先定位相关事件，再回到原始观测恢复缺失细节。

**MemPilot 的核心洞察**：记忆整理应从"写入时固定处理"改为"**查询时按需处理**"。真实记忆系统应按 SLA 配置，而不是追逐一个脱离成本的总体分数。

**World-T3 的警示**：快速权重需要冻结、回滚和版本控制。**如果位姿估计错误，错误会随空间记忆写入而被长期保留**，因此必须同时保存观测置信度、覆盖范围和回滚索引。

### 6.9 可靠性工程：SIx Harness 的七原则

**生产记忆系统的第一指标应是"零静默失败"，而不是召回率。**

四类记忆失败：知识丢失、重复劳动、上下文退化、**静默记忆死亡**（最后一类最危险）。

**实证记录**（2026-01 起持续运行的单项目开发场景，63.3 万行代码库）：

| 指标 | 数值 |
|---|---|
| hook 调用 | 78,933 |
| 记录失败 | 85（**无一静默**） |
| 失败分布 | 84 次集中在最初三周，此后 1 次，最后 20 天为 0 |
| 健康门 | 11 项，输出 `MEMORY-HEALTH: 11/11 GREEN` |
| 误触发 | 68 次提示中 54 个无意图项上 **0 次误触发** |

**证据边界**：这是 N=1 的生产操作记录，无对照组，作者自报。它证明的是**工程可实现性和观测方法**，而非准确率提升幅度。

**必须复用的**：11 项启动健康门 + 每次操作结果日志 + 每会话心跳 + 告警预算。**不要照抄其内部提示格式。**

**最小 SLO 与告警清单**：

```
□ 事件写入成功率
□ 索引一致性
□ 检索 p95 延迟
□ 注入精准率
□ 误注入率
□ 状态迁移成功率
□ 验证集回归
□ 未验证经验占比
□ 冲突积压
□ GC 误删率
```

> **每条告警都附"如何修复"的 runbook；无分母的仪表盘（如只显示"成功检索次数"）应禁止上线。**

### 6.10 校验三元组（CE 的数据源）

每次校验事件，无论通过或拒绝，均记录：

```json
{
  "event_id": "uuid",
  "session_id": "uuid",
  "timestamp": "ISO8601",
  "stage": "int",
  "query_repr": "bytes(embedding, d)",
  "candidate_chain": {
    "hidden_trace": "bytes(compressed)",
    "decoded_summary": "string"
  },
  "verdict": "PASS | REJECT | CORRECTED",
  "divergence_score": "float ∈ [0,1]",
  "authority_refs": ["doc_id"],
  "corrected_chain": "optional",
  "memory_ids_used": ["mem_id"]
}
```

> **REJECT 与 CORRECTED 的价值高于 PASS。** 被拒绝的链路是负样本，修正后链路是正样本，二者配对即形成偏好对——**这是生产过程的免费副产品，无需额外标注成本。**

**分歧度作为课程信号**：

```
priority(样本) = w₁ · divergence_score
               + w₂ · (1 − 该类别历史准确率)
               + w₃ · recency_decay(t)
```

分歧越大的区域，就是模型当前最不确定的区域，应优先投入巩固算力。**按分歧度排序采样，效率显著高于随机采样历史会话。**

## 第 7 章 L4：世界模型与反事实推演

### 7.1 五层解耦

统一 token、显式动力学、动作条件、不确定性、持久记忆应**分别形成接口**，避免用单一大模型遮蔽所有误差来源。

| 层级 | 建议模块 | 建议接口或损失 |
|---|---|---|
| **原始编码** | 模态专用 encoder、时间对齐与有效性 mask | 冻结公共编码、跨模态对比对齐 |
| **统一状态** | 统一 latent、事件边界、空间与状态 token | JEPA、MAE、表征一致性 |
| **动力学** | 显式谱结构或 normal 转移、动作专家 | posterior/prior、one-step、h-step |
| **多模态生成** | 视频、触觉、动作 head | flow matching、扩散、动作似然 |
| **决策与记忆** | 候选 rollout、不确定性 scorer、可重置记忆 | MPC、验证器、适用性条件 |

**最低接口要求**：

```
z_t = f(o_{≤t}, a_{<t})              潜状态编码器
p_θ(z_{t+1} | z_t, a_t)              动力学先验
o_t = g(z_t)                         观测解码器
r_t / V(z_t)                         奖励或价值预测器
u(z_t, a_t)                          不确定性输出
```

> 若模型只输出像素或视频，**没有可重入的状态和动作条件，就不应直接称为可规划世界模型**。

**数据流建议**：`raw modality → structural token → shared latent → modality-specific head`，而不是把所有模态直接压成无差别 embedding。

### 7.2 谱约束动力学：Koopman Dreamer

**确定性状态更新**：

```
z^d_{t+1} = K z^d_t + B a_t + (z^d_t ⊗ a_t)^T L + σ(z_t, a_t)
```

- `K`：二维旋转—缩放块，每个模态谱半径有界
- `B`：全局线性动作效应
- `L`：低秩双线性状态—动作耦合
- `σ`：离散随机状态，提供局部观测修正

**训练目标**（针对 imagination 与 posterior-conditioned 训练之间的分布失配）：

```
L = λ_ema·L_ema + λ₁·L_one-step + λ_H·L_h-step + λ_obs·L_obs
```

- 后验条件 EMA 教师提供目标
- 一步一致性、多步 rollout、开环观测预测共同约束长期轨迹
- 给出多步 rollout 误差界，把谱骨干与双线性交互造成的误差放大、随机状态失配、模型残差**分开**

**量化结果**：DeepMind Control Suite 9 项中 8 项优于 DreamerV3；无人机导航（矢量 LiDAR）目标成功率 53.8% → **73.8%**。

**⚠ 关键发现**：**最大收缩并非最优**——过度收缩会消除未来控制所需的信息。稳定与信息保留必须共同优化。

**可复用组件清单**：
- 以 2×2 块或 normal/Jordan 形式参数化 K
- 用谱范数或半径约束各模态
- 确定性状态与随机状态设置**独立传播路径**
- posterior rollout 与 prior rollout **分别统计误差**
- rollout error decomposition 作为诊断面板
- 随机状态在每个决策步重新由观测校正

### 7.3 表征预测与想象误差扩展律：RoboJEPA

**二阶幂律**：

```
E(C) ≈ a·C^(−b) + E_∞
```

- 12 种机器人本体数据
- **想象误差与下游机器人规划性能强相关** → 可作为真实机器人评测的**代理指标**
- 8B 版本是当时最大的 JEPA 预测模型，能以单张目标图像做零样本规划
- Meta 已发布权重、训练和部署代码

> **证据支持"先优化想象误差，再估计真实部署能力"。** 但只适用于 latent JEPA 路线，不能直接解释为所有视频扩散 WAM、所有具身任务或所有算力预算都成立。

### 7.4 世界动作模型：Dyna-2

**数据阶梯**：1000 / 10,000 / 100,000 / 1,000,000 小时人类第一视角视频，每阶梯保持来源比例不变。

**架构**：视频扩散骨干 + Mixture-of-Transformers——视频 token 与动作 token 拥有**各自**的 DiT 层栈，通过跨注意力融合；动作栈刻意保持较浅，并在早期接入视频流。

**共同 flow-matching 目标**：

```
L_WM + L_A = E‖ v_θ(x_t, t, c_vid, c_txt) − u(x_0, ε, t) ‖²
           + E‖ v_φ(a_t, t, z_vid, s_prop) − w(a_0, ε, t) ‖²
```

- 视频和动作共享骨干，但保持各自的边际速度场
- 文本不直接进入动作 token
- 视频采用因果掩码，动作采用双向自注意并 attend 上下文视频
- **动作网络不把带噪视频 latent 作为输入** → 推理时无需等待完整视频生成，策略仍可保持反应式控制

**量化结果**（39 项双 YAM 平台任务，两种预训练未见本体的零样本评测）：

```
零样本 action MSE = 0.306 × D^(−0.0713),  R² = 0.884
hold-out MSE      = 0.0691 × D^(−0.0184), R² = 0.919
```

- 最严格阈值的 accuracy 在四个阶梯上提升 **51%**，而 MSE 只改善 12%
- 固定 50,000 小时带标签动作数据，仅增加无标签视频，零样本机器人 MSE 从 0.340 降至 **0.120**

> **视频数据不只是动作任务的弱标签来源，还提供了跨本体可迁移的场景动力学先验。**

**部署瓶颈已从模型质量转移到生成延迟**：蒸馏前视频采样 10,203ms，蒸馏后 **110ms**；一步学生 FVD 121，Flicker 2.37 → 1.94。

**跨本体微调**：14 项任务，每种本体每项任务最多 10 小时机器人数据，归一化性能 20%/28%/45% → **53%**。

**⚠ 证据边界**：厂商技术报告，无独立复现、公开权重或 API。**"已验证内部实验，非开源审计"。** 且渲染 FPS、潜变量 FPS 和实际控制率必须分别测量——避免把"能生成画面"误报为"满足闭环控制"。

### 7.5 开源组合路线：OpenWAM

**四种组合程序**：

| 程序 | 建模接口 | 主要用途 |
|---|---|---|
| **VTA** | 视频 → 动作 | 利用视频潜变量预测动作 |
| **ATV** | 动作 → 视频 | 利用动作条件生成未来视频 |
| **Joint** | 视频—动作联合生成 | 统一预测与生成 |
| **Decoupled** | 视频与局部逆动力学分离 | 降低跨本体动作歧义 |

**量化结果**（LIBERO-Long）：
- 因果机器人视频预训练相对原始 Wan2.2 初始化：VTA **+29.4 分**，Joint **+34.4 分**
- 局部上下文逆动力学模型仅用示范数据：成功率 **21.5%**
- 加入**反事实 transition**：**84.0%**
- 仅使用反事实数据训练：**84.5%**

> **"动作不变式"或"局部物理规则"可以由反事实探索显式学习，而不必完全依赖无监督视频扩展。**

**开源程度明显优于 Dyna-2**，但数据规模、模型开放性和商业部署状态不同，不能直接把二者数值成绩理解为同等级竞赛结果。

### 7.6 想象时域的现实边界

**The Planning Limits of Latent World Models**（2026-09-30，arXiv:2609.39235）：冻结 V-JEPA 2 / 2.1、VideoMAEv2、VideoPrism、DINOv2，在 Meta-World 与 BridgeData V2 上比较**五步**想象（正是预测器训练长度），但任务目标往往位于 **16—53 步**之外。

| 方法 | 成功率 |
|---|---|
| 纯想象 | 23% |
| MPC | 30% |
| 想象到完整目标 | 47% |
| **使用附近专家子目标** | **76%** |

- V-JEPA 2.1 稳定性最好
- **更大的 predictor 或更长训练没有自然延长可规划范围**
- latent world model 用于 VLA 动作候选排序：8 候选成功率 65% → **77%**

**工程结论**：把想象训练分成两个阶段——在模型可靠的时间窗内做 full rollout；更远的目标只做短期 receding-horizon MPC，或引入子目标、环境反馈和实时观测重锚。**无限制想象既昂贵，也容易被累积漂移误导。**

### 7.7 反事实记忆：必须经可执行环境验证

**核心原则：反思式 self-play 通常只能生成"看似合理"的修正，不能证明反事实动作会改善结果。** 可执行世界模型、测试、证明检查器或求解器，则能在可重置状态中验证候选动作并给出客观结果。

**COUNTERMEM**（2026-09-25，arXiv:2609.31874）流程：

1. 失败发生后，在原始状态的副本或重置态中提出 **K=4** 个局部替代动作
2. 由可执行环境验证改善量 Δ
3. 只有 Δ > ε_adm 的修正才保存为记忆记录

**记忆记录结构**：

```
m = ( q, a⁻, a⁺, e, c, u )
```

| 字段 | 含义 |
|---|---|
| `q` | 查询 |
| `a⁻` | 原动作 |
| `a⁺` | 修正动作 |
| `e` | 证据 |
| `c` | **适用条件** |
| `u` | 复用统计 |

- 后期任务从有限记忆库检索候选，再由 DQN selector 决定**应用某条记录或跳过记忆**
- 验证器调用、记忆库和 selector 在 held-out 评测中**均被冻结**
- 奖励同时权衡任务成功、验证器调用、失败尝试和 token 成本

**量化结果**：六个领域、12 个基准中相对 ReAct 与 Reflexion 平均 **+12.6 个百分点**，任务运行 token 下降 7.7%—42.0%。四领域、两种 backbone 下，ReAct 成功率提升 14.4—31.5 pp，Reflexion 提升 3.8—15.8 pp。

> **"验证通过"不等于"普遍适用"。** 去掉验证或持久存储会削弱增益；**把已验证修正套用到条件不匹配的决策上，也会反向损害性能**。DQN selector 的作用是在"使用修正"与"额外验证+token 成本"之间权衡，而不是尽量多应用历史经验。

**可复现实现清单**：
- 版本化状态快照
- 确定性 replay / reset
- 带资源预算的替代动作生成器
- 可执行验证器
- ε-greedy 或 DQN selector
- 记录 (q, a⁻, a⁺, e, c, u) 的有限记忆库
- **上线前对条件误用做反事实攻击测试**

> 对于没有确定性的真实机器人，**不应将概率性 rollout 视为证明器**，应设置验证次数、置信区间和物理安全约束。

### 7.8 机制一致性 vs 预测精度：可能同时分裂

**On the Divergence of Accuracy and Mechanism Consistency**（2026-10-01，arXiv:2610.01842）：八个含真实动作的公开数据集，涉及工程基础设施和临床场景，区分连续动作、模式动作和事件动作。

**结果**：
- 冻结潜空间预测相较观测空间使 MAE 平均下降 **9.9%**
- 输出侧 gated fusion 相较输入拼接下降 **12.7%**
- 时间动作编码对平均 MAE 影响不超过 2.2%
- **但预测误差最低的配置，在五项含已知机制数据集中的四项跌至 chance 或以下**
- **没有任何设计能同时避免该问题**
- 方向监督提高了被惩罚机制的 consistency，却没有改变 MAE

**方向性机制损失**：

```
L_mech = Σ_j E[ max(0, −sgn(∂y_j/∂a_ij) · ∂f_θ/∂a_ij) ]
```

即预测响应与已知动作—状态关系**方向不一致时**才施加惩罚。

> **必须同时报告 MAE、NDTW、goal success 和方向一致性，不能把 MSE 作为唯一代理指标。** 只优化 MSE 会制造"准确但不因果"的动力学。

### 7.9 不确定性：可约 vs 不可约

**形式化定义**：

```
可约（模型/认知）不确定性：  Var_D[ f_θ(x) ]
不可约（偶然）不确定性：    E_D[ Var_{y~p(·|x)}(y) ]
```

- 前者：数据或参数覆盖不足，**可通过更多数据和训练降低**
- 后者：同一状态—动作条件下的真实随机结果，**不能通过继续拟合同分布数据消除**

> 规划器若把二者混在一起，会过度惩罚真正随机的环境，或过度相信数据覆盖不足的确定性预测。

**自适应 rollout 截断**（arXiv:2609.21482，IROS 2026 workshop）：不固定训练 rollout horizon，而是在**认知不确定性超过 warmup 阶段校准阈值时提前截断**。

比较五头共享骨干集成和 MC Dropout：

| 配置 | 32 步 RMSE | 160 步 RMSE |
|---|---|---|
| 固定 32 步 | 0.314 | 0.429 |
| 固定 8 步 | 0.274 | 0.458 |
| RWM-U | 0.321 | 0.419 |
| **自适应 anchor@2** | 0.288 | **0.389** |

ANYmal-D 达到相近最终性能时约减少 **72% rollout computation**。

> **训练 rollout 不应被设成全局超参。** 早期误差大时适合短程截断，置信度提高后再扩展。

**集成分歧必须被校准成可解释的不确定度，不能把方差直接当概率。** 工程要求：
- 独立初始化或 batch permutation、BN running statistics 隔离、共享主干的轻量头
- 用 calibration set 映射方差到预期误差
- 报告 ensemble size、diversity、平均预测误差、OOD detection AUROC
- **若集成预测近乎一致，即使预测错误，分歧也可能接近零** → 还应加入重建误差、动力学残差、先验—后验 KL、观测似然等辅助信号

**悲观值估计**（安全关键部署）：

```
Q̂_pess(z, a) = Q̂(z, a) − β · sqrt( Vâr(Q(z, a)) )
```

**只有不确定性下降到阈值以下时，才允许扩展想象深度。**

**低不确定子空间规划**（arXiv:2610.26979，CoRL 2026 Workshop）：利用 SIGReg 的 latent marginal 约束和 Gauss-Markov 假设拟合线性转移 A，证明其协方差无需额外参数；**约束 A 为 normal matrix**，可让同一特征基跨时间步保持稳定。规划目标限制在前 k 个最小不确定方向。2D navigation 上相对普通 ℓ₂ 成本最多 **+54.7 分**（仅六个环境，不能外推为通用机器人结论）。

**UA-NWM**（arXiv:2608.05597）：把 plausible futures 表示在不确定子空间中，把预测—目标差异分解为"可由不确定解释"和"不可解释残差"两部分，**只使用后者评分**。

### 7.10 长时分布漂移：LongForcing

**问题**：长时 rollout 的最大失效不是第一帧变差，而是**预测分布逐步漂移到训练分布之外**。短程 teacher forcing、短程因果 ODE 蒸馏和短程分布匹配，都无法直接约束长程联合路径。

**方案**：保留短程 teacher forcing 和因果 ODE 蒸馏，**只在最终分布匹配阶段把真实分数 teacher 替换为扩展时域双向 teacher**，以监督学生自 rollout。无需修改学生架构，也不增加推理成本。

**量化结果**：VBench Quality **85.52**；WorldRoamBench 60 秒 action score **+23.9 分**；演示最长 **24 小时**交互 rollout。

**部署测试必须覆盖数倍于训练窗口的时域**：
1. 1×、2×、5×、10× 训练窗口的 rollout
2. 对象身份、运动方向、相机轨迹和动作因果指标
3. 模型重启、场景重访与遮挡后恢复
4. 长程人类偏好与自动指标的相关性
5. 视觉质量、状态准确性和控制成功率**分别统计**

**实现路径**：从 student rollout buffer 开始，保留不同 horizon 的自生成片段，用扩展时域双向教师计算分布匹配损失；warmup 阶段先维持短程教师，再逐步扩大监督 horizon；加入**跨 chunk consistency loss**，避免只在末状态对齐。

### 7.11 空间持久记忆：World-T3

把自回归视频世界模型的过去场景写入**按相机位姿索引的快速权重**，用递归最小二乘在线吸收新视觉特征。只读场景的位姿记忆使存储和每步计算**不随 rollout 增长**。

- 重访 PSNR：13.52 → **18.31 dB**
- 绝对旋转误差：3.344 → **1.075**
- 单张 B200、1280×704：**20.6 FPS**
- 后续经 dual-teacher distribution matching 蒸馏为少步生成器

> LongForcing 解决监督 horizon gap，World-T3 解决空间 revisit，**二者不等价，实际应用中通常需要同时使用**。

### 7.12 显式 4D 状态：AEON

AEON（2026-10-20，arXiv:2610.28631，NeurIPS 2026）解决视频世界模型"换视角就崩"的结构性缺陷。

**两阶段**：
1. 4D reconstruction model 从单目视频预测 4DGS、相机位姿和 RGB/深度/法线监督
2. domain adapter 把生成视频 VAE latent 翻译为重建式 4D latent，蒸馏训练 student 4DRM

每个 4DGS 原语包含：参考时间、持续可见期、线速度、角速度 → 可沿预测相机轨迹渲染，支持场景级动态、相机轨迹和编辑。

**可复用价值**：把"视频生成"与"显式世界状态"拆为两层——视频潜空间负责高维外观，4DGS 负责持久几何。

**⚠ 论文没有提供机器人真实 rollout、物理接触或真实控制基准**，只能归为"已验证渲染/世界表示，非完整具身验证"。

### 7.13 统一多模态：五类接口，不是一个 embedding 层

> 如果统一只发生在 token ID 层，而时间因果、空间几何和动作语义仍彼此隔离，它只是"共同嵌入"，不是"统一世界模型"。

| 接口 | 必须保留的信息 | 典型失效 |
|---|---|---|
| **语义** | 跨模态含义、任务指令 | 同词不同模态语义错配 |
| **时间** | 因果顺序、采样频率 | 视觉慢、触觉快导致错位 |
| **空间/几何** | 位姿、深度、拓扑 | 换视角后场景不一致 |
| **状态/动作** | 传感器状态与本体动作 | 跨本体控制无法迁移 |
| **可信度** | 有效性、缺失与不确定度 | **把缺失当成零或确定事实** |

**NExT-OMNI 的离散 flow matching（DFM）**：视觉、文本、音频统一到离散 token 序列，并行去噪。

```
L_DFM = E_{t,x₁,x_t} [ −Σ_i log p_{1|t}(x_{1i} | x_t) ]
```

共享 Transformer 在每层执行多模态自注意，轻量模态专用头负责解码。相较自回归，DFM 从完全损坏序列开始并行迭代，更适合同时处理理解和生成。

**触觉模态的必要性**：触觉为不可直接观测的接触状态提供关键补充。Being-H0.8 的通用触觉编码器将异构触觉信号统一，附带位置、拓扑、左右手和**有效性标记**——**模态有效性标记尤其重要**，它区分"没有传感器读数"和"读数确为零"，避免把观测缺失错误解释为无接触。

> **伪标签只能填补缺失，不能创造真实力触分布**，可能系统性漏掉压力、滑移和材料变化。

**跨本体动作对齐**：人手、灵巧手和夹爪不需要具有同一骨架，但"接触、抓握、释放"等语义相近动作必须共享接口。

### 7.14 完整训练损失

```
L = L_recon
  + β · D_KL( q(z_t|o_t) ‖ p(z_t|z_{t−1}, a_{t−1}) )
  + L_1step
  + L_hstep
  + λ · L_mech
```

**方向性动作监督 L_mech 应针对已知物理关系设置**（机械开关、接触建立、速度方向、压力变化），**不应给全部状态维度虚构因果**。

### 7.15 想象训练与 MPC 部署

**想象 depth 应按 horizon curriculum、uncertainty gate 或 adaptive rollout 确定，而不是固定超参。** 候选 rollout 采用 **8—32 条**并行生成；**价值网络只训练真实轨迹**，避免完全在模型生成数据上退化。

**部署闭环（receding-horizon MPC）**：

```
1. latent video—action 模型生成 0.5—3 秒动作 chunk 及多个候选未来
2. uncertainty-aware scorer 对候选排序
3. 执行前若干动作；抑制因高认知不确定性或安全约束触发的 rollout
4. 从新观测重新编码 posterior —— 截断幻觉链
5. 对 3—10 秒子目标用 MPC，只在关键里程碑做完整长程规划
```

**幻觉循环的统一对策**：posterior reset、真实观测 re-anchor、短程 receding-horizon planning、扩展 horizon teacher supervision、空间持久记忆、校准后的 rollout termination。

## 第 8 章 L5：适配器栈与参数进化

### 8.1 定位与形式

外挂权重不直接修改主干，而是以**depth-wise 低秩适配器**形式存在：

```
ΔW_t = B_t · A_t,    A_t ∈ R^{r×d_in},  B_t ∈ R^{d_out×r}
```

- `t`：循环深度索引，**每个迭代步一组独立适配器**
- `r`：秩，建议 8—32

参数量 `T × 2 × r × d`，相对主干可忽略。

### 8.2 按深度分工

| 深度区间 | 职责 | 训练数据来源 |
|---|---|---|
| `t ∈ [0, T/3)` | 解析与召回 | 会话轨迹中的检索成功样本 |
| `t ∈ [T/3, 2T/3)` | 整合与推演 | 完整推理链 |
| `t ∈ [2T/3, T)` | 校验与精修 | 校验日志中的 REJECT / CORRECTED 样本 |

**长期目标**：校验逻辑逐步蒸馏进后段适配器，使抗错误能力从"每次推理外挂执行"变为"模型内生能力"。

### 8.3 剧集隔离：ReTTT

**ReTTT**（2026-10-08，arXiv:2610.23942）：在剧集内从行动—观察—反馈构造 "lesson" 并显式保存在记忆里，同时**冻结主干，仅更新 episode-local LoRA**；适配后的模型既生成后续行动，也生成后续反思，让策略适应与经验构造相互耦合。

**量化结果**：两个模型家族、ALFWorld / ScienceWorld / SWE-bench Lite 共 6 个设置上，优于轨迹式测试时训练，**成功率最高 +12.14 个百分点**；冻结反思的对照表明，反思策略自身适应带来 **+7.14 pp** 收益。

**⚠ 关键警示**：这是特定智能体评测中的已验证改进，**不能外推为通用无损终身学习**。必须以 episode 边界隔离更新，**不能把临时 LoRA 永久合并回主干**。

**模板**：
```
进入新任务 → 复制冻结基础模型 + 空 episode LoRA
          → 滚动经验经反思、验证后产生 lesson batch
          → 任务结束且独立验证通过后才允许离线合并候选
```

### 8.4 提交前验证：Settlement 三道闸

**核心问题：TTT 的最大风险不是梯度算错，而是模型用自己生成的偏差文本训练自己。**

Settlement（2026-10，arXiv:2610.05076）在 128K token 流上测试三种 TTT-E2E 配置（125M、760M、3B）及 Adam 更新 Qwen3-4B 权重，发现**对自身生成文本的保留更新会损害独立人类书写文本的预测**。

三项因果实验：

| 实验 | 结论 |
|---|---|
| **Fixed Generation** | 冻结生成器后消除 125M 和 760M 上超过 **98%** 的损害 |
| **Recorded Replay** | 区分"读取退化文本"与"在其上更新"造成的损害 |
| **配对单步分析** | 候选更新更适配源轨迹，却使新真实文本更差 |

Settlement 在提交前以**独立真实文本**评估候选状态，125M 和 760M 的端点差距分别为 0.07 和 −0.02 nats，同时保留真实文本适应。

**三道闸（强制）**：

```
① 输入证据门：来源独立、可执行性、事实版本
② 候选更新隔离：临时副本或临时适配器
③ 提交前验证门：保留的真实样本 / 独立真实样本 / 任务验证集
```

**提交条件（必须同时满足）**：

```
Δ_new   >  0          新任务收益为正
Δ_indep ≤  ε          独立真实分布损失回归
Δ_retain ≥ −δ         保留能力不退化
高风险动作验证通过
```

> **任何"损失下降"都不能单独构成提交理由。** 对模型生成的中间推理，只可作为内部临时状态，**不能成为永久监督信号**。

### 8.5 顺序扩展的吸引子陷阱

**Sequential Test-Time Scaling**（2026-09/10，arXiv:2609.39632）在 27 个方法—模型—基准组合中发现：**53.8% 的顺序扩展轨迹在四次迭代内进入"吸引子"**。

简单模型混合使吸引子命中率平均下降 **21.2 个百分点**，并让递归自聚合准确率至少提高 **2.2 个百分点**。

**对策**：
- 不让一个 rollout 无限制修改共享策略
- 设置 beam 多样性阈值、跨轨迹答案覆盖率
- 模型 / 温度 / 提示层面的混合
- 连续两次迭代答案集合几乎不变时停止
- 未达独立验证门槛，不把当前轨迹提升为长期经验

### 8.6 低秩更新的步长律：PaLoRA

**核心洞察：低秩更新不是天然低干扰。** 即使施加 null-space 投影，有限精度更新仍会在多个历史知识方向泄露。

**理论步长律**：

```
s* = sqrt( R / c )
```

其中 R 是过去更新的**有效秩**。

**算法组合**：历史知识自适应 SVD 截断 + 梯度投影到旧任务 nullspace + rank-aware 自适应 pacing。50 个任务的 ImageNet-A/R 上约 **+4 个百分点**。

**证据等级：C-理论/受限视觉实验。** 不是 LLM 长期智能体记忆的已验证答案。

**可复用组件**：
- 持续记录每个 LoRA 的 Gram / Fisher / 激活协方差谱
- 动态估计有效秩
- 合并或训练前按历史累积秩调整步长
- 保留旧任务的 small validation set
- **禁止把"低 rank"直接等同于"可忽略遗忘"**

### 8.7 输出头遗忘的工程防御

**Deafening Silence**（2026-10，arXiv:2610.09835）：灾难性遗忘集中在新语料中很少出现的 token 的**输出 embedding**——缺失 token 收到单向 softmax 梯度，而 Adam 二阶矩归一化把它放大为完整规模更新。

**对策：仅在输出投影层提高 Adam epsilon。**

**量化结果**（八个设置，160M—12B，四个模型家族）：
- 降低 **39.4%—67.9%** 的遗忘，不损害目标学习
- 与回放组合在 Qwen/Korean 上实现 **79.8%** 的保护
- 能拯救因发布头 LoRA 造成的 **23 倍**遗忘激增
- **事后编辑漂移行只能恢复不足 5% 的遗忘** → 干预必须在训练时发生

**可立即复用**：按词表覆盖缺口预计算风险、提高输出投影 Adam epsilon、保存输出 embedding 检查点、把新语料 token 频率纳入采样。

**⚠ 不能替代回放、适配器隔离或参数验证。** 若不使用 Adam、不更新输出头或主要做 LoRA 离线合并，该结论需重新实验。

### 8.8 遗忘诊断：Accessibility Collapse

**灾难性遗忘不仅是表示被抹去，也可能是"表征仍存但不可访问"。**

sequential CIFAR-100 / ResNet-18 实验：任务行为准确率从 54.8% 跌到 0%，但**线性探针仍保留约 76% 的原始表示信息**；只重训最终分类器可恢复 **75.7%**；早期与中间层信息较可恢复。

> **简单的"在线准确率下降"不能定位遗忘。**

**诊断四件套（定期在隔离验证流上执行）**：

```
□ full evaluation
□ head-only re-training
□ linear probing
□ layer-wise sensitivity
```

**只有当 head 恢复和 probe 都无法恢复时，才把问题判定为真正知识擦除。**

### 8.9 模型编辑契约

**EngramEdit**（2026-10-08，arXiv:2610.10533）：先为某事实的多种表达计算能让模型预测新值的目标记忆表示，再联合更新被这些表达激活的共享 n-gram embedding；**频繁复用的 embedding 更新受到更强惩罚**。

**第一阶段**——学习共享扰动：

```
δ_i* = argmin_{δ_i} (1/|X_i|) Σ_{x∈X_i} L_NLL(M_{δ_i}(x), o_i*) + R_target(δ_i)
s.t.  ‖δ_i‖² ≤ ρ ‖h_i(x_i)‖²
```

**第二阶段**——构建激活矩阵 A、更新矩阵 U、目标差矩阵 B：

```
U* = argmin_U ‖AU − B‖_F² + Σ_j λ_j ‖u_j‖²
λ_j = λ_reuse · w_j + λ_ridge
```

其中 w_j 综合 n-gram 长度与语料频率。

**量化结果**：CounterFact 上 99.5% Efficacy、97.0% Generalization；ZsRE 与多跳 MQuAKE 领先部分基线。**但通用能力仍有轻微下降**（如 MRPC F1），少数记忆碰撞会影响无关预测。

**⚠ 这是特定条件记忆架构下的结果，不能直接复制到普通 LoRA 或全参数模型。**

**LadderEdit**（2026-10-08，arXiv:2610.11160）：先以低成本低秩 sketch 保存每个编辑，再用 probe prompt 检查 **rewrite、generalization、locality** 是否满足；通过者保留低秩 sketch，失败者沿 **rank ladder** 提升直至满足契约。

**量化结果**：LLaMA-3-8B / Mistral-7B / Qwen2.5-7B 上，相对 exact per-edit LoRA **5.2 倍内存节省**，**5 万次顺序编辑后仍有效**。

**统一编辑接口**：

```
edit_request = {
  subject, old_value, new_value,
  language_variants[], scope, effective_at,
  source, risk_class, contract
}
```

**验证器必须运行**：rewrite prompts、paraphrase/generalization prompts、locality neighbor prompts、multi-hop composition、global capability suite、高风险执行验证。**只有所有硬约束通过才生成新 revision。**

> **删除事实应成为 tombstone 编辑，而非从训练数据物理抹除。** 这既支持审计，也支持未来重新验证。

### 8.10 推理 trace 的内存压缩

**Prefix Sliding**（2026-08，arXiv:2608.26070）：保留关键指令和工具所在前缀以及最近几千 token 窗口，丢弃中间推理 token。

- 不训练即可使现有模型加速 **3 倍**且保持性能
- RL 训练后可扩展到超过十万 token 的推理轨迹
- 优于 token 摘要或普通滑动窗口

**⚠ 定位限制**：它解决 KV/token 占用问题，**不是"长期经验是否正确"的问题**。可复用为在线推理的短期内存预算器；被丢弃的中间推理若值得保留，应经过抽象器转为结构化 lesson，**而不是再塞回长期向量库**。

## 第 9 章 L6：巩固引擎（睡眠期）

### 9.1 设计范式：把计算移到离线

**LLM Sleep**（arXiv:2605.26099，基础架构范式）：当在线上下文填满或某个会话/任务完成，系统进入离线睡眠窗口，对累计上下文执行 **N 次循环处理**，用学到的局部规则更新快速权重，随后清空或压缩在线 KV cache；**唤醒阶段仍保持单遍预测的低时延**。

- N 越大，对更深推理样本的收益越大
- 测试包括元胞自动机、多跳图检索和一个数学推理任务

**关键工程原则：离线算法可以任意复杂，唤醒路径必须简单、可缓存且低延迟。**

**对本架构的适配**：不必要求引入 SSM。可把快速权重视为一种离线压缩状态，替换实现为"临时 LoRA + summary state + structured graph cache"。

### 9.2 ConsolidationJob 定义

**离线引擎的最小工作单元应是版本化 batch，而不是实时更新函数。**

```
J = ( events[t₀, t₁],
      active_memory_root,
      candidate_graph,
      environment_snapshot,
      validation_suite,
      budget,
      parent_commit )
```

**八步流程**：

```
1. 从不可变事件日志读取新动作、观察、失败、版本变更和反馈
2. 事件去重、排序、归因并校验来源
3. 可验证结果转为 canonical fact / lesson，其余保留为 raw episode
4. 在隔离内存图上执行：冲突键匹配、生命周期迁移、结构化抽象、GC
5. 训练 episode LoRA / 快速记忆更新 —— 只在候选副本上
6. 在独立真实样本、旧任务保留集、跨会话任务集、可执行验证集上评估
7. 通过幂等事务提交新 active 根，生成回滚指针
8. 严格失败或回归超阈值时丢弃，不覆盖线上状态
```

### 9.3 四阶段巩固

#### 阶段 A：回放与误差定位

将历史轨迹重放进世界模型，逐步计算预测误差：

```
ê_t = ‖ ŝ_{t+1} − s_{t+1} ‖²
```

> **误差高的区段 = 模型当前最不理解的区域**，构成课程学习信号。

**关键优化**：若世界模型在隐空间内做预测，整个回放**完全在 latent space 完成，不解码回原始模态**，成本可忽略。这是本阶段可行的前提。

**产出**：按 ê_t 降序排列的误差区段队列。

#### 阶段 B：反事实分支推演

对阶段 A 识别出的高误差节点，以及"成功但高风险"的节点：

1. 采样 K 个替代动作（建议 K = 4—8，与 COUNTERMEM 的 K=4 一致）
2. 用世界模型推演每个替代动作的后果轨迹
3. 保留预测收益高于实际轨迹的分支
4. **仅经可执行环境验证（Δ > ε_adm）的修正才落库**

**价值**：从既有经验中榨出全新训练信号，无需新的真实交互。这是样本效率的主要来源。

#### 阶段 C：巩固与沉淀

产物按**可逆性递增**分三处落地：

| 去向 | 可逆性 | 触发条件 |
|---|---|---|
| 记忆库规则条目（playbook） | 完全可逆 | 默认 |
| 适配器权重 | 可逆，可拔 | 样本量 ≥ N_min 且 EV 通过 |
| 主干增量候选 | 不可逆 | 需人工复核 + 多轮 EV |

**默认只走第一处。** 后两处必须过门禁。

**四种子任务（正交）**：

| 任务 | 内容 |
|---|---|
| **纠错** | 重放带标签反馈，只更新临时副本，运行冲突和来源规则 |
| **抽象** | 对成功轨迹簇抽取 workflow，对失败簇抽取反模式，生成 typed node 与 contrast edge |
| **压缩** | 低价值细节入冷归档，共享结构提升为高层节点，对 LoRA 做 rank ladder 验证 |
| **多样化回放** | 按难例、边界条件、过期条目、已撤销条目和新版本数据采样 |

> **避免只重放近期成功。** 任何步骤都必须记录输入证据哈希、模型/算法版本、超参、损失和验证结果。

#### 阶段 D：系统偏差修正

若世界模型在某一类状态转移上**持续**预测错误，这不是噪声，而是模型的结构性缺陷。

用集成分歧区分可约/不可约（见 §7.9），只对可约部分投入容量。

### 9.4 发现树模拟器：Dream-RSI

**核心洞察：RSI 的真正瓶颈从"产生新候选"转向"评估新候选"。** 用历史作为模拟器绕开重复在线反馈。

**三阶段闭环**：
1. 在线探索由当前策略驱动 agent 扩展 discovery tree
2. 把树蒸馏成**可复用模拟器池**
3. agent 在模拟器内生成并评估大量替代探索策略，随后把改进策略部署到下一轮在线探索

**策略选择目标**（同时考虑帕累托发现质量和并行代价）：

```
V_i^m = (1/B_i) Σ_{j=1}^{L_i^m} (ā_i^{j,m} − ā_i^{j−1,m})(B_i − n̄_i^{j,m})
        − λ · (1/|R|) Σ_{ρ∈R, n>0} k_{i,ρ}^{m,*} / n_{i,ρ}^m
```

- 第一项：累积发现质量的归一化超体积
- 第二项：惩罚过度串行化

**量化结果**：Lasso path solver 上相比 SimpleTES 最多减少 **162× agent calls**；另一设定下平均运行时间 3587.1 → 2931.0 ms，agent calls 550 → 317。

**⚠ "最多 162×"必须带基线读**：同一 Lasso 任务相对 Recursive Fixed Exploration 只有 1.7×，说明节省高度依赖弱基线和任务结构。

**可迁移组件**：discovery tree schema、状态快照、确定性回放接口、策略候选生成器、质量—成本帕累托选择器、隐私/安全访问控制。

### 9.5 幻觉循环防御（三条硬约束）

**问题**：世界模型想象轨迹 → 在想象数据上训练 → 偏差累积 → 想象更离谱，形成正反馈。**模型越强大，越可能生成高似然但低物理正确性的轨迹。**

| # | 约束 | 具体值 |
|---|---|---|
| **1** | **混合比锚定** | 想象生成数据 : 真实交互数据 ≤ 1 : 3（硬编码断言） |
| **2** | **周期重校准** | 每 N 轮巩固，必须用纯真实数据重新训练一轮作为锚点 |
| **3** | **漂移监控** | 持续追踪想象轨迹分布与真实轨迹分布的 KL 散度，超阈值立即停止阶段 B |

**补充对策**：real-data warmup、model ensemble pessimism、reward uncertainty、真实 rollout replay、sim-to-real validation、将想象数据比例逐步退火。

### 9.6 经验年龄闸门

**离线批处理必须防止把短期经验永久化。**

```
新 lesson → episode / provisional 层
         → 经过不同环境、不同任务模板或不同时间窗口
            至少 K 次独立正向验证
         → 提升为 stable
```

- 仅一次成功 → 只能作为 weakly validated
- 存在反例或来源撤回 → 自动降级
- 高度具体、复现成本高、适用域窄的经验 → **保留在原始 episode 层，不必抽象成全局规则**

### 9.7 触发条件与资源约束

**不使用固定定时，改用阈值触发**：

| 触发项 | 阈值 |
|---|---|
| 集群资源占用率 | 低于安全水位持续 ≥ 15 分钟（**硬约束，未满足不得抢占在线资源**） |
| 距上次巩固时长 | > 24 小时 |
| 未处理会话数 | ≥ 5 |
| 校验分歧度均值 | 超过历史基线 1.5 倍标准差 |

**执行与观测**：

```
PENDING → RUNNING → COMPLETED / FAILED / CANCELLED
```

- 运行中必须能**流式订阅事件**：当前读取哪条记忆、正在写入什么条目
- 必须支持**随时取消**
- 完成后保留完整执行记录，可事后复盘
- 支持传入 instructions 字段（≤ 4096 字符）指定本次巩固的聚焦方向
- **输入记忆库不被修改**，输出为新库 → 可对同一份记忆执行多次不同聚焦的巩固

## 第 10 章 L7：评价、验证与门禁

### 10.1 定位

**评价器不是可选项，是前置依赖。** 没有可靠的自动评分，"进化"退化为随机游走。

### 10.2 独立评估器

| 组件 | 职责 |
|---|---|
| **固定评测集** | 覆盖核心能力的回归集，规模 ≥ 5000 条，多次巩固间保持一致 |
| **评分标准（rubric）** | 结构化描述"什么算成功"，支持主观质量维度 |
| **独立评估器** | **在自己的上下文窗口内评分，不读取被评对象的推理过程** |

> 独立评估器必须在独立上下文中运行——否则会被被评对象的推理链条说服。

### 10.3 四类内部校验原语

对循环核内部，建议加入：

| # | 原语 | 机制 |
|---|---|---|
| 1 | **跨轮答案一致性** | 连续两轮答案相同且状态变化小 → 提升停止置信度 |
| 2 | **约束守恒** | 数值等式、单位、集合成员、程序执行结果 |
| 3 | **反事实检查** | 对同一状态施加最小扰动，观察答案是否改变 |
| 4 | **独立复核头** | 用与循环主干**不同的浅网络**重新读取最终状态 |

> 所有内部检查都应记录可信度，**不应让模型仅凭自己的语言输出判断自身正确**。

### 10.4 外部可验证性为主

**核心原则：把"答案正确性"与"推理过程可信度"拆成两条路径。**

**DAS / DAS-Wave**（2026-09-28，arXiv:2609.34538）：
- Q/K 比 V 更早接近最终深度表示 → 让**浅层 drafter 读取已验证前缀的成熟 Value**，可提升 draft-target 一致性
- DAS-Wave 组合深度异步读取、携带式并行精炼、渐进块增长、**独立 full-depth verifier**
- 四个循环模型、数学和代码负载上，相对同栈全深度自回归解码取得 **4.00—6.96× 平均吞吐提升**

**⚠ 关键限制**：
- **成熟 V 只在 token 已被接受或显式标记为已验证时复用**；未提交的 speculative token 不能把浅状态当成熟
- **verifier 与 drafter 共享偏差**：若都来自同一骨干，错误可能系统性重复 → 应加入约束求解、检索证据、独立模型或多视角聚合，而不是只生成多条相似答案

### 10.5 风险分级

| 任务类型 | 可用手段 | 不可声称 |
|---|---|---|
| **可形式化**（数学、代码、约束满足） | 确定性验证器 | — |
| **检索依赖** | 证据支持率 | — |
| **常识 / 创作** | 概率校准 | **不能声称"已验证无误"** |

> **若输出不可验证，应明确返回置信度、证据和不确定性，而不是把循环次数当成可靠性指标。**

### 10.6 失败归因：必须显式建模

**Recuris**（2026-08，arXiv:2608.24876）最有说服力的证据是失败归因准确率：

| 归因方式 | 准确率 |
|---|---|
| 从结构化轨迹定位故障组件 | **64.8%** |
| 从任务最终结果直接归因 | **13.0%** |

**架构含义：不能把整个长轨迹压成一个 reward。**

**三状态记忆架构**：
1. 瞬时工作记忆（当前目标、约束、观测）
2. 可验证情景状态（已完成事件、对象状态、因果假设）
3. 跨任务经验库（成功轨迹模板、技能程序、反例）

**两级验证**：
- 写入前验证"信息是否足够可靠"
- 使用后验证"技能是否改善目标且不破坏其他约束"

**更新方程**：

```
M_{t+1} = Merge( M_t, Δ_t ;
                 admit(e_t, Δ_t),
                 validate(e_t, M_t, D_holdout) )
```

只保留通过验证的增量，并为每次写入记录来源、任务、失败证据、回滚版本。

**量化结果**：四个长程基准、10 个模型中，37 个模型—基准组合有 35 个成功提升；任务越长优势越大，最长任务 **+32.2**，常见长程失败最多下降 **80%**。

**⚠ 论文未公开所有模型—基准失败细节，也未报告完整 token 与验证成本。这些增益应视为 harness 层验证，而非权重自改进。**

### 10.7 可执行世界程序：Schema

**核心主张：陌生环境中的学习对象应从叙述性经验改为可测试、可证伪的程序。**

Schema（2026-09-30，arXiv:2609.39140）维护持久程序工作区，用程序表示对环境机制的理解。

**一致性约束**：

```
∀(o_i, a_i, o_{i+1}) ∈ H :  ô_{i+1} = P(o_i, a_i) ≈ o_{i+1}
```

若预测与观察不一致，该程序成为反例，被修改或丢弃；**通过验证的程序才进入规划**。

**量化结果**：同一基座模型下，ARC-AGI-3 的 RHAE 从 58.7% 提升到 **99.2%**，解决 DiG-bench 全部公开游戏，MazeBench 达前 50 名人类玩家中位数。

**⚠ 解读限制**：ARC-AGI 是有意弱记忆化、强规则发现的抽象谜题，不能直接外推到开放视觉、物理或社会交互。

**真正结论**：当环境规则可符号化时，**让规则可编译、可回放、可被反例推翻，比在长上下文中堆自然语言笔记有效得多**。

**世界模型应拆成三层，而不是一个统一潜向量**：

| 层 | 职责 |
|---|---|
| 连续感知—运动世界模型 | 像素、音频、触觉、动作 |
| 对象—关系状态 | 可持久化和可查询的事实 |
| 可执行转移程序/动力学程序 | 反事实预测、规划、可解释验证 |

**⚠ 真实环境存在噪声、部分可观测和高维连续参数，程序空间可能不可枚举** → 此时应使用概率程序、符号—神经混合程序或带置信区间的程序，**而非要求单一确定性规则**。

### 10.8 双层递归：AIDE²

**结构**：
- 内层 agent：在固定预算内完成任务
- 外层 meta-agent：**重写内层 harness**——搜索、上下文、反馈和记忆代码
- 只有**私有 held-out 评分严格提升**的候选才成为新 incumbent

**量化结果**（8 天自主运行）：100 节点轨迹树，7 个改进被接受，私有评分 0.703 → **0.778**；最终 agent 在四个未用于选择的外部基准上匹配或超越人工调优两年的 AIDEhuman；WeatherBench 2 forecast skill 0.404 → **0.793**；系统自主发明历史压缩、bug-rate-gated 失败记忆；OOD GPU kernel 任务中奖励破解从 55% 降到 32%。

**⚠ 不能被解读为"模型自己变成更聪明的模型"。** 改变的是代码中的搜索策略和上下文管理，模型、评测器、任务接口可以保持冻结；选择仍依赖私有验证和固定预算。

**可复用组件**：双层优化、版本化 incumbent、不可见 holdout、成本封顶、agent calls 与 solution execution 共同计价的预算、自动化 prompt/context/history 压缩。

### 10.9 原子算子共享词汇表：OpenMLE

**Frontis-MA1 / OpenMLE**（2026-07-30，arXiv:2607.28568）：由可验证环境的 OpenMLE-Gym、执行反馈驱动的 OpenMLE-RL 与长程搜索 OpenMLE-Evo 组成。

**四个原子算子**：Draft、Improve、Debug、Crossover。模型以去重后的执行反馈 SFT/RL 学习，再把这些算子组合成长程元进化搜索。

**量化结果**：35B 模型在 MLE-Bench Lite、固定 12 小时每任务、单 RTX 4090/12GB 条件下，奖牌均值由基线 39.39% 提升到 **60.61%**，Evo-Max 达 **71.21%**。

**NatureBench Lite 对照（最有诊断性）**：
- 框架固定，换入训练模型：Match-SOTA 50% → **70%**
- 模型固定，换入 Evo 框架：Match-SOTA 20% → **50%**

> **训练与搜索是互补而非二选一。**

### 10.10 晋升门禁规则

候选产物晋升必须**同时**满足：

```
1. 固定评测集整体得分不低于当前线上版本
2. 无任何单项能力下降超过 δ（建议 δ = 2%）
3. 错误率指标不上升
4. 人工抽检通过率 ≥ 95%
```

**任一不满足即拒绝晋升，不做例外。**

评分不达标时，评估器需**指出具体需修改之处**，返回重做一轮，直至达标或达到最大迭代次数（建议 ≤ 5）。

## 第 11 章 多智能体编排与跨体经验汇聚

### 11.1 定位

单个智能体的经验上限有限。多个智能体在同一组织内工作时，应共享一份经验手册。

**⚠ 重要限定**：2026 年 10 月由 DeepMind Institute 联合评论推动的"AGI 是社会性多智能体系统"观点，更适合作为**治理与设计原则**，而不是已验证架构理论。

**工程含义比"取代 Transformer"更实际**：能力边界正在从模型个体转向系统界面。单模型负责低延迟感知与局部策略；多个 specialist 负责长程规划、科学验证、代码执行；人负责定义目标、预算和验收。

> **它不支持"把更多 RL 压入一个模型就会自动产生 AGI"的推断。**

### 11.2 共享 Playbook 结构

```
Shared Playbook
  ├─ 全局规则（所有智能体适用）
  ├─ 领域规则（按任务类型分区）
  └─ 冲突区（待消解的矛盾条目）
```

### 11.3 冲突仲裁优先级

多个智能体贡献的经验冲突时，按以下顺序裁定：

```
1. 来源权威度：authority > user > synthesized
2. 支持该条目的独立智能体数量
3. 时间远近
```

### 11.4 溯源要求

每条共享规则必须记录：来源智能体、来源会话、采纳时间、生效范围。

> **不可溯源的经验不得进入共享层。**

### 11.5 失败传播控制

**多智能体也会放大错误传播，因此不能用社会隐喻替代验证。** 多模型内部辩论并不保证真相；冗余角色增加算力、上下文传输与一致性风险。

**可复用组件**：角色能力矩阵、消息 schema、共享世界状态、冲突解决规则、独立 verifier、可撤销 transaction、版本化责任链、预算分配器。

**系统级评测至少应报告**：
```
总 token、wall-clock、GPU-hours、失败传播次数、
人工接管率、单位任务成本
```
**而不是只报告单模型等效能力。**

## 附录 C：关键指标定义

| 指标 | 定义 | 用途 |
|---|---|---|
| **原始召回率** | 未压缩注意力下的证据召回 | L0 基线 |
| **压缩后召回率** | 经页压缩/量化后的召回 | L2 质量 |
| **位置无关 needle 准确率** | 不同深度 needle 的准确率曲线 | 长程保持 |
| **oracle 重合率** | 选中 token/页与 oracle 选择的重合 | **索引质量的核心指标** |
| **每额外轮边际收益** | 第 r+1 轮相对第 r 轮的质量增量 | 退出决策 |
| **固定点残差** | ‖h_{r+1} − h_r‖ | 收敛检测 |
| **退出深度分布** | 各 token 停止轮次的分布 | 计算预算 |
| **失败归因准确率** | 定位到故障组件的准确率 | 巩固引擎质量 |
| **注入精准率** | 注入且被采纳的比例 | 记忆门质量 |
| **误注入率** | 注入但无助于任务的比例 | 记忆门质量 |
| **想象误差 E(C)** | 世界模型多步预测误差 | 部署能力代理 |
| **方向一致性** | 预测响应与已知物理方向的一致率 | 机制正确性 |
| **负迁移率** | 应用经验后性能下降的比例 | 经验图质量 |
| **首次错误时间** | 连续运行中首次错误的时间 | 长期稳定性 |
| **错误持续时长** | 从错误发生到恢复的时长 | 恢复能力 |
| **单位任务成本** | token + GPU 秒 + 验证调用折算 | 系统级效率 |

## 附录 D：三条必须写在架构文档首页的红线

> **红线一：不要用"循环次数增加"或"潜态存在"作为可靠性证明。**
> 必须测错误恢复率、约束验证和跨轮因果消融。

> **红线二：不能用理论 FLOPs 或理论 KV 存储替代端到端评测。**
> 必须报告同一硬件上的 TTFT、TPOT、吞吐、并发和能耗。

> **红线三：不能把小模型结构化任务、语言建模损失和开放域下游准确率混成一个 scaling story。**
> 三者是不同目标。同理，扩散损失效率、ARC 成本帕累托、MLE 奖牌率、Terminal-Bench 分数、NIAH 召回率不可汇总为单一排行榜。

## 附录 F：结论

本季度最可靠的前沿信号不是"单一模型奇点"，而是**计算与智能都开始分层**：

- 高效状态算子、局部时空卷积、少量全局注意力和稀疏专家共同承担长上下文
- 任务级自进化把历史、记忆、harness、探索策略和世界程序变成**可验证的递归对象**
- 循环深度把推理深度从参数量中解耦，成为推理时可调节的计算量
- 世界模型从"生成未来画面"转向"在想象中稳定决策"

**最应坚持的一条设计哲学：可学习的是可验证的变化，不可验证的变化只能作为候选。**

窗口内证据一致指向四点：

1. 检索必须带生命周期与精准门
2. 冲突必须有状态而非覆盖
3. 参数适应必须在隔离空间
4. 离线巩固必须承担昂贵重放和压缩

与此同时，**没有任何论文证明一个通用智能体可以在开放环境中无监督地持续学习多年而不漂移**。对高风险决策，仍应以可执行验证、外部权威源、权限和人机确认作为不可绕过的边界。

**最终风险不在架构不够激进，而在缺少验证、归因和回滚。** 应把"可审计性"设为一等架构目标：任何自我修改都必须有提案、证据、私有评估、成本、影响和回滚记录。
