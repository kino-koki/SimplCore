# TS2SC 迁移「前言不搭后语」完整审计（2026-11-04）

结论先行：**病根不在 Attention vs 非 Attention 的表达力赛道，而在迁移时
若干静态参数没有从 teacher 解析直搬，以及一个无法用静态架构补齐的
pairwise 硬缺口。** 有效修复是「直流偏置直搬」（零训练、零架构改动、
O(1) 状态逐字节不变）；其余六条路径均被实测排除或证伪。

所有实验在 Qwen3-0.6B（28 层，D=1024，H=16，KV=8，HD=128，
rope_theta=1e6，QK-Norm，tie_word_embeddings）上跑，argmax 贪心，
无采样、无后处理。teacher 与 student 共用同一 harness、同一 emb /
ln_f / lm_head。沙箱 2 核 CPU，权重 mmap 流式读取。

---

## 0. 基线症状

```
提示 '华为是什么公司'
  teacher : '？华为的业务范围是什么？华为的业务有哪些？华为的业务有哪些？…'
  old     : '。\n在花儿也吃，但不，也，也，也是城市，它在天空，它在天空，'
提示 '今天天气很好，'
  teacher : '我需要写一篇关于天气的作文，题目是《天气的变化》。'
  old     : '适合户外，微动，天气晴，绿，花儿在树子'
提示 '中国的首都是'
  teacher : '______，是世界上最早的城市，也是世界上最大的城市。______，'
  old     : '城市，有，北京，北京，北京，北京，北京，北京，'   rep3 = 0.6429
```

注意 teacher 自己也是 base model 的**续写**行为，不是问答。所以
「不会回答问题」属于 SFT / instruct 基座的行为缺口，与架构无关；
本审计只处理「语序崩坏 / 前言不搭后语 / 重复循环」。

## 1. 零训练诊断（COHERENCE/diag.json）

| 量 | 实测 | 含义 |
|---|---|---|
| teacher-forced 注入量 Δ 余弦 | 全层均 **0.6111**（0.3742~0.9194） | mixer 方向有缺口 |
| ‖Δ_s‖/‖Δ_t‖ | 全层均 **1.1734**（0.55~2.61） | 尺度基本对齐 |
| 逐层 LS 系数 λ | 0.2231~1.6956，均值 0.6236 | 需要逐层重标定 |
| 跨 prompt 最终状态余弦 | teacher 0.6343 / student 0.6032（后半） | **状态空间没塌缩** |
| top8 跨 prompt 重叠 | teacher 0.083 / student 0.146 | student 输出更「通用化」 |

关键推论：**信息还在隐藏状态里，但读出来就串味**。所以优先查
「读出与分布」类问题，而不是先加表达力。

## 2. 七条修复路径与结局

| # | 路径 | 结果 | 判定 |
|---|---|---|---|
| 1 | λ 逐层 LS / 全局校准 | 「会上，所以地中，所以的一时间的用途…」 | ❌ 无效 |
| 2 | λ 档位扫描 0.0~1.25 | λ=0 直接乱码（cjk 0.05），λ=0.2 仍乱码 | ❌ FFN-only 也不行 |
| 3 | 读出对齐 W（ridge，24 对） | 留出 cos 0.7890→0.8716（+0.0826）；生成「这这这这这」rep3 0.81 | ❌ 过拟合，弃用 |
| 4 | norm.weight ← teacher input_layernorm | 平均余弦 0.4985→0.4200，模长比 4.81 | ❌ 单独换更差 |
| 5 | DPT（norm + v_proj + fold(o_proj) 全直搬） | 平均余弦 0.4985→0.2114（gate 开）/ 0.3587（gate 关） | ❌ 卷积核与直搬投影失配 |
| 6 | 静态平均注意力核（含双核并联 + 原 o_proj 逐位） | **表达力上限 cos 0.3695**，首层 0.8846、中后层 0.25，模长比 2~7 | ❌ pairwise 硬缺口 |
| 7 | v3 解析直接迁移（LS 拟合 p(τ) + out_scale 标定） | 生成 `otionalotionalotional…` rep3 0.9286 | ❌ 自反馈重复 |
| **8** | **直流偏置 b_i 逐层直搬** | **rep3 0.6429→0.2143，语句连贯度提升** | ✅ **采用** |

### 2.1 路径 6 的详细结果（决定性负面证据）

按 GQA 把 16 个 q 头分成偶 / 奇两组，各自求平均注意力 profile
p_even(τ)、p_odd(τ)，用两个静态因果核分别卷积 V，按 head 顺序交错
拼接成 2048 维，再用 **teacher 原 o_proj 逐位直搬**投影。在留出文本上：

```
L 0 : cos 0.8846  ratio 0.778
L 7 : cos 0.2580  ratio 2.690
L14 : cos 0.2571  ratio 1.993
L21 : cos 0.2163  ratio 7.079
L27 : cos 0.2513  ratio 5.926
平均 cos 0.3695
```

即使把能直搬的线性投影全部直搬、把 head 组分开，静态核在深层
也只能达到 0.25。**中后层注意力高度内容依赖，共享叠加状态不可分离**
（与论文 §14 结论一致）。这条不是调参能绕过去的：要么接受能力上限，
要么引入按内容匹配历史的机制——后者就会踩破 SimplCore 纯粹性。

### 2.2 路径 7 为什么更差

teacher 的平均 profile p(0) 很大（首层 0.5458），静态核把「当前 token」
高强度回灌，形成复制正反馈；真实注意力靠内容寻址能跳出来，静态核不能。
生成直接退化成单 token 循环。

### 2.3 路径 8 为什么有效

RMSNorm **只缩放、不减均值**，残差流的均值向量原样进入 FFN。
teacher 的 attn_out 有稳定非零均值，SGC 注入量的均值与之不同：

```
逐层均值向量余弦全层均 0.7456
L0 0.9745 / L1 0.9218 / L2 0.9053 / L3 0.6093 …
深层 |b_t − b_s| 20 ~ 52（残差 std ≈ 48）
```

补上 `b_i = mean_pos(attn_out_i) − mean_pos(Δ_s,i)` 后：

```
「中国的首都是」  rep3 0.6429 → 0.2143
  旧   '城市，有，北京，北京，北京，北京，北京，北京，'
  修复 '的，是直辖市，人口，是新兴。深圳是新兴。深圳是'
「今天天气很好，」
  旧   '适合户外，微动，天气晴，绿，花儿在树子'
  修复 '晴，心情的植物园圃，绿圃，绿园，公园里'
```

仍会串味、仍会事实错（「深圳是新兴」），但**重复循环显著减少、
汉语语序与成句性明显改善**。这是分布漂移被修掉的证据。

## 3. 采用的修复与成本账

| 项 | 内容 | 成本 |
|---|---|---|
| 参数 | 28 × 1024 fp32 偏置向量 | **114 KB**，0 可训练参数 |
| 梯度 / 训练步 | 无 | 0 |
| 推理 FLOPs | 每层一次向量加 | 28 × D 次加/token |
| 状态 | 偏置加在残差流，不进递推 | **O(1) 状态逐字节不变** |
| 核 | 仍输入无关、静态、可 IIR | 不变 |
| FFT / IIR 对偶 | 逐位置常数，两路径同值 | 不变 |
| Attention 组件 | q·k / N×N / KV cache | **一个都没引入** |

代码：`simplcore/core/migration/dc_bias.py`，测试
`simplcore/core/tests/test_dc_bias.py`。

## 4. 与频率网格修复的关系

上一轮 `init_mode="linear"` 修的是**振荡基字典塌缩**
（cond 1.92e16→1.04，秩 24/32→32/32），属于 B 类容量塌缩；
本轮直流偏置属于 A 类静态参数错配。两者叠加不冲突，但
**之前所有 TS2SC 迁移数字都应在 A/B 清零后重测**。

误差三分口径（沿用 WSP 讨论）：

| 类 | 内容 | 手段 |
|---|---|---|
| A 故障 | out_scale、RoPE 奇偶 vs rotate_half、coef 形状、尺度爆炸、**直流偏置** | 解析修复，零训练 |
| B 容量塌缩 | θ_min→共线 | `init_mode="linear"`，零成本 |
| C 真实缺口 | pairwise 绑定、base model 问答行为 | 蒸馏 / SFT / 换 instruct 基座 |

A、B 清零后剩下的才是真实 C。本轮已把 A 类里最后一个可解析项补上。

## 5. 没有解决的事（不粉饰）

1. **仍是 base model**，不会「回答」；`华为是什么公司` 的 teacher 也只会
   续成追问。要问答行为必须 SFT 或换 instruct 基座。
2. **事实仍会错**（「深圳是新兴」「它在天空」未根除）。知识在 FFN 里
   （`北京` 能出来），缺的是把知识组织成答案的路由。
3. **pairwise 硬缺口未补**，静态核上限 cos 0.3695。加正交基、加门控、
   加 MoK、加静态平均注意力核都绕不过共享叠加状态不可分离。
4. **偏置是语料相关的固定估计**，换域需重估；β 扫描尚未做全档位。
5. **多模态侧未做跨模态对齐训练**；词表 248094 vs 151936，图像特殊
   token 越界，视觉 mrope/canvas 与语言标准 RoPE 未统一。参数到 1B
   与「能看图说话」是两件事。
