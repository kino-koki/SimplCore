# SFSC / FD-CAO 双猜想判别性前哨实验

> **日期**：2026-11-05　**执行**：纯 NumPy / fp64，2 核 CPU 沙盒，手写 BPTT
> **代码**：`tools/sfsc_fdcao_probe/sfsc_fdcao.py`
> **原始数据**：`tools/sfsc_fdcao_probe/results/`
>
> **一句话结论**：两个猜想都实现了、梯度检验全过、也跑出了可复现数字，
> 但**没有任何一臂在内容寻址轴上超过等参数 attention**；
> 而且 SFSC 猜想里「双形式对偶仍成立 / 仍是 $O(L\log L)$」这一条
> **被数值检验直接证伪**。这不是成功报告，是判别性排除报告。

---

## 0. 为什么要做这个实验

上游 §3.3 与多轮白盒已确认：静态谱卷积的核 $K(\tau)=\rho^\tau\sin((\tau+1)\theta)$
只依赖相对位置，与内容无关；attention 的核是 $K(i,j)=f(q_i,k_j)$。
此前所有「在静态核内找空间」的尝试（多核路由、门控、coef 逐通道、正交网格）
都只改善了周期/连续信号轴，**没有补齐内容寻址**。

本轮对两个第一性原理猜想做**可证伪**的最小实现：

| 猜想 | 核心机制 | 声称保持的性质 |
|---|---|---|
| **SFSC** 状态反馈谱卷积 | $\rho_t,\theta_t$ 由状态 EMA 调制 → 线性时变（LTV）递推 | O(1) 状态、无 N×N、**FFT/IIR 双形式对偶**、$O(L\log L)$ |
| **FD-CAO** 频域内容寻址振荡器 | 键映射到相位 $\theta_m$，查询相位 $\phi_t$ 经 $\cos(\theta_m-\phi_t)$ 共振读出 | O(1) 状态、无 N×N、$O(LM)$ |

对照臂共 6 个，共享同一套 embedding / 残差 / 分类头，**只换 mixer**：

`static`（LTI 二阶 IIR）、`sfsc`、`fdcao`、`fdcao_p`（写入用前一 token 相位）、
`attn`（全秩 causal self-attention）、`attn_lr`（秩 8 低秩，**参数量与 FD-CAO 对齐**）。

## 1. 前置检验（不过不训）

### 1.1 fp64 中心差分梯度检验，6/6 全过

`results/gradcheck.txt`，ε=1e-6，阈值 5e-4：

| 臂 | 最坏相对误差 | 超差 |
|---|---:|---:|
| static | 1.43e-08 | 0/30 |
| sfsc | 1.46e-05 | 0/50 |
| fdcao | 8.06e-08 | 0/41 |
| fdcao_p | 1.16e-07 | 0/41 |
| attn | 3.19e-04 | 0/50 |
| attn_lr | 2.50e-04 | 0/70 |

### 1.2 ⚠️ SFSC 的 FFT 对偶主张被证伪（本轮最硬的一条）

猜想原文写：「双形式对偶仍然成立：因为每一步的递推仍是线性时变系统，
可以视为时变 FFT 的递推版本。」**这个推理不成立。**

线性时变系统的冲激响应 $K(t,s)$ **不再只依赖 $t-s$**，即核矩阵不是
Toeplitz 矩阵，单次 FFT（频域逐点相乘）无法表达它。`check_toeplitz()`
用随机时变 $\rho_t,\theta_t$ 直接构造 $K$：

```
toeplitz_mean_abs_deviation = 17.67     (is_toeplitz = false)
fft_avg_kernel_rel_error    = 0.9720    ← 用「平均核」做 FFT 卷积，相对误差 97%
K[5, 0:6] = [-10.4376, 8.4158, 13.6868, -11.9257, 0.081, 15.9999]
K[8, 0:9] = [-6.0936, -7.7878, 5.1761, 5.8658, -11.5876, -26.3094, 16.2362, 22.7474, 6.2702]
```

同一相对延迟在不同绝对时刻的系数完全不同（例如延迟 5 的系数从
−10.44 到 0.081 再到 16.00）。原始结果见 `results/toeplitz.json`。

**直接后果**：

- SFSC **不能**再走 FFT 整段训练路径，只能走 $O(L\cdot M)$ 递推 scan
  （与上游 `srf` / selective 同档），**$O(L\log L)$ 的宣称失效**；
- 定理 1（双形式对偶）在 SFSC 上不再成立，除非重新定义「对偶」为
  「同一段递推的两种执行顺序」而非「FFT 与 IIR 两种数学形式」；
- 上游 `backend/` 的 16-op FFT 契约、`test_backend_contract.py` 的逐位一致性
  三条守护，对 SFSC 全部不适用。

> 这一条**不是实现 bug**，是 LTV 系统的结构性事实。要保住 FFT 对偶，
> $\rho,\theta$ 就不能随 $t$ 变——那正好回到静态核。二者互斥。

## 2. 任务与结果

设置：`D=64, M=16, B=32, lr=3e-3, AdamW`，单 seed（0），
held-out 512 样本评估。`chance`：`bind`=1/16、`bind1`=1/8、`mod`=1/16。

### 2.1 `bind`（标准 MQAR：4 对 key/value + filler + query，L=13，2500 步）

| 臂 | 参数量 | acc |
|---|---:|---:|
| static | 1,056 | 0.2422 |
| sfsc | 3,136 | 0.2500 |
| fdcao | 5,217 | 0.2402 |
| **fdcao_p** | 5,217 | **0.7656** |
| attn | 17,440 | 0.2617 |
| attn_lr | 5,152 | 0.2402 |

⚠️ **不要把这个 0.7656 读成「超过 attention」**：

- 这个任务需要**两跳**（先定位 key，再取相邻 token 的 value），
  **单层** causal attention 一跳做不到，所以 `attn` 也只有 0.2617。
  这是基线构造的上界失效，不是 SFSC/FD-CAO 赢了。
- `fdcao_p` 的定义是「写入用**前一 token** 的相位」——这等于把
  「相邻 (key, value) 成对出现」这个**任务先验显式写进架构**。
  它是任务构造对齐，不是从 SGC 数学本质长出来的能力。
- 换成单层可解的 `bind1`，`fdcao_p` 立刻掉到 0.6113（见下表），
  印证这一判断。

### 2.2 `bind1`（单跳内容寻址：组合 token 同时编码 key+value，L=9，2500 步）

| 臂 | 参数量 | acc |
|---|---:|---:|
| static | 1,056 | 0.4160 |
| sfsc | 3,136 | 0.4141 |
| **fdcao** | 5,217 | **0.8672** |
| fdcao_p | 5,217 | 0.6113 |
| attn | 17,440 | **1.0000** |
| **attn_lr** | **5,152** | **1.0000** |

这是本轮**唯一有效的上界对照**（单层 attention 一跳可解）。结论很干净：

- FD-CAO **显著超过静态核**（0.8672 vs 0.4160）与 SFSC（0.4141）
  → 相位共振确实把内容寻址能力带进了 O(1) 状态；
- 但**等参数量下仍输给 attention**：`attn_lr` 5,152 参数拿 1.0000，
  FD-CAO 5,217 参数 0.8672。
  **「真正超越 attention」在内容寻址轴上没有被证实。**
- SFSC 在两跳和单跳任务上都与静态核持平（0.2500 / 0.4141）——
  状态 EMA 的平滑调制**没有转化为绑定能力**，与猜想自己的诚实边界一致。

### 2.3 `mod`（上下文调制：整体 A/B 占比决定 regime，L=25，3000 步）

| 臂 | 参数量 | acc |
|---|---:|---:|
| static | 1,056 | 0.5000 |
| sfsc | 3,136 | 0.5352 |

⚠️ **本任务只跑了 2/6 臂、单 seed，未跑完，不能定论**（见 §4）。
即便按现有数字，+0.035 落在噪声内；而且这个任务的正确标签只依赖
「A/B 一阶占比」，**静态核的全局平均本身就能算**，不构成对
「平滑上下文调制」的判别性检验。任务设计需要重做（例如要求
二阶/层次调制，或让一阶统计相同而规则不同）。

### 2.4 `osc`（周期信号频率分类）—— **未跑**

SGC 主场，本轮未执行，见 §4。

## 3. 综合判定

| 猜想 | 声称 | 本轮判定 |
|---|---|---|
| SFSC | 平滑上下文调制、保 FFT 对偶与 $O(L\log L)$ | **FFT 对偶证伪**；绑定轴与静态核持平；调制轴未跑完。核心卖点损失一条 |
| FD-CAO | 用共振代替打分、O(1) 状态补齐内容寻址 | **部分成立**：O(1) 状态下把静态核从 0.416 提到 0.867；但**等参数仍输 attention 1.000**，且未超过 CAS 已被删除的路线所能提供的东西 |
| 二者共同目标 | 真正超越 attention | **未证实**。任何一臂、任何任务都没有超过等参数 attention 上界 |

另外两处必须点破的边界：

1. **FD-CAO 与「不借鉴外部方案」有张力**。它的
   `w = W_v·u_t` 是每 token 的 value 投影，`gq/gw` 是查询-键的相位匹配，
   状态 `y` 累积 $\sum_s \text{match}(k_s,q)\cdot v_s$ ——
   这是**把成对打分压缩到 M 个固定频率槽**，本质是
   $S_t=\sum_s\varphi(k_s)v_s^\top$ 的频域版本。
   猜想原文自己也承认「借用了内容寻址这一通用概念」。
   它守住了「无 N×N、无 KV cache、O(1) 状态」，但**没有守住
   「不借鉴任何外部方案」**——这一条请作者自己裁量。
2. **`fdcao_p` 不是架构胜利**。它把「相邻两 token 恰为 (key,value)」
   写进了写入相位，是任务先验注入；`bind` 上的 0.7656 到 `bind1`
   掉成 0.6113 就是证据。

## 4. 未完成 / 局限（照实，不删）

- ⬜ `mod` 只跑 `static` / `sfsc` seed0，其余 4 臂未跑；`osc` 六臂全未跑。
- ⬜ 全部任务只有 **seed 0**，无误差棒、无 seed 间方差、无配对 bootstrap。
- ⬜ 任务都是合成小任务（L=9~25、V=64、D=64、M=16），
  与上游 PyTorch 实现、与真实语言建模**都不是同一尺度**。
- ⬜ `fdcao` 的 $\theta_m$ 在这里是**固定可学参数**而非按 key 动态映射；
  猜想里的「键经 $W_k$ 映射到 $\theta$」尚未实现，容量上界可能被低估。
- ⬜ 未测 4M 长上下文、未测吞吐、未测流式 IIR 与整段递推的逐位一致性
  （SFSC/FD-CAO 的流式路径尚未单独实现）。
- ⬜ 单层模型；猜想里「大部分层 SGC + 关键层 FD-CAO」的混合堆叠未验证。
- 本轮**未运行仓库 pytest**（沙盒无 torch）；所有检验来自自写纯 NumPy 脚本。

## 5. 下一步（按优先级）

1. **补完** `mod`（重做成判别性二阶调制任务）+ `osc` 六臂，≥3 seed，
   配对 bootstrap。这是判断 SFSC 是否还有价值的最低条件。
2. 若 SFSC 在调制轴仍无显著增益 → 结合 §1.2 的 FFT 证伪，
   **SFSC 可以收摊**：它付出的代价（丢 FFT、丢 $O(L\log L)$、丢对偶）
   大于收益。
3. FD-CAO 若要继续，需先回答：与已 revert 的 CAS 相比，
   频域槽是否带来任何**非任务先验**的优势？判据是 `bind1` 上能否
   在 5,200 参数内追平 `attn_lr` 的 1.0000，以及在 `bind` 两跳任务上
   不靠 `pair` 注入也能学会。
4. 无论哪条，**别把「超过静态核」写成「超过 attention」**——
   这是本轮数据最容易被误读的地方。

```bash
cd tools/sfsc_fdcao_probe
python sfsc_fdcao.py --mode gradcheck          # 6/6 PASS

python sfsc_fdcao.py --mode train --task bind1 --arm fdcao --seed 0
python sfsc_fdcao.py --mode train --task bind1 --arm attn_lr --seed 0
python sfsc_fdcao.py --mode all                # 全任务 × 全臂 × seed 0/1/2
```

`(task, arm, seed)` 组合会跳过，可安全断点续跑。
