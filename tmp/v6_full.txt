Where the Bits Must Live: A Tight Input-Side
Information Bound for Fixed-State Spectral Models
Anonymous submission
Abstract
We prove a tight lower bound on the information that must be supplied on the INPUT SIDE of a fixed-state attention-free sequence model: exact H-hop
content retrieval requires at least log2|A| bits of key/value role information, where |A| is the number of distinct answers compatible with the visible symbol
sequence (Theorem A). The difficulty is that the bound is universal -- it holds for ANY deterministic decoder, independent of depth, state order and kernel --
so the missing bits cannot be manufactured inside the model; placing them in the kernel makes its coefficients time-varying, which by Toeplitz IFF
time-invariance destroys the single-FFT / IIR duality. We therefore characterize WHERE the bits may live: an explicit tag, an alphabet partition, and a
positional format prior each carry one bit per ambiguous token, but only the alphabet partition preserves duality while remaining free of run-time annotation.
Strongest evidence: exhaustive enumeration gives accuracy 2^(B-m) for B<m and exactly 1 at B=m for m=1..4; a real static-LTI stack of depth 1..8 produces
bit-identical outputs across all compatible role assignments (deviation 0.0e+00); the three carriers measure 1.0000 / 1.0000 / 0.2969. Significance: the
objection 'the input format solves the task' becomes a quantitative design rule -- budget log2|A| bits at the input or relax exactness, because extra layers
cannot substitute. This REFINES our own earlier 'exactly one bit' claim into a general total-bit bound. Two tight structural bounds (an order-2 state for one
hop; exactly H static-LTI layers for H hops under last-layer read-out) are attained by the same Toeplitz, O(1) construction. We make no language-modeling,
perplexity or throughput claim.

1  Introduction
A fixed-size state must summarize an unbounded history. The
literature has established the LTI convolution/recurrence duality,
the time-invariance requirement for a convolution view, and the
recall/copying weakness of fixed-state models (S4 [1], S5 [2],
Zoology [13], Repeat After Me [14], Illusion of State [15]). We
do NOT re-prove those. The question we answer is which
ALGEBRAIC property of a specific architecture produces each
boundary, and which single premise must be removed to escape
it.
One story. Exact retrieval needs information that a flat symbol
sequence does not contain: which token of each binding pair is
the key and which is the value. We prove a tight lower bound on
that information (Theorem A), prove that a Toeplitz kernel
cannot create it internally, and show the bit-depth frontier is a
right angle. Two tight structural bounds complete the picture: an
order-2 state for one hop (Theorem 1) and exactly H static-LTI
layers for H hops under last-layer read-out (Theorem 2). All three
are attained by one Toeplitz, O(1)-state construction. Supporting
statements and withdrawals are kept in the appendix as a
soundness record, not as contributions.
1.2  Contributions
· 1. A tight input-side information bound (Theorem A, main result).
Exact retrieval needs B >= log2|A| bits of role information; the bound is
universal, attained, and independent of depth. Within the static-LTI class
the bits are FORCED to the input by Toeplitz duality. Parts (a),(b) are
standard information theory -- we say so explicitly; the novelty is the
location theorem, three-way conservation and the right-angle frontier.
· 2. Two tight structural bounds. Minimum tensor order exactly 2 for
one hop (T1), and exactly H static-LTI layers for H hops (T2). Both are
attained by one construction with O(1) state and no N x N scores.
· 3. A constructive counterexample. An orthogonal codebook partition
supplies the required information without any run-time annotation and
keeps FFT/IIR duality (relative error 2.89e-16). This retires our earlier
mutual-exclusivity claim and the positional-format prior.
· 4. Falsifiable witnesses. Exhaustive bit enumeration (m=1..4),
depth-1..8 invariance of a real static-LTI stack, three carrier
measurements, and a 5 x 5 layer x hop grid. Every number is injected
from raw result files; no value is a theorem.
We deliberately present FOUR core results, not thirty. Honesty about
withdrawals is a soundness practice, not an originality claim.
2  Preliminaries and Notation
We use t for the absolute time index, d = t - s for a delay, tau for a kernel
lag, H for the number of hops, H_L for the number of layers, and n for the
number of pairs. These are kept distinct throughout; no symbol is reused.
Notation ledger (v6, final). C in R^(V x V) is the deterministic Sylvester
Hadamard code, C C^T = I, NOT learned, applied by FWHT. V = 2 V_K;
the first V_K rows are KEY codes, the last V_K are VALUE codes -- this
is the SINGLE role bit. K_h(d) = sum_p w_hp rho_hp^d > 0 is static and
time-invariant. A_t = C[x_(t-1)] and b_t = C[x_t] are kernel-external; there
is NO r[t] gate (the parity mask was WITHDRAWN, the withdrawn
positional format prior). q_(h+1) = normalize(T_h z_h) with T_h a FIXED
learned linear map, not a function of t or of the content. s_(h,p) are P state
vectors per layer; total state is O(H_L P V) scalars with NO dependence on
L.

3.1  T1 - Minimum tensor order is exactly 2
Premises (complete). A single static-LTI mixer with a fixed-dimensional
state; the query enters only at the final position; values are independently
assignable; at least two distinguishable targets; the read-out may be ANY
function of the state and the query.
Claim. (a) An order-1 vector state cannot implement exact retrieval for any
read-out. (b) An order-2 tensor state attains it exactly with zero interference
and without knowing the target position. Therefore the minimum order is 2
and the bound is TIGHT. Proof route (corrected). The summary is A =
sum_p [alpha_p k_p + beta_p v_p] with beta_p = K(L-s_p) > 0 for a
strictly positive static kernel. A nonzero kernel of the induced map L:
R^(nd) -> R^d does NOT by itself guarantee that a kernel vector perturbs
the TARGET coordinate. We construct one explicitly: for n>=2 take Delta
v_1 = beta_2 u, Delta v_2 = -beta_1 u and all other blocks zero, with any
nonzero u. Then sum_p beta_p Delta v_p = 0, so Delta lies in ker L, yet it
changes the first value block. Choosing the query to target that block gives
two value assignments with identical (A,q) but different required answers,
so NO read-out can be correct. (b) The outer-product state preserves the
binding. Full proof: Appendix A.1/A.13.

3.2  T2 - Exactly H static-LTI layers (new)
Premises (complete). H1: n pairs (k_p, k_(p+1)), distinct keys, strict
key/value alternation, arbitrary pair-position permutation. H2: query k_0 at
t=L-1. H3: fixed code C with C C^T = I on the key range. H4: H_L layers,
each with static kernel K_h(d)=sum_p w_hp rho_hp^d > 0. H5 (REVISED
by Theorem A): the INPUT ENCODING supplies at least log2|A| bits of
key/value role information, where |A| is the number of answers compatible
with the visible symbol sequence. The orthogonal codebook partition (KEY
symbol k uses C[k], VALUE symbol k uses C[V_K+k], NO gate) is a
SUFFICIENT tight carrier; we no longer claim it is the unique or
information-minimal one. Lemma R3 is the |A|=2 worst-case special case;
R2 proves sufficiency; R2(d) shows an extra position gate is strictly
harmful. H6: layer interface q_(h+1)=z_h/||z_h||; LAST-layer readout only,
no stop mechanism. H7: 1<=H<=n.
Claim. (a) If H_L < H the answer is at most chance. (b) If H_L = H the
answer is exactly k_H without training for every n, permutation and V. (c)
If H_L > H the last-layer read-out overshoots to k_(H_L) and also fails. (d)
Under H1-H7 AND last-layer read-out, H_L = H is necessary and
sufficient; total state O(H_L P R) is independent of L; every kernel is
Toeplitz so FFT/IIR duality holds; no N x N, no softmax over tokens, no
KV cache, strict causality. Proof route. Induction: z_h = c_h C[V_K+k_h]
with c_h>0 because the VALUE-half code is orthogonal to the KEY-half
query, so the value-position peak vanishes; all keys are distinct. The lower
bound is completed by Lemma R3 (Section 3.6): zero role bits admit an
adversary permutation that forces error for ANY layer interface. Full proof:
Appendix A.31/A.34. Qualification (Theorem A(f)). The 'exactly H'
statement is a consequence of the LAST-LAYER read-out convention,
NOT an architectural law: retaining intermediate outputs and selecting the
H-th makes H_L >= H sufficient, while the lower bound H remains.
Why (c) is not a bug. Without a stop/select mechanism the query keeps
propagating along the chain. Retaining intermediate outputs and selecting
the H-th would make H_L>=H sufficient (the lower bound H remains). At
rho=1 with one pole, z_h = q_h^T (sum_t r[t] C[x_(t-1)] C[x_t]^T) is
isomorphic to a linear-attention state; with rho<1 and multiple poles it is a
DECAY-SPECTRUM weighted operator. We do not claim a new
paradigm.
3.3  T3-T6 (supporting core)
· T3 (NT04/NT05). For any V take R=2^ceil(log2 V) rows of a
Sylvester Hadamard matrix: after normalization C C^T = I (with R < 2V
rows), with a matching Omega(V N) state lower bound. Orthogonality is
SUFFICIENT but not necessary for argmax decoding; a Gaussian i.i.d.
code also attains 1.0000 in our ablation.
· T4 (NT12, strengthened from B4). For the second-order recurrence
y_t=a_t y_(t-1)+b_t y_(t-2)+c_t u_t with c_t != 0, the impulse response
is Toeplitz IFF (a,b,c) are constant in t. Proof by induction on the delay
tau=0,1,2. Consequence: non-Toeplitz admits NO single H(z), so the
single-FFT path fails. Boundary: this negates THAT path, not the
existence of every possible O(L log L) algorithm.
· T5 (NT13, arbitrary read-out). Under a fixed-dimensional LINEAR
history summary with query entering only at the current position and
independently assignable values, NO read-out (linear or nonlinear) can
implement retrieval. Four premises stated in full in Appendix A.13. TSC
escapes by changing the tensor order of the signal.
· T6 (NT03/NT30, joint tightness). The four quantities -- minimum
order 2, exactly H layers, O(1) state, static Toeplitz kernel -- are
simultaneously attained and none can be improved alone without
breaking another. A provable separation from linear attention holds for
rho<1 with multiple poles (decay spectrum); at rho=1 with one pole the
operators coincide and we say so.
Propositions P1-P8 (Appendix B). Standard but essential: Turan identity
for real poles, three-sample identifiability, linear-grid optimality, two-tap
minimal sufficient state, AND-gate uniqueness, verifier trap, interior
optimal rho, and the no-compensation lemma.

Theorem 4 (Toeplitz IFF time-invariant; strengthened B4). For y_t =

3.7  Eight supporting propositions (standard but essential)
These are deliberately PROPOSITIONS, not theorems. They are genuine,
reproducible and useful, but each is either a standard identity or a
special-case fact; promoting them would be theorem inflation. We state
each with its exact content so a reviewer can verify it in one line.
· P1 TURAN. h(d)^2 - h(d-1)h(d+1) = (r1 r2)^d > 0 for two real poles r1
!= r2; strict log-convexity follows. A conjugate-pole oscillatory kernel
necessarily takes non-positive values and cannot satisfy it. This makes
'real poles beat damped sinusoids on binding' a STRUCTURAL fact, not
a tuning result.
· P2 IDENTIFY. An impulse response h(0),h(1),h(2) from a
second-order LTI system determines (a,b,c) uniquely; three samples
identify the pole family without any training.
· P3 GRID. Among M points in (0,pi), the linear grid maximizes the
minimum pairwise separation; the proof is an elementary
pigeonhole/ordering argument, so we do not call it novel.
· P4 MINIMAL STATE. For a second-order recurrence, (y_(t-1),
y_(t-2)) is a minimal sufficient statistic; any smaller state loses
information. This makes the byte bound of T3 tight.
· P5 AND-GATE. Exhaustive enumeration of all 256 Boolean rules on
three binary inputs shows the no-regression gate is UNIQUE. Finitude
makes it checkable, not deep.
· P6 VERIFIER TRAP. A verifier that only checks statement strings
can report PASS for a false claim; all our checks certify witness
agreement and non-vacuity, while every proof is analytic.
· P7 OPTIMAL rho. For m-bit accumulators the optimal decay is rho*
= 1 - Theta(2^-m); the analytic closed form matches three numerical
scans to 0.6%, 0.08% and 0%.
· P8 NO COMPENSATION. Adding further poles P to a single layer
cannot compensate a multi-hop deficit: the layer still performs ONE
bilinear contraction. The remedy is H layers, not more poles.
Why they are here. They are the load-bearing but standard facts behind
the three tight bounds. Keeping them as propositions raises the average
information content of the six core theorems without hiding anything.

5  What This Does NOT Establish
· Not equivalence. On the synthetic single-hop parity run the Fisher
p-value was 0.4998. We say 'no significant difference was DETECTED
in this configuration'. A non-significant p is NOT an equivalence proof,
and the baseline came from a historical record file rather than a
same-run re-execution.
· Not language modeling. There is no >=10M-token equal-compute
run, no val perplexity, no generation readability, no Mamba-2 / GLA /
DeltaNet / Hyena / Transformer same-condition baseline, and no
measured throughput comparison. O1-O4 lack >=5-seed paired CIs.
These are the four experiments that would be needed for an architecture
claim; we did not run them.
· Not a new paradigm. T6 states the rho=1 single-pole isomorphism
with linear attention explicitly. The contribution is a tight JOINT
characterization under static kernels, not a claim of leaving that family.
· Role necessity is layout-conditional, and no side-channel is needed.
With no role tag the tight alternating layout fails (0.8691) while a
gapped layout reaches 0.9609 because zero fillers implicitly suppress the
spurious peak; Lemma R1(d) states the condition. Under the codebook
partition of Section 4.5, neither a tag nor a position rule is needed at all.
What remains is an ENCODING-LEVEL alphabet convention, not a
run-time annotation.
· Exactly one bit is a worst-case optimum, not a uniform one.
Zero-bit models reach 1.0000 on dense and 0.9949 on padded layouts,
because zero fillers implicitly suppress the spurious peak. Lemma R3
proves they cannot be correct on ALL legal inputs; it does NOT claim
they fail everywhere. The 2-bit result (0.2711) is strictly worse than the
1-bit result, so 'more role information is safer' is also false.
· Not a SOTA model. Positioning: an input-side information bound with
constructive counterexample + auditable negative results. We decline
every superiority claim; the withdrawn-claims register (Appendix F) is a
methodological signal, not a weakness to hide.
6  Related Work, Placed Precisely
Table 1 on the first page gives the exact increment per known result; we do
not repeat it here. Zoology [13], Repeat After Me [14] and Illusion of State
[15] established that fixed-state models are weak at associative recall. S4
[1] / S5 [2] gave the LTI duality; Mamba [4] observed that selective
parameters break the convolution view; linear attention [8] and its gated [6]
/ delta [7] variants gave the outer-product state. Our increment is a
FORMAL tightening: a tight log2|A|-bit input-side lower bound with the
bits FORCED to the input by Toeplitz duality (Theorem A), two sharp
bounds with four explicit premises each, and a retraction of our own earlier
mutual-exclusivity claim. We do not claim to be the first to observe that
static convolutions struggle with recall, nor that input format can carry
task-relevant information.
7  Limitations and a Falsifiable Prediction
The construction assumes distinct keys, adjacent binding emission, an
external query, and last-layer read-out. Repeated keys, multi-query chains
and stop/select mechanisms are outside T2. Finite-precision results cover L
<= 128 for the analytic construction; the earlier long-decay frontier is a
separate measurement. We did not run a >=10M-token equal-compute
language-model experiment, and we do not present this as an architecture
paper.
A falsifiable prediction the community can attack. Theorem A(b) is
distribution-free and depth-free: NO deterministic decoder supplied with B
< log2|A| input-side bits can be exact on all compatible instances,
regardless of layer count, state order or kernel family. Any construction
that achieves exact H-hop retrieval with fewer bits falsifies the bound at a
precisely identifiable place. This is a target for others to test, not a request
to forgive a missing experiment.
What we deliberately did NOT do. We did not add a >=10M-token
equal-compute comparison, same-run Mamba-2 / GLA / DeltaNet / Hyena /
Transformer baselines, or a throughput comparison. An unfair large-scale
baseline would be worse than none for a theory paper. Small, clean, seeded
comparisons plus an explicit 'no LM claim' are the honest scope here.
8  Conclusion
Exact retrieval needs information that a flat symbol sequence does not
contain. We proved a tight lower bound on that information (B >= log2|A|
bits, Theorem A), proved that Toeplitz duality FORCES the bits to the
input
side,
showed

one hop; exactly H static-LTI layers for H hops under last-layer read-out)
are attained by the same Toeplitz, O(1)-state construction. The practical
rule is simple: budget the bits at the input or relax exactness. This is an
information-bound paper with a constructive counterexample, not a claim
of language-model parity or a new SOTA sequence model.

Premises. CONDITIONAL. Streaming state s_t, causal information set at
step t contains only I_t = ( |u_s| <= U, s_(t-1), rho ), i.e. no future peak is
known. A quantizer chooses a scale Delta_t >= |s_t| to avoid overflow and
incurs absolute error delta_t proportional to Delta_t. A 'fixed global scale'
19

uses Delta_t = Delta for all t.
Claim. (a) The per-step peak rule Delta_t = max(|s_t|, Delta_min) is the
POINTWISE MINIMAL admissible scale given I_t, hence minimizes
delta_t at EVERY step. (b) Any fixed global scale must satisfy Delta >=
sup_(t<=L)|s_t|, and since sup >= max_t|s_t| pointwise, delta_fixed >=
max_t delta_peak(t), with strict inequality whenever the peak varies. (c)
Therefore fixed-scale quantization is never better and is strictly worse on
any sequence with a non-constant state envelope; the improvement is
CAUSAL (needs no future information).
(a) Admissibility requires Delta_t >= |s_t|; the smallest such value is |s_t|
(or Delta_min for the zero state), which uses only s_(t-1), u_t and rho -- all
in I_t. Minimality is pointwise, so delta_t = c Delta_t is minimized
pointwise.
(b) A fixed Delta must cover every t<=L, so Delta >= sup_t |s_t| >= |s_t| =
Delta_peak(t) for each t; hence delta_fixed >= delta_peak(t) for all t, i.e. >=
max_t delta_peak(t). If the envelope is non-constant the inequality is strict
at the step where |s_t| < sup.
(c) Combining (a) and (b) gives the partial order, and (a) shows the rule is
implementable causally. QED
Boundary. CONDITIONAL on scale-proportional absolute error and the
stated causal information set. It proves a PARTIAL ORDER of error
bounds, NOT that dynamic scaling always wins empirically (O6's fp16
non-monotonicity is a separate genuine numerical effect). It does not
contradict the withdrawal of 'dynamic scaling causes spurious artifacts' --
those are different claims.

A.27  NT27 - Phase transition of the optimal decay across precision depths
Premises. CONDITIONAL. NT07's resolvable-length bound g(rho) =
ln((1-rho)U/(c delta)) / |ln rho| on rho in (0, hi), hi = 1 - c delta/U; delta/U =
2^(-(m+1)) for mantissa depth m; c>1 fixed; delta/U sufficiently small.
Claim. (a) g is strictly increasing near rho -> 0 and strictly decreasing near
hi, so for small delta/U it has a SINGLE interior maximum rho*(m). (b)
rho*(m) solves the stationarity equation (1-rho) ln(1/rho) ln((1-rho)U/(c
delta)) = rho ln(1/rho) + ... equivalently the balance (1-rho) ln((1-rho)U/(c
delta)) = rho ln(1/rho); asymptotically rho*(m) = 1 - Theta(2^(-m)). (c)
Therefore DIFFERENT precision depths have DIFFERENT optimal
decays: a single rho tuned for fp32 is provably suboptimal for int8. rho -> 1
is never optimal (NT07).
Write N(rho)=ln((1-rho)U/(c delta)) > 0 and D(rho)=ln(1/rho)>0, g=N/D.
Then g' = (N' D - N D')/D^2 with N' = -1/(1-rho) < 0 and D' = -1/rho < 0, so
sign(g') = sign( -D/(1-rho) + N/rho ). As rho -> 0, D = ln(1/rho) -> +infinity
but N -> ln(U/(c delta)) is finite and positive; the term N/rho ~ ln(U/(c
delta))/rho grows as 1/rho and therefore dominates -D/(1-rho) ~ -ln(1/rho).
Hence g' > 0 near 0. As rho -> hi, N -> 0+ while D stays positive and finite;
then N/rho -> 0 and -D/(1-rho) < 0 dominates, so g' < 0 near hi. By
continuity g' has a zero in (0,hi); for small delta/U the ratio N/D is
unimodal (one sign change), giving a UNIQUE interior maximum rho*.
Setting g'=0 gives N/rho = D/(1-rho), i.e. (1-rho) N = rho D, the stated
balance. Now put rho = 1-epsilon with epsilon small and delta/U =
2^(-(m+1)): then D = ln(1/(1-epsilon)) = epsilon + O(epsilon^2) and N =
ln(epsilon * 2^(m+1)/c) = (m+1) ln 2 + ln epsilon - ln c. The balance
(1-rho)N = rho D becomes epsilon * N = (1-epsilon) * (epsilon +
O(epsilon^2)), so for epsilon>0 we need N = 1 + O(epsilon). Substituting N
gives ln epsilon = 1 - (m+1) ln 2 + ln c + O(epsilon), hence epsilon =
c*e*2^(-(m+1)) (1+o(1)) = Theta(2^(-m)) and rho* = 1 - Theta(2^(-m)).
This matches the NT07 finite scans (m=8 -> 1-rho* ~ 1e-2, m=11 -> ~1e-3,
m=24 -> ~3e-8). Since rho* depends on m, a single rho cannot be optimal
for two different mantissa depths. QED
Boundary. CONDITIONAL on NT07's uniform-error model; uniqueness
of the stationary point is asserted for SMALL delta/U (the regime of
interest); it is not a global proof for all parameters. The asymptotic
rho*=1-Theta(2^(-m)) is analytic, and is CROSS-CHECKED against
NT07's finite scans but not derived from them. Measured O6 rho=0.999 is
an observation.
Architectural use. Explains why the int8 / bf16 / fp32 frontiers must be
tuned separately and gives the precision-dependent decay law; strengthens
NT07 from 'an interior optimum exists' to 'how it moves with m'. Source:
NT07 + O6 raw result files in the supplementary artifact
A.28  NT28 - Layer x tensor-order incompatibility inequality for H-hop retr
Premises. A stack of L layers; each layer's output is a polynomial of total
degree at most the tensor order o of its state contraction (order-2 outer
product gives o=2; bilinear contraction degree 2). Skip connections do not
raise degree. The H-hop target contains H key-match factors plus one value
factor, total degree H+1.
Claim. L * ln(o) >= ln(H+1), equivalently o^L >= H+1. For o=2 this
recovers NT11 (L >= log2(H+1)); for L=1 it forces o >= H+1, so a
SINGLE layer needs tensor order at least H+1. CRITICALLY: increasing
the number of pole channels P changes the KERNEL SHAPE but not the
tensor order o, so P cannot compensate for too few layers or too low an
order. The two resources (depth, order) are incomparable and must both
satisfy the product bound.
Composition of polynomials of degrees d_1..d_L has degree at most prod
d_i <= o^L; skip connections (addition) do not increase degree. The H-hop
target is a multilinear form of degree H+1 (H factors <phi(q),psi(k)> plus
one value). A polynomial of degree < H+1 cannot equal a nonzero
degree-(H+1) form, so o^L >= H+1, giving the inequality. Setting o=2
gives NT11; setting L=1 gives o>=H+1. The pole count P enters only
through K_n(d)=sum_p w_(p,n) rho_(p,n)^d, a SCALAR multiplier of each
delay; it does not add a new tensor index or raise the polynomial degree in
the history variables. Hence P is orthogonal to the bound. QED
Boundary. NECESSARY condition only; no sufficient construction. The
degree bound is an upper bound on what L layers of order o can reach.
Per-position nonlinearities of degree > o change the premise. The measured
H4_multihop=0.0322 is a finite-sample observation.
Architectural use. Unifies NT01 (order 2 for 1 hop) and NT11 (layers for
H hops) into one inequality, and PROVES that the 'add more poles' fix
cannot work -- closing a whole search direction that was tried implicitly.
Source: NT01 + NT11 + O5 H4_multihop
