Where the Bits Must Live: A Tight Input-Side
Information Bound for Fixed-State Spectral Models
Anonymous submission
Abstract
We prove that exact H-hop content retrieval by any deterministic fixed-state decoder requires B >= log2 |A(v)| bits of input-side information beyond a flat
symbol alphabet, where A(v) is the set of answers compatible with the flat projection v (Theorem A). The difficulty is that the bound is distribution-free and
depth-free: extra layers, higher state order, and kernel retuning cannot manufacture the missing bits within the duality-preserving LTI class, because the
whole computation there is a function of the flat projection. We therefore characterize where the bits may live: an explicit tag, an alphabet partition, and a
symbol id carrying a role each supply one bit per ambiguous token. The alphabet partition folds the mandatory bit into the symbol id: it is not bit-free, it is
annotation-free. Strongest evidence: two further tight structural bounds (an order-2 state for one hop; exactly H static-LTI layers for H hops under last-layer
read-out) are attained by one Toeplitz, O(1)-state construction. In the architecture module the H6 interface is the codebook's fixed value-to-key swap rather
than a learned matrix; from random initialisation of the remaining weights, H=2 with two layers reaches 1.0000 +/- 0.0000 by step 150 on five of five seeds,
while one layer stays at 0.1809 +/- 0.0219 (paired difference +0.8191, 95% CI [+0.8008, +0.8375] at 1500 steps). The design rule is to budget log2 |A| bits at
the input or relax exactness. We make no language-modeling, perplexity, throughput, equivalence or superiority claim. Separately, on an exactly-defined
finite consolidation process we prove that zero-order codebook registration improves retrieval monotonically, with a predicted cover time of 129.87 rounds
against a measured 130.00 over five seeds; an earlier attention-parity statement is withdrawn because it did not reproduce (W12).
1  Introduction
Fixed-state attention-free sequence models compress a prefix into
a constant-size summary. The question addressed here is not how
much such a model can compress, but which information is
simply absent from a flat symbol sequence and therefore cannot
be recovered by any deterministic decoder, regardless of depth or
kernel design.
Multi-hop content retrieval exposes the issue sharply. When key
and value symbols share one alphabet, the same visible sequence
can be compatible with several binding graphs that demand
different answers. A decoder that sees only the flat projection
must guess. Prior work established the empirical weakness; the
contribution here is a tight, distribution-free quantification of the
input-side deficit, and a construction showing that supplying
exactly that deficit restores exact retrieval while preserving the
static-kernel duality.
1.1  Four core results
· Result 1 (Theorem A). A tight input-side information bound B >=
log2 |A(v)|, with per-fibre accuracy, a within-class-M location statement,
three equivalent carriers, and the bit-depth frontier. The serial-depth and
state-order statements of earlier drafts are folded into part (e) of the
same theorem.
· Result 2 (Theorem B). Two structural bounds proved jointly and
attained by one construction: the minimum tensor state order for one hop
is exactly 2, and exact H-hop retrieval under last-layer read-out requires
exactly H static-LTI layers.
· Result 3 (Construction C). A static-LTI, order-2, contraction read-out
layer that performs content addressing. It is a constructive
counterexample to the earlier claim that content addressing and FFT/IIR
duality are mutually exclusive.
· Result 4 (Empirical E). Five-seed verification at a 1500-step budget
that the layer bound survives end-to-end training from random
initialisation (Section 4.12), degradation curves, and a same-run
reproduction audit with one withdrawn claim.
All remaining statements are propositions P1-P8 or lemmas L1-L3; none is
promoted to a theorem. Table 1 records the exact increment over prior

2  Preliminaries and One Layer Interface
Alphabet and the budget B. Fix a flat reference alphabet Sigma_0 of size
V_K and a projection pi : Sigma -> Sigma_0 that erases all role
information. For an input x_(1:L) in Sigma^L write v = pi(x_(1:L)) for its
flat projection. Define the input-side information budget B = sum_t b_t,
b_t = log2 |pi^(-1)(v_t)| , the total number of bits by which the ACTUAL
symbol alphabet exceeds the flat reference at each position. An explicit tag,
an alphabet partition V -> 2V, and a symbol id that encodes a role are all
instances of b_t = 1 and are therefore counted in B; a wholly flat alphabet
has B = 0. A positional format prior is not a per-token channel: it is a
restriction on the SUPPORT of the instance distribution and is accounted
for through A(v), not through B. Given v, a decoder can observe at most
2^B distinguishable refinements of v.
One layer interface (H6, unique). Each static-LTI layer computes m_h[t]
= <q_h, e(x_(t-1))> and z_h = sum_t K_h(L-1-t) m_h[t] e(x_t). For h <
H_L the interface is q_(h+1) = T_h z_h / ||T_h z_h||_2 with a learnable
T_h in R^(d x d); the analytic optimum is T* = C_key^T C_val. Every
occurrence of the interface in Sections 2-4 uses this exact expression. The
phrase 'maps the VALUE half to the KEY half' describes the action of T*,
not a second interface; the unnormalised product (z_h C_val^T) C_key is
the special case T_h = C_val^T C_key with the same normalisation
applied. The read-out is last-layer only (P4).
Kernel families, kept separate. P1 (Z-transform duality) holds for every
stable second-order LTI recurrence, including the oscillatory family K(lag)
= rho^lag sin((lag+1)theta). The retrieval construction and Result 2 use the
strictly-positive real-pole family K(lag) = sum_j r_1^(lag-j) r_2^j > 0,
which is required by the positivity premise of P2 and by the matching
argument. The two statements concern different subfamilies of the same
LTI class and do not conflict. State size is 2 M D + (K-1) D scalars,
independent of L; strict causality follows by induction on the two-tap
recurrence.
Symbol discipline. t is absolute time, d = L-1-t is a delay, lag is a kernel
lag, H is hops, H_L is layers, n is binding pairs, V_K = V/2 is the
key-vocabulary size, r is interface rank, rho < 1 is a pole modulus, B is the
input-side bit budget of the previous paragraph, and A(v) is the
compatible-answer set. No symbol is reused.
2.1  State accounting, derived
The layer's entire streaming state is the pair (y_(t-1), y_(t-2)) of the two-tap
recurrence together with the (K-1) delayed inputs of the FFT overlap-add
path: 2 M D + (K-1) D scalar values, or 4(2 M D + (K-1) D) bytes in fp32,
with M the number of poles, D the channel width and K the fixed kernel
length. None of these quantities depends on L. Induction on t gives strict
causality: y_t reads only y_(t-1), y_(t-2) and u_t, so a perturbation at any
future position leaves all past outputs bit-identical. A per-channel
1

coefficient tensor of shape (M, D) is permitted by the architecture:
replacing the fixed (rho, theta) grid by learnable, time-INVARIANT (r_1,
r_2) poles keeps the operator LTI, hence keeps Toeplitz and the
single-FFT/IIR duality. Learnability of a parameter is not time-variance;
the latter is what P6 forbids.
Two consequences are used repeatedly. First, the O(1) state is a structural
property (a fixed number of scalar registers), not a measurement; it is why
A(b)'s pigeonhole argument applies at all. Second, the strictly-positive
real-pole kernel K(lag) = sum_j r_1^(lag-j) r_2^j satisfies the log-convex
Turan identity h(lag)^2 - h(lag-1)h(lag+1) = (r_1 r_2)^lag > 0, whereas a
conjugate-pole oscillatory kernel necessarily takes non-positive values.
Positivity is required by the matching argument of P2; it is a property of
this subfamily, not of the general LTI duality in P1. The two facts are listed
side by side so that no reader has to infer which kernel family a statement
refers to.
2.2  Task distribution and the fibre A(v), formally
An instance G is a directed binding graph on n pairs. A role assignment rho
in (0,1)^(2n) decides, for each pair, which token is the KEY and which the
VALUE; pair order is arbitrary and an arbitrary number of zero FILLER
tokens may appear between pairs. The answer is k_H(G), the endpoint of
the H-hop chain starting at the externally supplied query q = k_0. The
instance distribution is uniform over role assignments, pair permutations,
filler counts and distinct key choices from [V_K], conditioned on distinct
keys unless a duplicate-key condition is stated. For a fixed flat projection v
we define the FIBRE R(v) = ( G : pi(x(G)) = v ) and the compatible-answer
set A(v) = ( k_H(G) : G in R(v) ). The per-fibre statistic P5(i) is the
uniform measure on R(v); the marginal statistic P5(ii) is the push-forward
of the instance distribution under pi. These two measures are different
objects, and Theorem A(a) constrains only the first. Section 4.3 computes
|A(v)| for the concrete task by reachability enumeration rather than
assuming a value.
3  Four Core Results
3.1  Result 1 - Theorem A (input-side information bound)
Premises. P1 (task): an instance has n binding pairs, a role assignment
deciding which token of each pair is the KEY, arbitrary pair order, arbitrary
zero fillers, and answer k_H(G), the endpoint of the H-hop chain from an
external query q = k_0. P2 (visible input): the model sees (v, s) with v the
flat projection and s in (0,1)^B the refinement counted above. P3 (class M):

Two accuracy notions (P5). (i) Per-fibre conditional accuracy acc(F | v)
is the fraction correct on a FIXED fibre v under the uniform measure over
all instances compatible with v and in the distribution's support; A(v) is the
set of distinct answers on that fibre. (ii) Marginal accuracy is E_v[acc(F |
v)] over the data distribution. Theorem A bounds (i). When most fibres
have |A(v)| = 1, (ii) can exceed 1/2 while (i) stays bounded. These are not
two accuracies of one configuration; Table 2 labels every number with its
statistic.
(a) Per-fibre impossibility. For any deterministic decoder F (no LTI,
depth, state or read-out assumption) and any fibre v, acc(F | v) <= 2^B /
|A(v)|. If B < log2 |A(v)| then acc(F | v) <= 1/2. This is a conditional bound
on a single fibre, not a marginal claim.
(b) Bit lower bound. Exact retrieval on every compatible instance requires
B >= log2 |A(v)|. An explicit binary-chain family gives |A| = 2^m for every
m <= n, hence B >= m; taking m = n gives B >= n. If the pairing itself is
absent from v, |A| >= n! and B >= log2(n!). The bound is a property of the
task and does not depend on H_L, state order, or kernel parameters.
(c) A within-class-M location statement. Within P3, increasing H_L, the
state order, or retuning (rho, theta, w) cannot lower the bound: the
composition is a function of v with s removed. To place role information in
the KERNEL one must make its coefficients input-dependent and hence

3.1.1  Algebra of (a), (b) and (c)
Fix a fibre v. F(v, .) has at most 2^B values because the refinement s lies in
(0,1)^B. Let A(v) be the distinct answers over instances compatible with v
and in the support. If |A(v)| > 2^B, two instances G, G' share (v, s) but have
k_H(G) != k_H(G'); F cannot equal both, so under the uniform measure on
the fibre at most 2^B of the |A(v)| classes are correct and acc(F | v) <=
2^B/|A(v)|. Exactness on every instance requires |A(v)| <= 2^B for all v.
Neither step uses P3. The BINARY-CHAIN witness fixes m <= n, H = m;
at hop h the flat sequence contains one key and TWO candidate successors,
and a bit d_h not recorded in v selects the binding. All 2^m assignments
give the same v and q, yet map to distinct endpoints sum_h d_h 2^(h-1), so
|A| = 2^m and B >= m. If pairing is also absent from v, all n! matchings lie
in the fibre and B >= log2(n!).
For (c), layer h computes z_h = sum_t K_h(L-1-t) m_h[t] e(x_t) with
m_h[t] = <q_h, e(x_(t-1))> and the unique H6 interface q_(h+1) = T_h z_h
/ ||T_h z_h||. K_h depends only on the lag and on fixed parameters, T_h is
fixed, e is fixed; the composition is a function of the multiset of (flat id,
position) pairs plus q, i.e. of v with s removed. Under arbitrary filler
spacing the pair positions are determined by filler counts independent of
the role assignment, so F is constant on the fibre and A(a) applies. Placing
roles in the kernel makes the recurrence coefficients time-varying. For y_t
= a_t y_(t-1) + b_t y_(t-2) + c_t u_t with c_t != 0, P6 gives h(s,s)=c_s,
h(s+1,s)=a_(s+1)c_s and h(s+2,s)=(a_(s+2)a_(s+1)+b_(s+2))c_s; Toeplitz
forces c_s, a_s and b_s constant by induction on the lag, hence (rho_t,
theta_t) constant. Non-Toeplitz h(t,s) has no single H(z) and the single-FFT
path fails. This negates THAT path inside M, not every conceivable O(L
log L) algorithm, and it is conditional on the choice to keep duality. QED.
3.1.2  Algebra of (d), (e) and (f)
For (d), the Section 2 definition B = sum_t log2 |pi^(-1)(v_t)| counts an
alphabet partition with |pi^(-1)| = 2 as exactly one bit per non-empty token,
and counts an explicit tag as the same quantity. Tagging only the KEY
token of each of n pairs gives B = n, attaining B >= n from (b). A positional
prior is NOT a per-token channel: it restricts the SUPPORT of the
distribution, thereby reducing |A(v)|, and under random filler spacing that
restriction no longer holds, so the effective supplied information falls to
zero. This is why the position carrier is analysed through A(v) and never
added to B. For (e), (b) makes B < log2|A| infeasible for EVERY
deterministic model and hence for every H_L; for B >= log2|A| Result 2(ii)
gives minimum depth exactly H. The frontier is a right angle. For (f), under

P4 the decoded value at depth H_L is k_(H_L); with distinct keys and H_L
> H this differs from k_H. Retaining and selecting the H-th intermediate
output gives the correct answer for any H_L >= H, so the lower bound is
unchanged and 'exactly H' is not an architectural law. QED.
3.2  Result 2 - Theorem B (two tight structural bounds)
(i) Minimum state order. Under P2 with a linear historical summary and n
>= 2 binding pairs, no order-1 (vector) state supports exact one-hop content
addressing (P2 below). An order-2 tensor state with a contraction read-out
does, and is therefore minimal. (ii) Exactly H layers. Under H6, P4 and
distinct keys, one static-LTI layer resolves at most one content match; H
hops require H_L >= H, and H_L = H suffices. Both bounds are attained by
the SAME Toeplitz, O(1)-state construction C. Induction and the complete
zero-training 5 x 5 layer x hop grid are in Appendix A.4 and Section 4.
3.2.1  Induction and the attaining construction
Result 2(i) follows from P2 (no order-1 vector state with a linear summary)
plus Construction C (an order-2 tensor state works), so the minimum is
exactly 2. For 2(ii), induct on H. Base H=1: one contraction with q_1
resolves one content match and returns the value; a zero-th layer cannot.
Step: H-1 layers resolve H-1 hops and deliver q_H = C[k_H] through H6;
layer H performs one further match and returns k_H's successor. With
fewer than H layers the last read-out sees a mixture of at least two
successors and cannot be exact on all fibres. The construction attains
1.0000 on the diagonal of the 5 x 5 grid (Table 5) and <= 0.10 off it, so the
bound is tight. Overshoot H_L > H is A(f), not a failure of the lower bound.
All premises (distinct keys, H6, P4, static coefficients) are used; none is
silently dropped. QED.

3.3.1  Relation to linear attention, stated precisely
Setting rho = 1 and retaining a single pole reduces the Construction C state
to S = sum_tau k_tau v_tau^T, which is the linear-attention state; P4
records this isomorphism. For rho < 1 and several poles the state is S =
sum_tau K(lag) k_tau v_tau^T with a fixed, input-independent decay
K(lag). Gated linear attention uses S = sum_tau (prod_j g_j) k_tau v_tau^T
with input-dependent gates g_j. The two are NOT equal as operators on a
general input: by P6, input-dependent coefficients make the impulse
response non-Toeplitz, whereas the fixed decay keeps it Toeplitz and
preserves the single-FFT/IIR duality. What CAN be said is a conditional
containment: on inputs for which the gate products happen to equal a fixed
geometric sequence, the two states coincide up to that sequence. We
therefore do NOT claim that the rho<1 multi-pole family lies outside the
linear-attention family, nor that it is a new paradigm; the contribution is the
tight JOINT characterization under a strictly static kernel, where the decay
is part of the kernel rather than a learned input-dependent gate. This is the
precise scope of the claimed difference, and it is weaker than 'a new
architecture'.
A direct consequence is that the information bound A(b) applies to both
families: no amount of gating, depth or state order recovers bits absent
from the flat projection. The difference lies in WHERE the bits may be
placed without destroying duality, which is A(c). This also answers the
question of whether the tensor state is 'linear attention with extra steps': the
read-out contraction is bilinear, but the recurrence coefficients are static,
the state is decaying, and the layer count is exactly H by Result 2(ii).
3.3.2  The bit / depth / order frontier (design rule)
The three quantities form a step function rather than a smooth trade-off.
Table 6 gives the measured frontier. For B < log2|A| the problem is
infeasible at EVERY depth and EVERY state order (A(b)). At B >=
log2|A| the minimum depth is exactly H (Result 2(ii)) and the conditional
minimum state order is H+1 (P5, when each hop offers d orthogonal
successors). Pairwise scoring is never required inside the recurrence: the
q.k match occurs in the contraction read-out outside the static kernel.
Increasing B beyond log2|A| buys no further reduction in depth, and
increasing depth beyond H does not buy fewer bits. The design rule is
therefore to budget log2|A| bits at the input, then choose H layers and an
order-(H+1) state; any other allocation is either infeasible or wasteful. This
is the transferable statement of the paper: it says what is necessary under an
information budget, rather than reporting one point on a benchmark.

3.5  Dependency map and falsification
P2 and P6 feed Result 2(i); P1 and P6 feed A(c); P5 feeds A(e); Theorem
A(b) plus Result 2(ii) give A(e)'s right angle; Construction C supplies the
attaining witness for both A(d) and Result 2; Empirical E tests Result 2(ii)

statement. The bound is non-vacuous: n=4, m=2, V_K=32, H=2, flat

Numerical witnesses are not the proofs.
3.6  Why the three escapes do not beat the bound
P2's conclusion depends on its premise: a single mixer whose history enters
the final computation only through a fixed linear summary A. Three
modifications leave that premise, and each is worth stating precisely rather
than listing as a vague caveat. (i) Deep stacks with per-position nonlinear
FFNs. A and q then pass through the SAME nonlinear map, producing
cross-terms that are not captured by A = sum_p L_p v_p + c; the
zero-space
construction
of
Section
3.4
no
longer
applies.
(ii)
Input-dependent gates. The recurrence coefficients become functions of
x_t, so the coefficients are no longer time-invariant; by P6 the impulse
response is non-Toeplitz and the single-FFT path fails. This is a real
architectural difference, not a defect. (iii) Outer-product states. Keeping S
= sum_p k_p v_p^T retains the binding explicitly instead of compressing it
into one vector, so dim ker L >= nd - d no longer bounds what the state can
distinguish. Construction C is an instance of (iii).
None of the three escapes changes Theorem A(b). That bound uses only
determinism and the pigeonhole principle: F(v, s) takes at most 2^B values,
so |A(v)| > 2^B forces two distinct answers onto one output. It makes NO
assumption about P3. Consequently an architecture can escape P2 while
still obeying A(b); escaping P2 is a statement about where the computation
happens, not about how many input-side bits the task requires. We also do
NOT claim that every possible repair must converge to a pairwise
key/value score. That reading is an explanatory framework, not a theorem:
the proof of A(b) excludes only decoders with fewer than log2|A|
distinguishable refinements, and says nothing about the internal form of

4.3  Bridging the tight witness to the original task
Theorem A is tight on the binary-chain witness, where |A| = 2^m and B =
m. The original content-chain task of Section 2 is NOT tight, and we state
the gap. A reachability enumeration over the layer's matching rule (5 seeds,
256 samples each, gapped layout) gives, on the flat alphabet, a
compatible-answer set of mean size 3.2508 and maximum 5 at H=4, i.e.
log2 |A| <= 2.3219 bits; under the codebook partition |A| = 1 for every H
tested. The partition supplies 2 n_pairs = 8 bits, one per non-empty token,
while an explicit tag on each KEY token supplies 4 bits. Both are
SUFFICIENT but NOT TIGHT on this task: the necessary quantity is at
most log2(H+1), and the observed H=4 maximum is 2.3219 bits. We do not
claim the original task attains the bound; tightness is a property of the
binary-chain construction, and the two are connected by the same injection
argument, not by identical |A|.

re-running any training. A(b) is falsified by any exact H-hop construction

4.13  Deep SGC-SMM fusion and provable self-evolution
The sidecar is removed. Earlier versions kept an episodic bank outside the
model and injected a retrieved vector into the SGC stream. Here an
experience is registered INTO the same Sylvester-Hadamard codebook
used by the tensor state: S_t = rho S_(t-1) + sum_e C[k_e]^T C[v_e], with
read-out o = q S_t. Registration is a partial isometry between two
orthogonal half-spaces, not a learned update, so it is zero-order by
construction. Because Hadamard rows are exactly orthogonal, C[k] S = w_j
C[V_K+v_j] when k = k_j and 0 otherwise (SE1): retrieval accuracy is
IDENTICALLY the fraction of bindings correctly registered, not a
finite-sample estimate. This identity is what makes improvement provable.

5  What This Does NOT Establish
· No parity claim. W12 withdraws it; the same-run audit did not
reproduce the stored baseline. No equivalence, superiority or inferiority
is claimed.
· No architecture comparison. Section 4.6 supplies same-condition toy
mechanism references for a reproduction audit, not full reproductions of
GLA, DeltaNet, Mamba-2 or Transformer, and not a performance
ranking. Earlier O1-O4 lacked 5-seed paired CIs; the Section 4.6 results
have them.
· No language modeling. There is no >=10M-token equal-compute run,
no val perplexity, no generation readability and no measured throughput
comparison.
· Not a new paradigm. P4 states the rho=1 single-pole isomorphism
with linear attention. The contribution is a tight JOINT characterization
under static kernels.
· Role necessity is conditional. With no role bit the tight alternating
layout gives 0.8621 while a gapped layout gives 0.9609 because zero
fillers suppress the spurious peak (L1). Under the codebook partition
neither a tag nor a position rule is needed; the alphabet convention
remains an encoding-level inductive bias. Exactly one bit per token is a
sufficient carrier, not an information-theoretically minimal one.
· Overshoot is not an architectural law. Theorem A(f) attributes H_L
> H failure to last-layer read-out, not to the static kernel family.
· Self-evolution is bounded. Section 4.13 proves real, monotone
improvement for a finite consolidation process, but SE4 caps the
information entering the state at T w log2(V_K) bits, independent of
context length and bank capacity. Long context buys inference-time
retrieval, not a faster learning rate. No language-model, perplexity or
general-capability improvement is claimed.
6  Related Work, Placed Precisely
Table 1 gives the exact increment per known result; we do not repeat it
here. Zoology [1], Repeat After Me [2] and Illusion of State [3] established
that fixed-state models struggle with associative recall. S5 [4] gave the LTI
duality and the requirement of time-invariant coefficients; Mamba [5]
observed that selectivity breaks the convolution view; linear attention [6]
and its gated and delta-rule variants [7,8] use outer-product states. We do
not claim to be the first to observe that static convolutions struggle with
recall, nor that LTI systems require time-invariance. The increment is the
exact algebraic bound B >= log2 |A|, its per-fibre accuracy statement, the
tight binary-chain witness, and the joint layer/state characterization under a
strictly static kernel.
6.1  Relation to MQAR and associative-recall protocols
Zoology, MQAR and induction-head tasks measure recall under a large
vocabulary, multiple queries and non-adjacent bindings, with performance
summarised over a distribution of sequences. The task studied here is
deliberately narrower: n_pairs = 4, V_K = 32, one external query, adjacent
binding emission and a single last-layer read-out. It was chosen because it
admits an EXACT per-fibre answer set A(v) that can be enumerated, which
is what makes the bound tight and falsifiable. It is not an MQAR result and
is not reported as one. In particular, the 0.9512 five-seed trained accuracy
on H=2 (Table 3) is not comparable to an MQAR score: the vocabularies,
query counts, sequence lengths and answer distributions differ. What
transfers is the information bound A(b), which is distribution-free and
therefore applies to MQAR as well: any flat projection that leaves |A(v)|
compatible answers requires at least log2|A(v)| input-side bits, regardless of
vocabulary size. Establishing the same tightness on a standard MQAR
protocol would require enumerating A(v) there, which we did not do and
do not claim.
7  Limitations and a Falsifiable Prediction
Theorem A assumes distinct keys, adjacent binding emission, an external
query, last-layer read-out and a deterministic decoder; multi-query chains
and stop/select mechanisms are outside Result 2. P5's state-order bound is
conditional on d mutually orthogonal candidate successors per hop; when
the branching factor is 2 it degenerates to 2^(H+1), which we state rather
than hide. Finite-precision results cover L <= 128 for the analytic
7

construction; the long-decay frontier at L=2049 is a separate measurement.
Theorem A(b) is distribution-free and depth-free: no deterministic decoder
supplied with B < log2 |A| input-side bits can be exact on all compatible
instances. Any construction attaining exact H-hop retrieval with fewer bits
falsifies the bound at a precisely identifiable place. We did not run a
>=10M-token equal-compute language-model experiment, and we do not
present this as an architecture paper. A learnable codebook, a converged
strong baseline and a fair throughput comparison remain open.
8  Conclusion
Exact retrieval needs information that a flat symbol sequence does not
contain. We proved a tight lower bound on that information (B >= log2 |A|,
Theorem A), stated precisely where the bits may live within the
duality-preserving LTI class, and showed that the bit-depth frontier is a
right angle: extra layers cannot substitute for missing bits. Two tight
structural bounds (order-2 state for one hop; exactly H static-LTI layers for
H hops under last-layer read-out) are attained by one Toeplitz, O(1)-state
construction, and the layer bound survives 1500-step end-to-end training
from random initialisation (Section 4.12) with the inter-layer map fixed to
the codebook's own value-to-key swap. The practical rule is to budget the
bits at the input or relax exactness. The earlier attention-parity claim is
withdrawn because it did not reproduce (W12). Deep fusion of the
codebook state with zero-order consolidation (Section 4.13, Appendix
A.7-A.11) further shows that this class of models can improve itself on an
exactly-defined finite process, with a predicted and measured cover time in
agreement, while remaining within the same information bound. This is an
information-bound paper with a constructive counterexample, not a claim
of language-model parity, equivalence, superiority or a new SOTA
sequence model.
8

Broader Impact
This is a theoretical and synthetic-experimental study of information limits
in fixed-state sequence models. It contains no language-model training, no
human-subject data, no deployed system and no generative capability. The
immediate practical consequence is a design rule: an input-side information
budget must be accounted for before attributing a retrieval failure to model
capacity. A possible misuse is to quote the synthetic exactness figures as
evidence of general language-model parity, or to treat the withdrawn parity
claim as a performance result; both readings are excluded explicitly in
Sections 5 and 8. The work does not introduce a new mechanism for
surveillance, data collection or large-scale deployment. Its environmental
footprint is limited to CPU-only synthetic probes.

Appendix A  Complete Analytic Proofs
All proofs are analytic. Numerical witnesses certify non-vacuity and
agreement with the statements; they are not used as premises.
A.1  Theorem A(a) and A(b)
Fix a fibre v. The decoder observes (v, s) with s in (0,1)^B, so F(v, .) has at
most 2^B distinct values. Let A(v) be the set of distinct answers over
instances compatible with v and in the support. If |A(v)| > 2^B, two
instances G, G' in the fibre share (v, s) but have k_H(G) != k_H(G'). F
cannot equal both. Under the uniform measure on the fibre, at most 2^B of
the |A(v)| answer classes can be correct, hence acc(F | v) <= 2^B / |A(v)|;
this proves (a). Exactness on every instance requires |A(v)| <= 2^B for all
v, i.e. B >= log2 |A(v)|; this proves (b). Neither step uses P3. The marginal
accuracy E_v[acc(F|v)] is NOT bounded by 1/|A| when fibres with |A(v)|=1
carry most of the mass, which is why Section 4 labels every statistic. QED.
Binary-chain witness for |A| = 2^m. Fix m <= n and H = m. At hop h the
visible flat sequence contains one key k_h and TWO candidate successor
symbols; a bit d_h not recorded in v selects which one is bound, and the
selected symbol is the key of hop h+1. Both candidates are present as
tokens, so every d in (0,1)^m yields the SAME v and the same q = k_1.
Map d to the endpoint id sum_h d_h 2^(h-1); with V_K >= 2^m these are
2^m distinct endpoints. The witness enumerates all 2^m assignments with
bit-identical visible inputs (max deviation 0.0e+00). If the pairing is also
absent from v, all n! matchings belong to the fibre, giving B >= log2(n!).
QED.
A.2  Theorem A(c) and the Toeplitz equivalence (P6)
In class M, layer h computes z_h = sum_t K_h(L-1-t) m_h[t] e(x_t) with
m_h[t] = <q_h, e(x_(t-1))>, and q_(h+1) = T_h z_h / ||T_h z_h||. K_h
depends only on the lag and on fixed parameters, T_h is fixed, and e is
fixed. The composition is therefore a function of the multiset of (flat
symbol id, position) pairs plus q, i.e. of v with the refinement s removed.
Under arbitrary filler spacing the positions of the pair tokens are
determined by filler counts independent of the role assignment, so F is
constant on the fibre: no choice of H_L, state order or (rho, theta, w)
changes this, and A(a) applies. To encode roles in the kernel one makes the
recurrence coefficients functions of x_t, hence time-varying. For y_t = a_t
y_(t-1) + b_t y_(t-2) + c_t u_t with c_t != 0, P6 gives h(s,s)=c_s,
h(s+1,s)=a_(s+1) c_s, h(s+2,s)=(a_(s+2)a_(s+1)+b_(s+2)) c_s. Toeplitz
forces c_s, a_s and b_s constant by induction on the lag, so (rho_t, theta_t)
are constant. Non-Toeplitz h(t,s) has no single H(z) and the single-FFT
path fails. This negates THAT path within M, not every conceivable O(L
log L) algorithm. A(c) is therefore a conditional statement: IF duality is
preserved, the bits must enter on the input side. QED.
A.3  Theorem A(d), A(e), A(f) and P2
A(d). By the Section 2 definition B = sum_t log2 |pi^(-1)(v_t)|, so an
alphabet partition with |pi^(-1)| = 2 contributes exactly one bit per
non-empty token and is COUNTED in B. An explicit tag and a symbol id
carrying a role are the same quantity in a different carrier. Tagging only the
KEY token of each of n pairs gives B = n, which attains B >= n from A(b).
A positional prior is a support restriction: it reduces |A(v)| rather than
increasing B, and under random filler spacing the restriction no longer
holds, so the effective information falls to zero (measured 0.3438, 5 seeds).
QED.
P2 (explicit construction). Fix keys and q; A = sum_p L_p v_p + c with d x
d blocks L_p, read-out f(A,q) arbitrary, target j = j(q). Case 1: L_j singular.
Pick nonzero delta in ker L_j and change only v_j; delta-A = 0, answer
changes. Case 2: L_j invertible and some L_p != 0 for p != j. Pick delta_p
and set delta_j = -L_j^(-1) L_p delta_p; then delta-A = L_p delta_p + L_j
delta_j = 0, and delta_j is nonzero, so the target value changes. Case 3: L_j
invertible and all other L_p = 0. Then A depends only on v_j; fix all values
and redirect q to a different pair p != j, which changes the required answer
while A is unchanged. In every case two legal assignments give the same
(A,q) and different answers, so f cannot be exact. No step infers a
target-coordinate perturbation from dim ker L > 0 alone. Scope: single
mixer with a fixed linear historical summary; deep stacks with per-position
nonlinear FFNs, input-dependent gates and outer-product states leave the
premise. QED.
A(e). B < log2|A| makes exactness impossible for EVERY deterministic
model by A(b), hence for every H_L; for B >= log2|A| Result 2(ii) gives
minimum depth exactly H. The frontier is a right angle. A(f): under P4 the
decoded value at depth H_L is k_(H_L); for H_L > H and distinct keys this
differs from k_H. Retaining and selecting the H-th intermediate output
gives the correct answer for any H_L >= H; the lower bound H_L >= H is
unchanged. QED.
A.4  Result 2 (Theorem B): induction and tightness
(i) P2 rules out an order-1 vector state with a linear summary; Construction
C gives an order-2 tensor state with a contraction read-out, so the minimum
is exactly 2. (ii) Induction on H. Base H=1: one contraction resolves one
content match and yields the value; a zero-th layer cannot. Step: suppose
H-1 layers resolve H-1 hops and produce q_H = C[k_H] by the unique H6
interface. Layer H performs one further match with q_H and returns k_H's
successor. Fewer than H layers leave at least one hop unresolved: the last
read-out sees a mixture of at least two successors and cannot be exact on all
fibres. The analytic construction attains 1.0000 on the diagonal of the 5 x 5
grid and <= 0.10 off it, so the bound is tight and non-vacuous. Overshoot
H_L > H is A(f), not a failure of the lower bound. QED.
A.5  P5: conditional state-order lower bound
Premise. The interface is H6 with rank at most d; the codebook rows are
mutually orthogonal; at each of H hops there are d mutually orthogonal
candidate successors; answers are determined by the joint choice of the
start key and the H successors, so the candidate set has size d^(H+1).
Claim. An order-o tensor state whose per-layer linear summary has image
dimension at most o*d cannot be exact unless o >= H+1. Proof. The H+1
independent matching directions must be simultaneously recoverable from
the summary for every one of the d^(H+1) joint choices. If o <= H, the
summary is a linear map from a space of dimension (H+1)d into one of
dimension o*d <= H*d; its kernel has dimension at least d > 0. By the P2
construction (with the blocks taken to be the coefficient matrices of the
H+1 directions) there exist two distinct joint choices producing the same
summary and the same q, hence the same read-out, yet requiring different
answers. Exactness is impossible; therefore o >= H+1. This is a
CONDITIONAL bound: when each hop offers only 2 candidates the same
counting gives 2^(H+1) classes and the necessary order is weaker,
degenerating to a log2(H+1) bit requirement. We state that degeneration
explicitly rather than presenting d^(H+1) as unconditional. QED.
A.6  P1, P3, P4, P7, P8 and non-vacuity
P1. H(z) = sin(theta) / (1 - 2 rho cos(theta) z^(-1) + rho^2 z^(-2)) gives y_t
= 2 rho cos(theta) y_(t-1) - rho^2 y_(t-2) + sin(theta) u_t, a real-field
equivalence; different rounding orders in the FFT and IIR paths make fp32
bitwise identity false (W1). P3. For a finite output set F with |F| <= |S|, the
state can encode f(x) directly, so the literal claim 'O(1) states must lose' is
false; the correct statement is that a SPECTRAL compression state loses
content addressing. P4. At rho=1 and a single pole the Construction C state
reduces to sum_tau k_tau v_tau^T, the linear-attention state; rho<1 retains
a decay spectrum. P7. With impulse response bounded by rho^lag /
|sin(theta)| and per-step injection bounded by delta_max, the output error is
at most delta_max / ((1-rho)|sin(theta)|), under a uniform floating-point
perturbation model. P8. As theta_m -> 0 the dictionary columns approach
theta_m rho^lag (lag+1) and become collinear, so the grid is asymptotically
rank deficient. Non-vacuity: n=4, m=2, V_K=32, H=2, flat alphabet,
arbitrary filler spacing give |A|=4 at B=0 with acc <= 1/4, and exactness at
B=2.

A.8  SE2: monotone improvement and cover time
PREMISE. n bindings arrive by i.i.d. sampling with replacement (coupon
collector); the gate has false-accept at most alpha and miss at most beta;
accepted experiences are correct; rho < 1 with a precision floor epsilon
such that SE5's capacity K* >= n. CLAIM. (i) the number m_t of correct
registrations is monotone non-decreasing; (ii) E[m_T] >= (1-beta) T until
saturation; (iii) E[T_cover] = n H_n / (1-beta) with H_n = sum_(i=1)^n 1/i;
(iv) Pr(T_cover > (1+eps) E T) <= exp(-eps^2 (1-beta) n H_n / 3); (v) the
probability of any false commit in T rounds is at most min(1, T alpha).
PROOF. (i) SE1 makes each correct registration a disjoint orthogonal term;
register() replaces only the term of the same key and never removes
another key's correct term, and K* >= n prevents decay below epsilon. (ii)
The gate accepts a true binding with probability at least 1-beta. (iii) The
classical coupon-collector expectation n H_n divided by the effective
arrival probability 1-beta. (iv) Chernoff on a sum of n geometric variables,
equivalently the union bound Pr(some type missing) <= n(1-1/n)^T. (v)
Boole's inequality over T rounds. NON-VACUITY AND CHECK. For n =
32, alpha = 0.05, beta approximately 0, the prediction is 129.87 rounds; the
measured five-seed mean first full-cover round is 130.00 (relative gap 0.10
percent), with per-seed values 170, 100, 90, 120, 170. The arrival model
was set to i.i.d. BEFORE measuring. BOUNDARY. A deterministic
round-robin schedule gives T_cover = n and SE2 does not apply; large beta
stretches the cover time by 1/(1-beta); if K* < n then SE5 takes over and
full cover is impossible.
A.9  SE3: the statistical gate is necessary
PREMISE. Each accepted experience is corrupted independently with
probability p; a corrupted value is uniform on [0, V_K); there is no gate;
the final value of a key is its last write. CLAIM. E[acc] = (1-p) + p/V_K =
1 - p(1 - 1/V_K) exactly, and E[acc] <= that value in general because some
keys may never arrive. PROOF. The last write is correct either when it is
not corrupted (probability 1-p) or when corruption happens to draw the true
value (probability p/V_K). SE1 makes the keys independent, so accuracy is
the mean of n such Bernoulli variables. CONCENTRATION. Over N
independent key-level trials, Hoeffding gives Pr(|a_bar - mu| >= t) <= 2
exp(-2 N t^2). With N = 640000 the 4-sigma interval is [0.7071, 0.7116]
and the enumeration mean is 0.7091, inside it. WHY NECESSARY.
Orthogonality prevents cross-talk but cannot prevent a wrong value from
occupying an orthogonal slot; hence without a gate SE2's full cover is
unattainable under corruption. SCOPE. With p = 0, mu = 1 and the gate is
irrelevant: the ungated clean arm ties the fused arm exactly. The gate is
necessary ONLY when experiences can be wrong. W15. An earlier draft
called mu an almost-sure upper bound and tested it pointwise against a
sample mean; a sample mean legitimately exceeds an expectation. The
claim is now an exact expectation with a concentration interval.
A.10  SE4: compatibility with the CT7 rate bound
CT7(b) bounds the information that T consolidation rounds can write into
the state by T w b bits, independent of context length L and of bank
capacity C. SE2 permits about (1-beta) T registrations and a corresponding
accuracy gain. CLAIM. Both hold together. PROOF. Registration is
injective (SE1's partial isometry), so one binding corresponds to one
key-value association of exactly log2(V_K) bits. With T = 100 and w = 1,
SE2 registers 100 bindings using 500 bits, while CT7 allows 500 bits:
equality, not violation. MEANING. Self-evolution is real but bounded.
Long context buys inference-time retrieval, not a faster learning rate.
CT7(c)'s earlier statement that improvement was not proved is resolved for
this finite process; CT7(b)'s upper bound is untouched.
A.11  SE5: optimal decay eviction and closed-form capacity
PREMISE. Slot weights w_a = rho^age(a) with rho < 1; utility is additive
and orthogonal (SE1); precision floor epsilon; capacity C_max. CLAIM. (i)
Greedy removal of the smallest weight is optimal; (ii) the number of slots
whose weight stays above epsilon is K* = floor(log epsilon / log rho).
PROOF. (i) Utility U = sum_a w_a u_a with u_a >= 0 and mutually
independent; retaining the C_max largest weights maximizes U, and
dropping the smallest is its online realization. (ii) rho^a > epsilon iff a < log
epsilon / log rho. NON-VACUITY. At rho = 0.999 and epsilon = 1e-3, K*
= 6904; at rho = 0.90, K* = 65. The fast-decay arm loses accuracy to
0.1313 while the standard arm stays at 1.0000 over 320 rounds, matching
the predicted capacity collapse. BOUNDARY. rho = 1 is critically stable,
non-BIBO and has amplitude growing with L; the architecture excludes it
and no run instantiates it. A near-critical value such as 0.99999 barely
decays within the run and therefore has no discriminating power; 0.90 was
chosen so SE5 is observable.
